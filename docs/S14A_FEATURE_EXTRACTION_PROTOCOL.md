# S14A执行前协议：无评分依赖的诊断输入整理

2026-09-06制定；本协议是已见数据上的执行前合同，**不是未知数据预注册，也不是新算法有效性实验**。S13数值与成稿已核，S14创新候选仍待完整方法审读；本阶段只验证能否从评分前信息提取固定普通诊断量。

## 唯一问题与固定域

在不打开GT、评分文件、原图或任何NPZ数值数组的情况下，能否从30个已保存JSON为全部24个已见查询提取固定15列特征，并保留可独立核对的来源？

范围固定为S7/S8各3块、query20–23、主A0P0/stride8；S7 block0为开发4，其余S7测试8、S8测试12。阶段和query仅作元数据，不能作学习特征。本次不关联任何收益标签，不算相关性、不选阈值、不拟合模型、不重新选图，不评价支持/视频/速度，不下载或运行模型。

## 输入与列合同

确切30JSON域与15列公式以 `docs/S14A_EXTRACTOR_PREPARATION.md` 为定义文件；其代码及准备文档要在运行前SHA固定。域为6份prediction_only_selection和24份S12 selection，每份具有精确相对路径与字节SHA；不允许通配新增文件或沿JSON里的路径读取其它文件。控制文件为manifest和提取器源码，不计入30实验JSON。

特征依次为：候选交集大小/Jaccard、最终四图交集大小/Jaccard、来源weights归一化HHI/最大占比/熵、原weights降序14减15的已保存FP32间隔、FP32查询距离升序15减14间隔、两方案已选四图到query的均距、两方案已选四图内部六pair的均值/最小值。来源间隔以原FP32减法数值语义精确核验，最终复用保存值；中间验证对零规范为正零，最终保留保存gap符号。配额candidate_counts只验证身份，不能当概率。组合姿态距离不以米为单位。原权重中的首次来源累加语义保持不改，不将票权称校准置信。

两方最终四图六pair只取各自NMS接受步骤中保存的距离。每行使用12条pair记录，24行共288条使用记录，不是288次新距离计算或独立pair。缺任何pair、fallback不满足合同、ID重复/越域、非有限数、全0权重、未预期tie、SHA/域错误均停止，保留失败。

## 冻结、执行与退出

1. 不同作者阅读完整源码/准备文档和最终v4的28项人工边界检查回执；人工通过不等于真实输入通过。预审发现的FP32差与混合符号零问题须闭环，旧失败前审和修前源码全部保留。核最终预审是否对当前源码SHA有效。
2. 根生成 `docs/S14A_EXECUTION_MANIFEST.json`，绑定当前提取器、确切30输入、协议/准备文档/预审等控制材料；实际runtime守卫范围明确是提取器、manifest和30输入，控制材料另由根运行前后核SHA。
3. 单次运行输出为新 `results/S14A_prediction_features`，CPU标准库，600秒/1GiB为预期规模的观察上限，程序不含硬资源限制；由调用者观察，不把它报告为程序强制预算。任何异常保存日志，重试必须新目录。
4. 成功要求实际解码30JSON、产生24行×15有限特征、6项元数据、288pair使用来源；全部30输入和源码/manifest前后相同。逐行来源、实际计数、UTC/环境、源码/manifest快照和输出哈希齐备。
5. 执行后由不同于提取器作者的实现从同一30JSON重新算全15列、六pair和CSV/JSON。整数/ID/原保存距离精确，HHI/熵/均值允许预定绝对1e-12舍入差；不使用生产extract_row。输出差异表和检查范围，不读取评分文件来“验证特征有用”。

## 允许结论

只能说输入提取在此固定已见域中运行并通过核对，为后续普通门控强基线/机制研究准备了数据。程序隔离不恢复研究者未知结果状态；查询相机依赖真实query RGB，生成前只有轨迹的接口仍未验证。进一步训练、标签联结、校准和新场景有效性实验需新的明确协议与方法审读，不能借此阶段推进到未经审查的有效性主张。
