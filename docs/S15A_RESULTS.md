# S15A：20张新来源实拍已完成真实模型推理

**这轮真正在本机运行了模型。** 2026年9月6日北京时间18:04，固定的CUT3R模型读取了Bonn `static_close_far` 序列中预先选定的20张真实照片，保存了每张图的三维预测、预测相机位置和可供后续使用的模型记忆。运行成功，随后不同作者核对了文件、全部127个数值数组及相机转换。

这次回答的是“新来源照片能否进入我们的本机实验流程，并留下完整可核查输出”。尚未用传感器深度判断预测准不准，因此没有新的准确率、视频效果或算法创新结果。它也不是上轮S14E的93.10%结果复测；两轮数据、输入和实验问题不同，不能合并为新方法成绩。

## 1. 实际用了什么数据

来源是Bonn作者公开的 `rgbd_bonn_static_close_far.zip`，本项目此前没有对这段照片运行过模型。共获取20份原生RGB PNG，文件合计 **9,641,442字节**；模型记录20张均为 **640×480、RGB模式**。照片通过官方 `load_images(size=224)` 转成224×224模型输入，没有按未确定的标定再次去畸变。每张原图、时间戳、SHA和输入顺序都列在[冻结运行清单](S15A_HISTORY_EXECUTION_MANIFEST.json)及[模型回执](../results/S15A_bonn_history/run_metadata.json)中。

固定采样从RGB索引首时间 `1548340549.99545` 起，按 `t0+1.0+0.4×i` 选24个理想时刻；最近帧完全等距时取较早者，最大允许时间差0.025秒。前20帧作history，后4帧只登记为未来目标。实际history首末RGB时间为 `1548340550.99864` 和 `1548340558.60632`，跨度 **7.60768秒**。24个固定样本的最大采样偏差为0.01662秒，最大RGB/depth索引配对差为0.01613秒。这些是时间戳核查，未读取深度像素。

这项修订依据元数据完整性，未看照片、模型预测或目标答案。它不改变20+4帧、0.4秒间隔、0.025秒门槛或最近时间规则；v1源码、协议和失败回执未覆盖。

## 4. 不同作者复核了什么

模型完成并于北京时间18:05:12.062537封存之后，不同于runner作者的验证器实际执行一次，时间为 **18:05:24.557572—18:05:25.987358**。它核对 **161份文件、全部127个数组、1053项判定**，结果PASS。独立NumPy/SciPy实现将相机四元数编码转为旋转矩阵，最大绝对差为 **2.906570284455512×10⁻⁸**，在运行前固定的`atol=10⁻⁶、rtol=10⁻⁵`内；编码和相机平移字节一致。[完整复核回执](../results/S15A_bonn_history_independent/verification.json)

验证器没有重新运行模型，也没有解码照片、深度、轨迹或权重数组；但按封存身份实际读取了20份RGB文件及权重的字节流进行SHA核验。这两种“读取”明确区分。20张图的原尺寸在该验证器里来自模型metadata；后续汇报程序另外实际解码同20张图。

1053项是工程判定，不是1053次实验或独立样本。127个数组数值有限、旋转转换一致，只能支持记录完整和计算接口正确，不能说明深度接近真实答案。准备阶段的人工样例也不计入这次真实模型效果。此次复核是团队内不同作者核验，未冒称外部第三方复现。

## 5. 创新判断与下一步

[近邻与机制审查](S15_MECHANISM_AND_NEAREST_WORK.md)已明确：普通“历史一致性→置信度→模型/重投影混合”与已有工作重叠，不作为新增方法推进。当前保留的研究候选是：**旧记忆要被模型建议的新几何改写时，先保存新旧两种预测；等后来真实照片到达，再比较这一次改写是否获得更多支持，最后决定是否更新。** 它须胜过同样输入与预算的普通置信度、几何一致性和融合基线；目前只是有待推翻或支持的候选，尚未实施、没有分数，也未认证新颖性。

继续工作的先后关系是：

1. 先解决Bonn图像网格、相机坐标及时间的标定证据。当前不能把动捕轨迹未经核查就当成RGB光学相机位姿，也不能选择让分数最高的坐标变换。[标定审计](S15_BONN_CALIBRATION_AUDIT.md)完整保留确定事实与假设。
2. **这20张history已经被模型、汇报程序和研究流程看到。** 它们可以用于软件与信号探索，不能再冒称新机制的未见见证照片或确认集。严格的“先提案、后看见证”机制应另选一个提前固定的新时间段，明确12帧前缀、随后8帧见证及最终目标的读取顺序。当前未打开的4个future target继续保持原记录，不能把其状态与已暴露history混淆。
3. 为新段冻结新旧几何、来源照片身份、时间顺序、简单强基线、缺失处理和停止条件。先验证照片证据能否区分有益与有害改写，再做最终传感器深度评分；只有几何收益成立，才推进四图检索与完整视频消费者实验。

本轮实际使用了Supervisor的输入输出先定、小步骤编码和近邻致命缺陷审查，以及本地Claude科学批判思维技能的测量/混杂/主张强度检查；没有调用Claude模型。多人分别承担标定检索、机制审查、实现、人工前审、真实执行和不同实现复核，具体路径保存在对应回执中。研究主账、当前记忆与原则由根任务维护；本报告作者只依据文本/JSON记录整理，没有再次打开实拍或NPZ，也没有修改旧实验或协议。
