## 一个必须说明的变化

这段修复会改变历史权重的含义。原程序使用“方向权重÷(1+深度)”，组件返回的是除以中位数后的相对深度。因此，即使两个点都能看见，它们的相对票重也可能改变。后续配额和筛选也可能不同，不能描述为“只修了距离门槛，其他行为完全等价”。

共同尺度约定是已知工程概念；DUSt3R原论文和固定官方源码已有尺度约束。它们不等于实现了本组件的同一规则。原文、代码位置与区别见[独立近邻及语义分析](../work/S61_unit_consistent_retrieval/NEIGHBOR_AND_SEMANTIC_REVIEW.md)。本轮读取已有固定原文，未把旧检索计作新网络请求，也未新增Gemini咨询。

组件不提供真实米制标定，不改原几何生产器、优化初始化或深度缓存，也不能保证所有场景都有可用候选。完整检索另有混合平移和旋转的距离计算，这次局部换算没有证明整条检索对长度单位不敏感。
