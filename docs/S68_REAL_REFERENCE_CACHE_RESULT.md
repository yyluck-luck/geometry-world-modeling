# S68：五张真实参考照片已经接入原模型编码器

2026-09-09，北京时间。完整实验时间以正文及原始回执为准。

本轮已经把 TUM 数据集中的五张历史实拍照片，真正交给 VMem 原代码定义的图像编码组件计算，并保存全部输出。不同作者已核验来源、输出结构与相机内参换算。**完成的是后续实验需要的数据准备，还没有新生成视频，也没有验证新算法收益。**

可以把它理解为：模型要参考以前拍过的照片，我们先把五张照片翻译成模型能读取的数字，并确认照片编号没有接错。接下来还要告诉模型每张照片是在哪里、朝哪个方向拍摄的。

## 实际做了什么

执行前，从旧实验两组固定参考集合中取并集，只编码历史编号 **12、13、14、18、19**。这五张足以准备当前有限对照；其余十五张只核元数据，不为凑齐缓存重复计算。目标编号 20–23 的照片正文没有进入本次编码。

| 项目 | 实际记录 |
|---|---|
| 唯一一次真实编码 | 2026-09-09 09:12:53.263956—09:13:11.908300，北京时间；外部总耗时 **18.644267 秒**，正常退出 |
| 本机执行 | CPU，8 线程，FP32；使用已有本地权重 |
| 输入 | 五张 640×480 实拍 PNG，压缩文件合计 2,625,997 字节 |
| 原预处理 | 缩放到 768×576，左边裁掉 96 像素，得到 576×576 |
| 每张输出 | 图像 latent `[4,72,72]`、CLIP embedding `[1024]`、像素内参与归一化内参各 `[3,3]` |
| 存储对应 | 原编号 12/13/14/18/19 → 缓存行 0/1/2/3/4；不能把编号 19 直接当成五行数组的下标 |
| 输出体积 | 五份 NPZ 合计 440,740 字节，内含二十个数组 |
| 资源观察 | worker 自报峰值 RSS 12,969,394,176 字节；外部定期采样的进程树峰值 10,275,667,968 字节。两者测量口径不同 |

原 AutoEncoder 取后验均值乘以 0.18215；CLIP 保留逐照片的原始 embedding。采用之前已声明的 `sd-vae-ft-mse` 组件变体，**原 SD2.1 VAE 身份仍未确认，不能称原始基线的精确复现**。

启动前发现作者交付的解释器路径误指向基础环境，已用单独的更正文件恢复项目环境，然后才启动唯一一次计算。旧记录保留；没有把这个执行前更正写成一次模型失败。

## 核验到了哪里

不同作者于北京时间 **09:17:21** 完成一次有限复核：五份原始 PNG 的文件身份与头信息、五份缓存的完整文件身份、二十个数组的类型/形状/有限值，以及独立实现的内参缩放和裁剪算术均通过。共 138 项条件通过，**这不是 138 个科学样本**。

内参算术与保存的 FP32 数值逐字节一致。这里使用数据集官方提供的近似内参，未做去畸变；**尚未验证完整相机标定、像素中心约定或真实三维射线对齐**。核验者读取了五张压缩 PNG 共 2,625,997 字节，但没有解码或观看照片；不能把这一核验描述为“没有读 RGB”。

没有再次执行神经网络，没有独立重现全部 latent 数值，也没有运行后续条件组装、图像生成或质量评分。成功仅关闭了五张历史照片的外观编码接口。

## 对创新方向有用的新发现

旧 S8 实验在估计目标相机时用过目标照片。`update=false` 只代表没有更新历史记忆，不代表模型没有看到目标图。因此，旧结果可以用于**已经看过数据的固定参考集合对照**，不能直接作为“完全不看目标照片的在线选图算法”的证据。

旧实验两组顺序分别为 `[19,18,13,12]` 和 `[19,18,14,13]`。虽然只替换了一张照片，共有照片 13 的位置也改变了。后续必须比较完整的有序集合，并重新计算各组对应的相机归一化、射线和条件；不能把所有后续量冻结后声称测到了选图的完整影响。

当前仍值得检验的问题是：**旧几何指标更高的参考组合，是否真的让这几个固定目标的生成图更接近实拍答案？** 这还只是待检验的问题。S8/S12 已有的选图支持率、S14E 已有的深度对照不再重做后包装成贡献。本轮没有选定新方法，`new_method_validated=false`。

原文定点阅读核对了 VMem、WorldStereo 和 Mem-World 的相机/参考输入要求。Mem-World 此处只按已核的预印本处理。普通参考编码、视场选择和时间 surfel 已有近邻，不能仅换名称就称为创新；实际阅读范围见下方来源记录。

## 下一步已经明确

1. 补齐五个历史时刻与四个目标时刻的 **RGB 拍摄时刻相机姿态**。复用 S52 已算好的三个时刻，只新增缺少的六个；不能用深度拍摄时刻替代 RGB 时刻。
2. 数值核对 TUM 与 VMem 的坐标轴和射线，再实际运行原模型的相机归一化及 `get_cond` 条件组装。现有接口说明只是源码推导，这两步尚未执行。
3. 条件正确且两组确实有可比较差异后，再冻结完整生成对照及评分。至少需要原组、原组同输入重复、替换组，以区分组合差异和运行重复误差。尚未启动这些生成。

这一步的价值是让后续创新实验有可信输入，并排除错误的问题设定。它不是论文创新已经完成；跨场景、长时序、强基线、消融和论文贡献仍需真实证据。
