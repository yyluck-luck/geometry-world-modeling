# S14E：真实深度对照，模型记忆查询在这四个目标上优于普通重投影

**本机真实运行和传感器深度评分已完成，保存结果独立复核通过。** 四查询等权平均δ1为模型93.0974%、历史重投影85.8008%，差7.2966个百分点。模型在三方法共同有效像素域的平均绝对误差也更小。这是公开CUT3R现有能力在已见单段场景中的结果，尚不是我们的新算法或视频改善证据。

## 给新手的解释

我们先让模型记住此前20张实拍照片。这次恢复已保存的记忆，给它四个相机位置，要求它预测每个像素对应物体在相机前方的深度，也就是沿相机光轴的距离；它没看四张目标照片。另一个普通办法是把历史照片里的预测三维点直接投到目标画面。最后，打开深度传感器早已拍下的测量文件，比较两种办法，并加入“所有地方都猜同一距离”的简单对照。

δ1是距离比例达标率：预测/实测与实测/预测两者的较大值严格小于1.25算成功，所有有实测距离的像素都计分，缺预测算失败。93.10%不是相机定位准确率、画面相似度或视频质量，也不等于平均误差只有6.90%。覆盖率表示在有实测答案的位置能给出正且有限的预测；它不是正确率。

## 对结果的限定

1. 给定TUM相机轨迹和标定是共同允许输入，不能说没有任何GT信息。尺度只由20history拟合，s=1.1146619883400035模型单位/米；history平移RMS=0.0441773765模型单位。目标深度未参与对齐。
2. 相机内参按[TUM官方文件格式与标定建议](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/file_formats)使用已配准数据的ROS默认参数；PNG/5000转米，不重复应用已做的fr2修正。224裁剪K和depth时间条件在运行前固定。
3. 模型主输出固定self-z/s。官方带平移ray编码用于条件输入，标准pinhole用于基线投影；不把两个输出head强作严格刚体等价，也未根据答案换head或置信过滤。
4. 所有方法允许相同的history和相机来源，运算路线不同；本轮没有四图检索/NMS，也没有计算成本公平性或SOTA主张。
5. [CUT3R官方项目](https://cut3r.github.io/)已有虚拟视角的记忆查询能力。本轮验证现有组件在给定场景的有用性，没有训练新模型、定义新记忆机制、生成完整VMem视频或新增独立测试场景。
