- **30 个 mapping** 从同一块原映射独立重建，逐行、逐有序列表核对固定规则；没有把五种规则串成连续修改。原 52 文件的身份与 S10 冻结相同，六块原地图的 memory digest 重建一致。
- **60 份 render NPZ、180 个数组** 对六份对应原缓冲逐 shape/dtype/C 字节核对，零容差，包含正负零。
- **60 份 context NPZ、300 个数组** 与根据实际选中 ID、原历史相机、固定 K 和占位 latent/embedding 独立重建的数组逐字节核对；另对同条件两臂 150 对 context 数组直接逐字节比较。每份五个字段均核过。
- **30 对完整 trace** 两臂逐值一致；其数组身份逐项对应真实 NPZ，而非只相信 PASS。六个 baseline replay 的完整 official/decision trace 另核原 query20 封存值；baseline 的 context/render 身份亦独立核对。
- **66 次独立票权重建与 NMS 记录回放**：六 baseline 加 60 对照/候选记录。按原 buffer 的 C 序像素和新有序来源先收集每个来源的贡献序列，再逐个来源折叠累加，保留原程序首次贡献双加与 NumPy2 的 float32 算术。配额、可见来源、候选及截断差核对；用保存的 float32 距离排序，再消费每个比较、接受/拒绝、阈值放宽与后备步骤，最终核实际返回 ID。没有重算几何相机距离，也没有调用原选择器。
- **60 个初始状态重建、120 份 before/after 摘要**对应原几何、人工 mapping、相机、K、占位上下文和 target；两臂及调用前后完全相同。初始 NMS 阈值核原封存记录，没有重新计算阈值初始化。

## 参考性质与证据限制

本实验实际 66 次完整选图入口调用：30 次候选真实渲染、36 次参考 buffer replay（其中 6 次原来源 baseline），实际原 renderer 新调用为 0。参考虽重算投票与选择，但其三数组来自既有封存，不是新重跑的原 renderer。

六个 baseline 只保存 trace 与数组身份，没有独立 baseline render/context NPZ；因此本审查的 60+60 份实际 NPZ专指 30 条件的两臂，不夸大为 66 份。状态是存下的身份摘要，而非审查者独立观察的全部运行时张量。每次传入回放器的实际实参张量/签名也未单独另存；本审查重建固定预期实参和负对照差异，守卫确实执行的依据仍包括冻结源码与运行完成记录。

NMS 回放只核保存距离下的算法决定，不把它表述为相机距离重新推导。完整相等的官方 trace 中，姿态距离相关字段仍受这一范围限制。人工来源编辑不是物理正确的新观测或真实 merge/update 历史，也不能用来估计缓存命中率；S10 候选本身没有缓存。本轮 30 条来源条件与广域 192 条条件分开报告，既有六个查询不是 30 个独立新查询。
