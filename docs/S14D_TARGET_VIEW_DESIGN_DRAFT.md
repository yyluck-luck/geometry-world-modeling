## 给新手的解释与决定

S14C已经表明：只看过去四张图“分散多少”，同一片段里换目标照片时，指标可能完全不动，真实效果却变了。下一步先检查一个直接问题：**站在这次的目标相机位置，预测记忆里看得到的区域，有多少能找到所选四张历史照片作为来源？**

A可利用24份已经保存并通过旧核验的渲染ID图，不重跑模型、渲染器或选图，不新增查询RGB、预测查询深度或任何实测深度读取。此量是普通coverage基线；其价值是补齐对照与检查目标视角接口，不是新颖性或效果证明。

### 不能略去的相机限制

旧query相机来自CUT3R观察真实query RGB后的估计。虽然新提取器不再看query照片，它复用的ID图已经依赖该估计。正确结论只能是“**给定现有预测目标相机的档案组件诊断**”。尚未验证如何仅用未来轨迹和历史记忆取得同一坐标系下的目标相机，不能称完整生成前可部署。

旧渲染沿用平均焦距×0.65、主点居中、160×160、16边圆盘、near=0.1、far=1000和margin=50；按法向背面检查，圆盘用平均深度参与z-buffer。它不是按每个像素求真实光线交点。源crop K和渲染有效K也不相同。S14D-A原样继承这份近似；不偷偷改K、分辨率、遮挡或法向规则。

## S14D-A最小操作定义

固定域：S7/S8，各block0、1、2，query20、21、22、23，A0P0，stride8，共24条已见且相关记录。历史ID0–19，G是旧来源14的最终四图，P是S12姿态14最终四图，候选/次序/NMS均不重新计算。

记第q个旧渲染ID图为I_q(p)，p是160×160中的一个像素，N=25,600。记点j的历史来源集合为F(j)，来自同块A0P0_sources.json。对固定四图集合S∈{G,P}定义：

```
V_q(p) = 1[I_q(p) >= 0]
M_S(q,p) = V_q(p) * 1[F(I_q(p)) ∩ S 非空]
C_S(q) = sum_p M_S(q,p) / 25600
x_cover(q) = C_P(q) - C_G(q)
```

唯一主描述量为x_cover，正值表示G在这份预测可见图上来源覆盖更少。**不是实测支持差，也不是占真实可见像素的比例。** 分母固定整张目标网格，不能换成各自可覆盖的像素来人为升高分数。作为描述同时保存F_S=sum(M_S)/sum(V)，sum(V)=0时F_S为null；这两个分母必须在表头写清。

I_q已由目标相机和固定历史地图生成，所以即使四图选择不变，目标移动也可以使x_cover变化；这是“可以变化”，不是提前声称24条里一定变化。相反，相同I、相同G/P来源集合必给同一结果。

每个q以整数保存五类互斥像素：未渲染、双方有来源、仅G有来源、仅P有来源、已渲染但双方都无来源。五类和必须精确等于25,600；nG=双方+仅G，nP=双方+仅P；x_cover精确整数差定义为(仅P−仅G)/25,600。保存所有计数及比例，不用epsilon、不clip、不加权。

另保存每个像素的五类uint8编码，作为可独立核验的空间结果；分类图不是实验照片。对每块4个query固定枚举6对，共36对，记录：I相等像素数、V的交/并像素数、G与P来源mask各自异或像素数、两条整数差是否相等。它们用于回答“变化的是目标投影还是选图”，不是新增样本和统计显著性检验。

### 为什么不是重复S14A或S14C

S14A取来源票、位姿距离等JSON标量；S14C在历史共同点域计算3D质心分散，没有空间像素权重。本次真正新增的是旧渲染ID图与**两套固定四图**来源关系的逐像素联结。已有trace里的rendered_coverage只说整张地图渲染了多少，不等于G/P各自覆盖。因此读取旧图并算新量是新的档案测量，但没有新拍摄、模型推理、选图或生成。

## 检验与失败规则

执行前人工例只用于软件正确性：全−1；单点单来源；多来源交集；G=P；G/P互换；相同选择不同ID图；相同ID图不同选择；可见但两端无来源；一来源映射重复ID；非法负ID/越界ID；错误shape/dtype；重复/缺query；文件身份变化；部分文件失败。空图不是程序错误：记录NO_RENDERED_PIXELS，C_G=C_P=x_cover=0，F_G/F_P=null；不删该query。

结构错误、坏SHA、非整数ID、ID不在同块来源域、非法来源或选四图不合法都阻断整次结果封存，保留已经写出的失败目录、实际读取数与完整异常。不把缺项记为0，不换块补24条。真实数组读取前需由不同实现作者完成前审。

独立数值核验使用与生产不同的表达，例如生产点级bool查表再索引，核验逐像素集合交集/整数累加；完整24条计数/类别图和36对记录精确相同。比例由整数重新计算并核浮点语义。无需在旧渲染器上做第三次几何复现；要说清“核验了新联结”，没有重新证明CUT3R或物理可见性。

主描述性问题：固定选择的同块query，x_cover是否确有变化？若S8某块仍不变，如实保留，不能换其他重投影公式追求变化。即使变化，也只证明接口携带目标相关信息，**不证明它预测选图失败**。本阶段无Spearman、p值、拟合、权重、阈值、路由、候选搜索、选图改善或视频评价。

完成封存和独立核验后，才决定是否值得另立旧标签探索；不能把是否出现“漂亮曲线”设成开始关联的条件。若关联，要与普通查询距离等既定基线共同完整报告，并明确研究者早已知道24条结果。未来有效性和条件新增信息必须在新的物理场景、同输入/监督/模型容量和总计算预算下检验。

## 可选S14D-B：普通投影质心分散，暂不启用

明确一个不看query深度/RGB的可算量，是为了审查构念，不是批准立即试更多特征。

对S14B旧c(j,f)，先用归一化预测query pose构造相机坐标a(q,j,f)=R_q^{-1}(c(j,f)−t_q)。若要与旧ID图精确同接口，必须复制并核验旧average_camera_pose→optical/VMem往返的单相机旋转语义，不能默默假定浮点逐位等于原pose。用旧渲染有效K定义投影pi_q(c)=(f_eff*a_x/a_z+80, f_eff*a_y/a_z+80)，其中f_eff=0.65×mean(crop_fx,crop_fy)×160/224。

共同点域J_q要求：旧I图中可见；G/P各至少两个来源；G∪P的相关质心全部满足0.1<a_z<1000。任一不满足时两端同时排除该点并记录原因，不能各自选更容易的域。w(q,j)为旧ID图中j的像素个数，L²=160²+160²。

```
e_proj(q,j,S) = mean_{f<g in F(j)∩S} ||pi_q(c(j,f)) - pi_q(c(j,g))||² / L²
E_proj(q,S) = sum_{j in J_q} w(q,j)*e_proj(q,j,S) / sum_{j in J_q} w(q,j)
x_proj(q) = E_proj(q,G) - E_proj(q,P)
```

空共同域一律null，不填0。质心落出画面仍可比较其投影差，不再作人为screen内筛除。此量单位为归一化像素平方，不能与S14C的半径归一3D分散数值直接比较。

它的严重限制是：两个质心在同一目标射线上但深度不同，e_proj仍为0；来源错误关联可能把不同真实表面当同一点；同组系统偏差也可一致但全错。w来自固定锚点可见性，而非每个来源质心真实可见性，所以它不是完整遮挡或深度次序冲突。简单把3D欧氏残差旋转到query坐标更不会产生新信号，因为旋转保持欧氏范数。

若未来执行B，普通coverage A是必备基线；还须与相同历史深度和相机输入下的标准逐来源重投影/相对深度一致性、单图可靠度和query位姿距离比较。把上述量高于一个简单基线的单变量相关当作“联合新增信息”是不成立的。本轮不写生产B代码、不读其数值数组、不做效果筛选。
