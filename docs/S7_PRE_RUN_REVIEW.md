## 1. 可识别性：通过，但解释边界必须保持

固定A路径，在P0/P1之间复用相同的观测归属和出生顺序，法线、半径、颜色、贡献帧次数和来源表不变，只改最终位置，确实构成受控的位置干预。重放函数没有树或邻居搜索；每个旧点每帧先把该帧贡献位置取质心，再按贡献帧数递推，符合原`Memory.add`语义。它没有错误地按观测像素数加权。

固定P、跨A会同时改变分区、点数、出生属性和来源。这只能称**关联轨迹整体效应**。协议已正确排除“纯来源标签效应”；不能把交互差值解释为世界中的唯一因果分解。A0P1/A1P0是人为固定路径后的诊断地图，不是声称相应在线算法自然会产生的地图。

四个读出在同一地图上改变候选来源和NMS，能判断这些软件环节是否足以改变ID或支持。这个判断限于所冻结的排序、候选多重性和预算。12个不同查询、主测试8个、一个场景；384个条件不是384个独立样本。共同支持不变仍可能换图，协议已要求ID另报。支持与几何均为组件代理，不是生成视频质量。

## 2. 观测身份和事件：通过

`observations()`用原构造器分别处理真实RGB和编码RGB，逐值检查位置、法线、半径及过滤计数，并从编码取回224裁剪坐标。真实颜色回查原RGB，正式地图只使用真实观测。因此编码不会改变建图几何或混入地图颜色。两个关联路径直接复用同一批`frames`和同一身份数组，避免用不同路径的最终点号伪造对应。

`record_path()`调用原`Memory.add`记录原输入次序的匹配，出生点从`old_n`递增。原实现整帧使用冻结旧点树；重放检查匹配目标小于`old_n`，同帧新生点不能被作为旧点匹配。每帧offset、所有原几何、观测ID和事件均保存，支持后续不导入重放模块的独立复算。

ID应读作`(block, stride, frame, u, v)`，其中block/stride由所在案例目录提供；`(frame,u,v)`只在案例内唯一。它是同一原始预测观测身份，不是经过物理表面真值认证的对应。
