# S28：修复梯度后，优化目标更低，真实深度反而更差

**仅修复深度梯度连接并没有解决问题。** 在完整初始参数和输入逐字节相同的两组真实计算中，修复版确实更新了深度，却让共同4帧的平均相对深度误差从83.34%升到87.48%。与此同时，原优化目标从约0.01594降到0.00511。这个负结果否决了“只接通梯度就够了”的解释，后续要分别检验初始化尺度和目标约束。

这是已见TUM `fr2_desk` 首4帧的组件实验，基于真实照片产生的已有网络预测。本轮没有新的神经网络推理，也没有生成视频。普通autograd修复不是新算法贡献，4帧结果不是跨场景结论。

## 一、真正改变了什么

| 条件 | 新原版A | 仅修梯度B |
|---|---|---|
| 数据与几何输入 | 同一4份原预测头、给定相机；相同8图PIL准备后仅取前4 | 与A相同 |
| 初始化 | 原MST/PnP | 同一原MST/PnP；全部注册参数与buffer原始字节与A相同 |
| 相机、主点、深度先验 | 给定相机冻结、主点固定；不输入传感器深度 | 与A相同 |
| 唯一数学实现变化 | 原深度getter断开注册参数梯度 | 原MST完成后，getter直接堆叠原注册深度叶子，保留梯度 |
| 优化 | 原目标、Adam、400步、初始学习率0.01、linear计划 | 与A相同 |
| 评分 | 两臂完成并封存后统一读取4张传感器深度 | 同一完整有效GT分母、原尺度，无过滤或尺度拟合 |

原函数不在磁盘上改动；B只在独立进程中安装一个表达式的派生getter。仅删除detach并不充分，后续新建临时Parameter也会切断连接，所以修复直接保留原叶子。构造其他参数的helper保持原样，见[唯一getter差异](../work/S28_gradient_scale_control/getter.diff)。

这次额外运行新的A有明确用途：旧实验没有完整原始初态可供无损回放，因此新A/B保存并逐字节比较完整参数及buffer。它们是两次新的400步实验，旧400步及其失败回执完全保留，不重新编号或追认。

## 五、科研上支持什么，下一步是什么

本轮直接支持：在这组固定输入和预算下，普通梯度修复让深度实际参与优化，却进一步增加原尺度深度误差。**实现正确性和科学目标正确性是两个不同问题。** 下一步应检验剩余的初始化与尺度约束，不是再堆一个复杂模块。

S27M初始化的共同尺度约0.173。源码推导显示，同步变换点图与预测相机再取局部深度时，公共旋转和平移相消，尺度保留。约130°的映射相机朝向差不能直接解释标量缩小；单改旋转也不保证恢复深度，见[初始化源码与强对照](../work/S28_initialization_prior_analysis/analysis.md)。

S29候选先比较两个只初始化、不优化的普通控制：一个保持原尺度但重算对齐相机中心均值的平移，另一个约束初始化尺度为1并同样匹配中心均值。这会把平移起点的变化与尺度变化分开；尺度1是采用模型名义米制先验，绝不是真值保证。先核初始化代数预测，再决定是否有必要新增400步对照。候选计划与实际状态另存在`work/S29_scale_control_preparation/`，本报告不称其已执行。

这遵循Supervisor第2章“强基线→失败→根因→针对模块”的顺序。DUSt3R、CUT3R、Pow3R、MapAnything、TCO及传统配准都已提供相关机制和强对照；原文范围见上述初始化分析与[TCO方法复读](../work/S28_TCO_boundary/root_reading.md)。不能把固定尺度、增加先验或常规梯度修复换个名字就称创新。

本项目仍需在常规修复之后找到重要、可复现的剩余问题，形成实质新机制，并完成跨场景与真实生成消费者验证。当前没有达到最终PhD深度/CCF A投稿质量，也没有以负结果伪装性能进步。
