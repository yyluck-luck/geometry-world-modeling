# S9 候选 B：先核实际使用条件

结论：**当前“固定查询、固定点组与来源，仅允许位置改变”的第一版，不能直接当作原版 VMem 正常导航的加速方案。** 原系统每批先选参考，生成新帧后再建图；下一批查询可能改变，来源和点数也可改变。这要求先修改方法适用范围，而不是在离线实验中增加重复查询来制造收益。广义精确增量加速仍未检验，本报告没有证明它不可能。

本次是固定源码审查和人工控制流检查，不是完整 VMem 运行。绑定官方提交 `39291e4f272f6b4f270691d930926ab5930f942e`；具体源码 SHA、函数行号、实际执行时间见 `results/S9_B_call_trace/verification.json`。人工检查于 UTC 2026-09-05 20:30:55.943428–20:30:56.054976 完成；不把这段程序时长写成学生科研工时。

## 完整结果不变需要覆盖的内容

原渲染器 228–410 把 surfel 表面圆盘离散成16边形：正深度、视野预筛、背面、顶点投影、包围盒、整像素 polygon 测试、严格小于的深度比较都影响可见身份。不能用单个点中心的像素取整代替整个圆盘。深度缓冲为 float32；同深度时的历史顺序和转换也属于既有执行语义。

462–502的投票除来源外还依赖像素深度与视角余弦；即便可见 ID 不变，权重也可能变。首次出现来源的贡献在原实现中被累计两次，保持结果时须保留。当前调用令整数配额 n=min(14,来源数)，n总不大于来源数；因此 `get_frame_distribution` 在这条调用路径只给入选来源各1次，至多14个来源候选，不会进入能产生重复次数的剩余额度分支。随后按到查询姿态距离做 float32 排序、逐轮放宽阈值的 NMS 和后备补齐。**这不是取分数最大的4个候选。** 候选展开语句结构能表示重复，不意味着本调用实际产生重复。本项目 S7 的详细决定轨迹可以用于回归，但不能代替不同设备浮点行为的证明。

这是一份依赖清单，并不是正确性证书或新算法证明。复杂条件的存在也不是新颖性的证据。相关旧方法和同类近期工作已在 `S9_B_NOVELTY_EVIDENCE.md` 逐机制比较。
