## 3. 支持指标到底测什么，GT是否独立

对查询q的有效测量点集合V_q，历史i的支持mask S_i,q 表示：用**查询测量深度及查询GT位姿**反投影到世界，再用历史GT位姿投到该历史裁剪图；最近像素在范围内、历史测量mask有效，且投影轴向Z与历史测量Z相差不超过50mm。选择集合F的得分是 |V_q ∩ (∪_{i∈F} S_i,q)| / |V_q|。也就是四张中**至少一张**支持，不要求四张共同一致。源码 `scripts/run_s6_memory.py:32–47` 与两阶段 scoring 段明确给出。

查询/历史深度都先通过原640×480的5×5邻域全有效与50mm一致条件，最近邻缩放/裁剪到224；查询再每隔2像素取112×112网格。所有方法在同一查询共享V_q。该支持分数不使用预测地图、来源列表或首图拟合比例来定义真值；首图比例只用于伴随地图几何误差投影。

前20帧是历史来源，后4帧是只读查询，所选ID只能0–19，没有查询点写入地图。查询RGB用于CUT3R只读预测/相机估计，姿态对照和几何策略共享该查询信息。查询测量深度和GT位姿值在原选择全部封存后才用于评分；S7复用已独立核验的S6支持，S8从新场景原PNG/GT构建。S8采样此前使用过GT时间戳，不能称从未访问GT。

“独立”应准确限定为：评分不由待评价预测地图或来源标签自证、原选择不使用测量深度/GT位姿值；不是统计独立的新测试集。查询与历史来自同一连续片段/设备，共享表面与时序相关性；评分依赖查询和历史双方测量及GT，带传感器/标定/异步误差。S7/S8现在都已见，S12据此设计的新对照是诊断，不能重新标为未见验证。

该代理指标衡量可用几何重叠，不测颜色/纹理/遮挡边缘恢复、参考之间的信息互补、生成真实感或视频一致性；近姿态及重复覆盖可能有利于它。NMS为多样性付出的覆盖代价也不等于视频性能下降。20历史全部支持率是20图预算的覆盖上界，不是同4预算的oracle或可部署竞争方法。

## 4. 最小缺失实验与现有存证是否足够

优先缺口是**pose-nearest14 → 原姿态排序 → 原NMS → 4图**，对照已存 **geometry-weight14 → 同排序 → 同NMS → 4图**。双方同20个可用历史、同14候选数量、同4输出、同相机/距离精度/阈值/回退和评分，仅候选形成准则不同；候选ID必须允许不同，否则当前实现后半段必然相同。此对照可以隔离几何候选准则相对一个明确姿态候选准则的作用，不自动代表所有姿态策略。

范围建议固定全部24查询：S7开发4、S7测试8、S8测试12分层，不混合为独立n。4图×2密度是同查询的相关地图变体，共192配对条件；姿态14基线与地图/密度无关，原则上只需每个查询生成一次新基线24次，核重复引用身份后对照8个原变体。原geometry14选择和分数沿用，不重跑renderer。

保存字段的只读检查结果如下：

- 24查询各有完整20个 `distances_float32`、完整20项 `sorted_frames`、`expanded_candidates`=0..19、初始阈值，以及实际执行过的比较/放宽/回退步骤。两种all20读出的距离与排序相同，完整all20_nms trace跨8变体相同。
- 每查询只保存了13–39个不同非自身历史pair的距离；完整20历史需要190个无向pair，0/24拥有完整表。旧步骤只描述旧选择分支，不能直接截断后冒称覆盖新pose14的分支。旧all20实际放宽0–4次，回退0次；未执行的回退不在steps中，算法定义仍在固定源码。
- 新pose14可从封存预测poses按原 `geodesic_distance`（FP64、平移权重0.1）补算实际需要的历史pair，不用renderer/GT/模型；查询仍经过原单姿态平均/四元数规范化，再投成FP32排序。不能偷偷用未规范化光学输入、另一距离公式或改变严格 `< threshold` / `/1.2` /回退规则。
- 24查询的20个FP32查询距离无任何并列，14/15边界间隔为0.001543402672至0.023294687271。原192个geometry14票权边界也无零间隔，最小1.061335206e−5。此为保存字段检查，不是重新排序运行。新协议仍须冻结并列语义：优先绑定已有全20排序前14的池定义，按原frame-ID顺序建立0/1计数并用原NMS；若新复算距离/排序与封存不同就失败，不用新稳定排序或补epsilon掩盖差异。
- 新基线支持应从已经封存的 `query*_scoring.npz` 中 `support/valid` 对其新ID评分，不从旧records猜分数。该步骤需要新冻结评分文件身份，并核同查询两stride的支持数组相同后才复用；本审查没有打开NPZ或生成这项分数。

实施前最小回归门是：在新入口中先用原已保存all20计数和相同预测poses复现旧all20完整排序/NMS记录，确认坐标/精度/阈值一致；然后才执行新pose14。应记录新候选、完整NMS、4ID及旧support评分，独立复核。为解释“任何缩小候选池是否都能起到作用”，随机14等控制可以是后续问题，但不是本轮最小缺口，也不提前选择随机结果。

若要提出一般方法优势，还缺未用于设计的新场景、实际生成器/下游质量或其他独立用途指标；这些不是本次工程回归能够替代的。没有创新承诺。
