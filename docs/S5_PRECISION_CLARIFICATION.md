# 精度描述澄清：保留官方内部RoPE类型转换

独立源码审查在S5新序列评分前发现：固定CUT3R所用CroCo encoder的models/blocks.py在RoPE调用前将q/k转为torch.float16，调用后转回原dtype；decoder则显式转float32。此前“CPU FP32”表示模型参数、外部输入和保存输出的dtype，不应被理解为每个中间算子均使用FP32。

S4和S5均保留同一官方行为；本澄清不改模型、权重、适配器或输出，也不改变评分。既有参数/输入/输出FP32标签仍保留作为类型字段，但文稿必须说明这个内部FP16例外。原冻结S5协议保留，其哈希不改。本轮不为速度额外降低精度。

有符号负位置出现在decoder位姿token；其FP32适配检查已独立完成。encoder非负位置的FP16查表一致性另外保存为部件核查，不冒充新增图像推理或CUDA设备对照。
