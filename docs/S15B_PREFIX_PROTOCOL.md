# S15B：固定来源几何提案与后续照片证据的探索协议

本协议在本阶段新模型推理和照片代价计算前固定。数据是旧已见 TUM fr2_desk S8 block0，不能称新场景或未见确认集。DTAM、DSO等原文已否定简单“比较新旧照片代价再改写”的新增方法定位；此处执行的是测量与强基线组件，用于理解世界模型提出的几何修改。

问题：在同一来源照片、相机、尺度与候选几何下，后来照片对“保留旧深度”或“采用模型重新查询的深度”给出什么证据？照片代价是否能预测后续实测深度收益，尚待检验。照片相似不等于几何真值，也不把同一网络多次查询当独立观察。

## 固定数据与允许输入

使用results/S8_cut3r_cpu_v2/frozen_inputs.json的block0，不重采样：frame0..11为提案前缀，来源固定0/3/6/9；12..19为8张见证；20..23为最终4个已见评价目标。该数据在旧轮次已经处理，本轮仅保证新执行过程的提案先封存、再读见证，不声称这些图首次被整个研究流程看到。

TUM光学GT camera-to-world与固定K是明确允许的共同条件；不声称无GT pose。复用S14E已独立验证的allowed_gt_poses.npz：前20条是RGB时间，后4条是目标depth时间。准备可读该24相机元数据及时间数组，但只将前12条写给提案模型。模型进程禁止读完整轨迹、8见证图、4目标图及任何depth PNG。见证/最终相机分别写独立JSON，下游使用同一12前缀尺度，不用后续相机重新拟合。

K固定为[[245.2734375,0,112],[0,245,111.5],[0,0,1]]；原图640×480，官方224 loader的299×224 resize与[37,0,261,224] crop。最终实测depth按既有TUM /5000及nearest处理，不重复fr2尺度修正。

## 12前缀与4来源提案

复用现有固定CUT3R224权重、官方commit8bc15dc92a6d7fd92920b4ec81540d3dec7d3ecf、99源码、signed RoPE、CPU8/seed0/FP32，600秒/32GiB外层监控。新12前缀与来源query不同于已完成的20前缀/未来query，不是重跑旧成功条件。

一次官方history inference只处理0..11。保存12×6全部heads与12pose、最终五字段state。只用12个预测相机与其given GT做S14E同一forward OLS：A=Rpred0 Rgt0.T，u=A(g_i-g0)，v=p_i-p0，D=Σu²，s=Σu·v/D，c=p0-sAg0。D>1e-12、s正有限；不得反向OLS、abs、截断、SVD修正或用depth拟合。旋转atol1e-5、往返atol/rtol1e-5。

来源相机统一为R=A Rgt_s、t=sA g_s+c。旧候选取该来源首次观测的self-z，新候选从同一冻结12state在同一given-source相机ray query取self-z。两者使用同一given-source相机及K做标准pinhole构点，米深度同除s。这是**在共同标定相机中比较两种来源深度假设**，不是把旧预测pose原样保留的世界地图实验；避免将位姿差混作深度改写收益。

query序列严格[0,0,3,6,9]。第0来源重复计入5次query预算，六head字节精确一致才继续；每query前后五state保持不变。官方模型ray编码ro=t、rd=normalize(R K^-1 pixel+t)原样；物理构点用纯pinhole，二者不得混用。全部query输入RGB占位、img=false/ray=true/update=false/reset=false，不读取真实目标RGB。全部六heads、rays/相机/K/s与old/new conf_self保存。所有返回的原始输出在质量门槛前保存，失败保留，不换样本或调条件求成功。

## 见证照片测量与强对照

提案及参数、代码、身份封存后，另一个进程才打开来源4图和见证8图。见证GT相机按同一A/s/c转入模型坐标；无新尺度拟合。RGB→299×224 LANCZOS→上述crop→PIL L灰度，5×5 Census的24个非中心位采用“邻居<中心”。source中心限定[2,221]；old/new都正且有限，投到同一见证后两者Z>0，最近整数floor(u+0.5)皆在[2,221]才纳入同支持域。不做遮挡过滤，不把通过边界检查称真实可见。

来源每张划14×14个16×16块，共784块全部保留。逐块逐见证记录配对观察数量与old/new Hamming整数和；观察数量是像素×见证，不是独立样本数。每个有效cost在0..24。

- pool选择：全8见证整数Σold>Σnew才采用new，tie或无观察保留old。同支持域同聚合的二候选photometric argmin必须与它完全一致；这个等价关系是控制，不是创新。
- split-time选择：12..15与16..19两个组各有至少64配对观察，且两组都Σold>Σnew才采用new，否则old。
- 数量匹配absolute-new：在同样两组各count>=64的eligible块中，按Σnew/count从小到大选择恰好split-time接受的K块，平局按source、块行、块列。它使用另一规则的K，是偏有利于对照的匹配诊断，不是独立可部署门控。

mask按接受块覆盖整块，下游统一检查每个像素几何有效性；边缘/缺失未作隐形过滤。还需never-old、always-new、0.5深度混合、模型自身置信对照。主张任何新增算法前还要加入同信息MVS等近邻完整对照；本轮组件探索不假装已完成这些方法。

## 后续评价及停止边界

在读最终4张depth前先封存所有方法的记忆选择和标准z-buffer重投影结果。各方法固定同4来源、同源像素、同目标相机、不改RGB/source索引，最近像素floor(u+.5)，最小正z，同z取source/raster顺序最小，缺失NaN。最终GT>0全部域为主分母，缺预测算δ1失败；同时报告共同支持域误差、覆盖及每目标结果。预测self-z与重投影光轴z不能混淆。具体评价实现与身份清单须在答案读取前完成并冻结；不在本协议中虚构已执行评价。

若证据方法只等价普通argmin、仅因接受数少或数据更多获益，不作新机制主张。若照片证据与实测收益相反，记录全部失败块及作用条件，不能看完答案调阈值。该发现可成为后续新问题的依据，但仍需原文近邻与独立确认。

实际使用Supervisor idea-evaluator的F1早门、vibe-workflow的明确输入输出/小步执行，以及本地Claude科学批判的测量效度与混杂审查。不同作者承担实现和核验；人工检查、真实推理、保存数据测量与GT评分分别记录。所有步骤写实际时间主账，保留旧结果。
