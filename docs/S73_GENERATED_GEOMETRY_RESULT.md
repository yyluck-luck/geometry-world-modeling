创新检索如何影响下一步：

- CameraCtrl的真实视频误差底线对照已有先例；本轮真实对照属于观察器检验。固定F也无法区分某些沿同方向平移的距离差，因此低残差不能证明完整相机正确。
- [EgoSim，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/6b295b08549c0441914e391651423477-Paper-Conference.pdf)已采用指定相机的极线注意力与条件门控；[GEN3C，作者v1/CVPR 2025](https://arxiv.org/html/2503.03751v1)已有请求视角渲染、未覆盖区域遮罩和视角融合。简单加入这些组件不构成新方法。
- [VIVID，CVPR 2025的作者版本](https://arxiv.org/html/2411.07765v1)与固定官方代码已有软极线偏置及self/source联合注意力；该极线方案是论文的对比变体，不能说成最终默认方案。多个对应保留到生成过程这一宽泛设想也有重合。
- 可继续研究的问题是：多义或不可靠对应在被生成器使用时，能否得到具有明确含义的处理？当前尚无具体合格算法。self注意力质量不等于无匹配概率；重复纹理可能同时满足几何而身份错误。相关源码与数学说明见本阶段innovation_sources，属于机制边界，不是模型实验。
