## 一个可继续澄清的测量草案，尚未立项

把后续问题收窄为：“同一个记忆点所关联的历史观测，在预测坐标中是否彼此一致？”对固定A0事件中的记忆点j和历史帧f，以事件targets和observations的offsets/ids连接，形成该帧贡献点集。可以定义该组贡献的质心c(j,f)，并比较它与固定记忆位置x(j)的距离。这样的测量需要新公式、无效值/单来源处理和输入合同；本轮不把它加进15列，也不运行它。

若采用半径归一化，应说明分母取谁的半径、半径为何为正、无效项怎样报告；它不能叫米制测量误差。正常遮挡和不同面并不能单凭质心距离区分。事件匹配本身已按位置/法向阈值筛选，因此残差分布经过筛选；源数、入选时刻、观测密度和物面几何都是混杂因素。不能从低残差直接推导真值正确或来源可靠。

**必须先排除一个代数上的循环论证。** 若用同一组帧质心的平均平方距离衡量记忆位置好坏，令μ为这些质心的均值，则

`mean_f ||c(j,f)−x(j)||² = mean_f ||c(j,f)−μ||² + ||μ−x(j)||²`。

因此均值位置天然使该训练内量最小。“把位置改成平均后，该量下降”不能独立证明选图或真实几何更好。与实际frame_mean对照时还须准确还原出生观测、每帧聚合和权重，不能擅自把全部像素等权代替每帧一次贡献。未来若使用留出观测或下游支持检验，须另冻划分与评价，避免同一观测同时定义位置和证明位置可靠。

这只是普通几何残差测量的候选定义，不是新算法。若最终分数仅是已有pair残差的函数，它没有增加观测信息；要评价的是表达方式或归纳偏置，常规非线性基线也应取得相同原始残差及计算预算。先有可检验对象，再决定它能否产生独立贡献。
