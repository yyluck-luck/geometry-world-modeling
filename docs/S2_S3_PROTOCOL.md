# S2 / S3：真实RGB-D接口与简单位置更新对照

冻结时间：本文件写入时间与研究日志记录为准。初次下载仍在进行，尚未查看本实验的结果。参数改动或探索性补充另记修订，旧结果保留。

## 问题与证据范围

S2检查真实RGB、深度、时间和坐标是否正确接入。S3检查首次位置保留与简单重复观测均值更新，在真实测量上是否改变几何一致性及最终参考帧选择。输入使用TUM Kinect深度和mocap相机位姿，是**真实测量、已知位姿下的记忆部件实验**。没有CUT3R推理、置信度、原版完整清理或生成视频；不等于完整VMem复现。

## 数据、划分与预处理

- 官方TUM `freiburg1_xyz`；存下载URL、大小、SHA256和时间。RGB-D使用时间差严格小于20ms的唯一贪心匹配；在深度时刻插值mocap位姿，不外推。全序列按时间排序。
- 采用官方推荐ROS默认内参525/525/319.5/239.5，不再去畸变，不再乘1.035；深度除5000，0无效。
- S2均匀抽24个有效观测，检查回投再投影的坐标恒等、深度有效率、时间差和相邻观测的一致性。坐标恒等只检查实现，并不验证真实相机标定无误差。
- S3将有效匹配序列按时间等分为3个互不重叠的块，每块均匀抽24帧，前20帧写入、后4帧只评测。第0块为开发/实现检查；第1、2块为固定参数测试。同一房间的时间块不是3个独立场景。
- 主实验采样stride16；预定stride24敏感性检查。取原图相隔1像素的右/下邻居估计法向，排除无深度或邻居深度差超过0.05m的点。相同预处理用于两种方法。
- 半径使用VMem公式 `0.5*z/(525/stride)/(0.2+0.8*cos)`，表示稀疏采样的覆盖足迹，不表示传感器误差。记录半径分布。

## 记忆处理：只增加一个位置更新规则

对照为官方`merge_surfels`的单叶搜索语义：距离内按已有点索引升序遇到首个法向兼容点就合并，并非最近邻。固定normal threshold=0.6（原pipeline调用值），位置阈值使用原版每步全体半径的mean+0.5std。为使CPU可执行，用精确cKDTree范围查询并排序还原单叶顺序；小规模输入逐项核对未修改官方函数。默认八叉树另有已知边界问题，不混在本实验内。

两个方法为：

1. **first_write**：匹配后仅增加来源，保留旧位置。
2. **frame_mean**：同一旧点在一帧内匹配到多个点时先取均值；每帧结束后和历史帧均值按有效观测帧数平均。每帧最多计一次权重。法向、半径和颜色保持初次值。新点与原方法一样在帧结束后加入。

更新方法按自己的当前位置进行下一帧匹配；因此后续对应关系可自然变化，这是在线方法的结果。两方法均保存来源关联、更新次数、每步合并数、实际位置阈值、点数和耗时。不把简单平均声明成新方法贡献。

每个块运行原始测量，以及**仅第一帧**沿其相机深度轴加20mm、50mm的受控扰动；位置扰动不改变已计算的法向、半径、颜色和位姿。这两项是插入真实测量后的人工错误，不代表CUT3R自然误差。原始测量为主结果，扰动为机制压力检查。两种方法使用完全相同输入和顺序。

## 评测与检索

held-out深度不参与建图、法向、参数、更新或参考帧选择，只在选帧后作评测。

独立几何评测将记忆中心点投影到160×120网格，最近像素z-buffer，比较对应held-out测量深度。报告各自有效覆盖；主比较在两方法均有预测且目标深度有效、远离0.05m深度边界的共同像素上，报告绝对深度差中位数、均值、90分位及3cm以内比例。共同覆盖范围与样本数一并报告；不会删除大误差来抬高分数，也不把测量一致性称作真值误差。

检索使用未改动官方完整函数（context4、translationweight0.1、NMS）。mocap光学相机矩阵右乘diag(1,-1,-1,1)作为VMem输入，其内部翻轴回到光学坐标。NMS阈值由最初5个历史位姿的原版距离中位规则确定，两方法冻结同值。检索宽160×120，保留官方focal×0.65的更宽视野。预定在320×240检查选帧结果对分辨率的稳定性。原版中心主点与TUM缩放主点存在小于0.5像素差，记录为接口近似。

参考帧质量代理使用**固定测量支持mask**：held-out目标像素回投世界坐标，再投到每个历史相机，与该历史深度在5cm内一致即支持；两个方法所选4帧均在同一套mask上计算并集覆盖。mask不使用各自记忆来源，因此不能靠来源增加自动得分。报告最终帧ID、可见来源数、候选帧、权重和覆盖。覆盖不是生成视频质量。

运行前完善评测（数据仍未下载完成，未查看真实结果）：额外记录全部20历史帧的支持并集作为可达覆盖上界，以及最后4帧`recent4`、仅按同一位姿距离选择最近4帧`nearest_pose4`的辅助对照。两者选帧均不看目标深度；nearest_pose4不做NMS，因此只作实用参照，不用于单因素归因。恢复过程同时记录第1/5/10/20次写入后各自支持区域的描述统计，以及所有检查点和两方法都覆盖的固定像素统计；后者若为空则记缺测。

## 结论规则与停止条件

输出每块、每查询和每条件的配对结果；重复查询不能当独立场景算显著性。不能只展示改善样例。若几何指标改善但检索不改善，结论只限几何；若小扰动/原始测量不支持机制，保存负结果并收缩贡献。若参考帧变化但固定支持覆盖不下降，不能声称检索受损。

实现不变量失败时停止该配置并记录错误；若支持mask或共同像素为空，记缺测而非0误差。必须先通过坐标与等价性检查。未经实际完成，不填写视频质量、训练性能、GPU运行或导师会议完成。
