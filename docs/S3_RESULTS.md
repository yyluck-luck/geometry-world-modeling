# S3真实测量结果：更新地图尚未带来稳定的选图收益

本轮已经完成并核验。18个预定案例全部成功，0异常；独立结果验证4544项通过，另一位审查者从保存的深度重新计算72条查询记录，未发现需作废实验的实现偏差。正式实验于2026-09-05 22:41:40开始，22:46:45结束（北京时间，来自运行元数据）。

## 先看结论

在主要设置中，用后续观测平均更新地图，最终选中的4张参考图在8个测试视角上全部保持不变；160和320两种检索宽度都如此。地图深度差的中位数略小，但大误差仍然明显，共同比较区域也很稀疏。现有证据不足以支持“更新位置就能稳定改善参考图”，更不能声称改善生成视频。

可以把它理解为：先检查笔记里的位置是否被修正，再检查系统查阅的照片是否改变。笔记有所变化，并不意味着选照片的答案一定变化。这一轮把两个检查接到了同一份真实输入上。

## 数据、比较与分母

数据是TUM RGB-D的freiburg1_xyz办公室序列。深度来自Kinect测量，位姿来自数据集的运动捕捉轨迹，二者和标定均有误差。它们不能被当作无噪的完整三维真值。按预先冻结的协议分成3个等时长时间块，每块20张历史图和4张留出图。块0用于开发，块1和2用于固定参数测试；这些块来自同一环境。

18案例来自3时间块、2采样间隔和3首帧扰动条件。每例比较first_write（匹配后保留首次位置）与frame_mean（每个观测帧贡献一次权重的位置均值）。后者是简单对照，不声称创新。检索沿用固定版本VMem的完整最终选帧路径。真实输入绕过了CUT3R置信度和原版完整清理流程。

共保存36张地图、72个配对查询条件、144个“查询条件×检索宽度”的配对记录。真实相机查询只有12张，其中8张用于测试；这些数字不能视作72或144个独立场景。

## 主要结果：原始测量，采样间隔16

| 指标 | 首写保留 | 每帧均值 |
|---|---:|---:|
| 逐查询深度差中位数的平均（mm） | 30.289 | 27.992 |
| 逐查询平均绝对深度差的平均（mm） | 260.856 | 259.265 |
| 自身预测覆盖有效目标的平均比例 | 10.845% | 10.585% |
| 4张参考图的固定测量支持覆盖 | 90.837% | 90.837% |
| 每个测试时间块的平均地图点数 | 3515 | 3475 |
| 20帧建图时间的平均（秒） | 0.148 | 0.183 |

以上几何误差使用每张查询中两种方法都预测到的相同像素。共同像素为450–646个，平均529.375个，只覆盖有效目标约3.908%。覆盖率小意味着这些分数只能描述稀疏局部，不能代表整个画面。建图时间不包含读取图片、数据关联、评测和选帧，是本机这次运行的描述性记录。

两档检索宽度各有1/8个查询的候选集合发生变化，但最终4图集合都保持不变。这表明中间候选变化确实可能被后续筛选吸收。最终选择集合不变时，基于固定图像支持的评分也必然不变。

## 与简单选图的比较

原始测量主设置中，选最近4张历史图的支持覆盖为92.810%，按位姿距离选最近4张为93.820%，均高于本轮VMem记忆选帧的90.837%。这两种简单参照不查看查询深度。全部20张历史图联合支持为96.848%；它只是额外预算的上界参照，不能当作同样4张预算的最优方法。

这个发现提示，下一步值得优先检查最终选帧规则、姿态多样性要求与本场景的匹配程度。它不证明简单最近位姿策略在长视频中更好，也没有改变原先测试参数。

## 为什么中位数与MAE相差很大

看到主结果后，追加了明确标为post-hoc（事后）的诊断，覆盖全部8个主要测试查询。保留的4235个共同像素中，首写保留有1392个误差至少100mm、881个至少500mm；均值更新分别是1366和864个。按像素汇总的90百分位绝对差约1000和1009mm。这里按像素汇总的数值与上表“逐查询等权平均”不同，不能混用。

大误差在更新后仍然存在。共同像素只是两套稀疏点中心投影落在同一个格子，不能保证来自同一物理表面或满足真实遮挡关系。4倍降采样的取整可能移动至原图邻近像素，而深度边界筛除只有1像素邻域。这是候选解释之一，尚未证明它是全部尾部误差的原因；传感器、位姿、遮挡和建图也可能影响结果。所有误差仍计入原指标，未剔除不利结果。

## 当前研究决定

继续保留first_write与frame_mean作为可复现部件对照，暂不把简单平均包装成新方法，也不扩大GeoTrust复杂机制。下一步接独立CUT3R真实估计器，先核实本机两帧推理、输出坐标和数值，再决定有依据的后续实验。完整VMem视频生成、学习置信度和跨场景泛化仍待验证。
