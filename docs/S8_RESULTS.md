# S8新场景复验：换图仍会发生，旧模式未重现

新场景TUM freiburg2/desk的72张真实RGB已完成CPU推理；6个案例、24地图、96次原渲染、384条读出完成，14,253项独立结果核验通过。三个块全部测试，只有12张不同查询，而且来自一个新增物理环境。检查次数、地图数和读出数不能当独立样本数。

最明确的结果是：主设置中，固定A0关联只平均位置，12张查询全部不换图、支持不变；固定A1关联平均位置，4张换图，2张支持上升、2张下降、8张不变，12张平均只增加0.018962个百分点。因此，“位置会条件性地影响选图”在新场景仍有实例，但S7主设置的A0负/A1正符号组合没有重现，预定稀疏路径的精确抵消也没有重现（0/12）。不以较好看的敏感性结果替代主结果。

## 数据与方法

原始官方TGZ完整校验后保存。V1在只读GT时间戳阶段因重复键1311868229.576停止；两行的7个位姿token文本不同，不代表已证实物理位姿矛盾。随后在看新像素或位姿数值之前冻结V2：对全部重复float时间统一排除abs(t-d)<=0.051秒的GT行，并保留其他原始行bytes与次序。本次20957→20926，排除31行；最近保留左右间隔0.1066999435秒，超过沿用的0.100秒插值上限。5932个非GT文件独立字节复制，原源树不变；23,803项独立派生检查通过。旧协议、失败及官方原件完整保留。

完整RGB/depth表先按严格20ms一对一关联得2893对，再按双时间同一连续GT区间过滤。8.840秒、24等距目标、50ms最近误差、100ms窗间隔的固定规则得到6窗，取0/2/5三个首中末窗；独立采样1554项检查通过。全部72张RGB核PNG/640×480/完整解码及SHA，原样复制交付，三总览逐张查看且没有换样。三个片段约8.84秒，cadence近似旧场景但运动与重叠并未匹配。

每块独立CPU进程，20张历史写入，4张查询只读，reset全False。沿用CUT3R 224 linear中间权重及signed-RoPE适配；输入/输出FP32，但官方encoder内部RoPE为FP16。不是VMem完整512DPT/全局优化/clean/视频生成。504个保存输出通过核验，查询内部状态以运行内hash/flag记录检查，未保存原状态张量。

A表示观测如何归入地图点：A0为首写在线关联，A1为在线均值关联。P表示点放在哪里：P0为出生位置，P1为贡献帧质心的等帧递推平均。同A内，来源及非位置属性严格固定；跨A还改变观测分区、点数、出生属性和来源，不能说只改变来源标签。四图对角严格复现本轮直接建图，不与旧场景地图相混。

主stride8、敏感性stride12。每次都只选4张历史，比较原候选+NMS、同候选去NMS、全20候选+NMS、全20候选去NMS。NMS按相机位置和朝向避免太近视角。全部选择封存之后，才解码原深度/派生GT位姿，每块只在第一帧拟合一个测量尺度。深度/5000，不重复fr2预修正；K沿用官方推荐近似。目标5×5有效筛选、50mm一致阈值及112栅格投影均沿用旧规则。

参考支持率：所选4张旧照片的实测几何能共同支持多少有效查询点。同一查询各方法共享分母，先逐查询计算，再等权平均。支持率不是视频美观或新视角质量。

独立核验从72份原深度PNG及派生GT重建测量/mask/支持，核504保存模型数组、6观测集、12关联路径、24地图、96保存渲染至投票及384完整读出。没有重跑神经模型、surfel多边形光栅化或原内部state张量。时序证据是元数据与归档源码，不是复原历史文件访问轨迹。详见S8_INDEPENDENT_AUDIT.md。

数据来自与fr1不同物理环境及另一实体Kinect，仍同TUM数据集和同类设备；相机、场景、运动、可见重叠共同变化。官方训练资料与权重静态metadata无法证明模型训练未见这些序列，因此只称本研究留出的场景。GT传感器/标定本身非无噪真值；本次评分使用保守时间排除子集。

研究贡献候选是能够审计位置、关联、读出条件作用的实验工具。跨一个新物理环境的组件证据已补上；通用新颖性、广泛场景覆盖和生成视频消费者验证仍不足，不宣称成熟benchmark、普遍优越新算法或完整项目已结束。下一阶段应优先检验诊断能否指导具体改进，再对完整消费者进行验证；原proposal、课程真实活动和最终提交仍单独跟踪。
