# S15A：新来源原生实拍的真实历史推理协议

本协议在新来源照片、深度和轨迹内容读取前建立。执行时间以分阶段回执为准。问题仅为：固定的 CUT3R 224 模型能否从此前未在本项目运行过的 Bonn 序列，处理固定的20张实拍，并留下可复用的几何预测和历史状态？这不是新算法、几何准确率评测或完整视频实验。

## 来源与阶段边界

使用作者公开的 `rgbd_bonn_static_close_far.zip`。复用已验证 ZIP 中央目录的成员名称、压缩长度、CRC 和本地头偏移；每次网络读取都检查同一 ETag、Last-Modified、总长度、精确 HTTP 206 Range。旧 S14 元数据合同已结束；本文件与新的分阶段合同授权新的有限成员读取，不修改旧合同。

1. 先获取 `rgb.txt`、`depth.txt` 两个时间戳/路径索引。它们不是图像深度数组，但属于真实数据元数据，需如实记录读取。禁止获取 `groundtruth.txt`。
2. 用下述固定规则选择24个时刻。将20个 history 和4个 future target 的路径/时间记录到样本表并冻结。选择不依赖像素、置信度、预测或答案。
3. 只解压前20个 RGB 成员。ZIP 解压不等于 PNG 图像解码；两者分别计数。4个 future target 的 RGB、所有 depth PNG 和 trajectory 均不获取、不解码。
4. 冻结模型运行 manifest 后只解码20张 history RGB，真实运行一次官方历史推理；输出封存后再核查保存数组与绘制全部20张实拍索引图。

公开下载链接支持本地研究访问，不推断独立再分发许可证。数据留本地，不上传到公网。Bonn 是新数据来源/新拍摄序列，但具体物理房间与其他数据集的对应、完整预训练数据暴露情况未知，不称认证的未见房间或训练无重叠。

## 预定采样规则

读取索引时忽略空行与 `#` 注释，数据行必须恰为时间戳和相对路径两列；时间戳有限、严格递增，路径须在冻结中央目录中且类型正确。不得按图像内容删样本。

设 RGB 索引首时间为 t0。理想时刻固定为 `t0 + 1.0 + 0.4*i`，i=0..23。每个理想时刻选绝对时间差最近的 RGB，完全等距时选较早时间；要求偏差不超过0.025秒。为后续阶段仅记录最近 depth 路径/时间，等距取较早，RGB-depth 差也须不超过0.025秒。必须得到24个不同且有序的RGB和24个不同depth条目，i=0..19是history，i=20..23是future target。若条件失败则保留失败并停止，不悄悄换起点或难度较低的序列。

## 原生图像与模型

当前标定审计尚不能认证 PNG 是否已去畸变或 `groundtruth.txt` 是否为光学 c2w。故本轮保留原生 RGB，不用假定的畸变做第二次重采样，不提供 GT 相机、不做投影和尺度对齐。官方 `load_images(size=224)` 进行唯一的归一化/resize/crop；记录每张原图尺寸与模式。该选择可以支持工程可运行性，不能解决几何标定问题。

复用现有约3GB `cut3r_224_linear_4.pth`、固定官方 commit `8bc15dc92a6d7fd92920b4ec81540d3dec7d3ecf`、99份Python源码及已验证 signed RoPE 适配器。固定 CPU、8线程、seed0、float32、20历史/0查询、600秒和32GiB RSS 监测上限。不得自动改用其他模型、低分辨率、序列或降低样本数来获得成功。

`run_s15_history.py` 接口与运行 manifest 规定全部输入SHA及输出schema。一次 `inference` 处理20个历史，图像 encoder 一次含20帧；官方内部会计算一次随后乘零的 dummy ray encoder，不冒称其调用数为零。没有目标相机 query。保留120个官方预测数组、20个相机编码/矩阵、五字段最终状态；预测在有限性等完成门槛前写出，失败也保留。成功门槛是预定输入/身份/调用数/形状/有限性和状态完整性，不是准确率。

## 复核、展示与结论

不同作者检查运行输入与源码身份、20张全量图片、输出数组schema/哈希及相机编码到矩阵的一致性；不为了复核再跑模型。照片索引图必须列出全部20张，清楚标为实拍；任何模型深度图另标为预测且尚未定米制/准确率。不得把“非空/有限/旋转矩阵有效”写成重建正确。

本轮不计算 δ1、MAE、视频指标，也不训练新模型。下一步须解决标定接口，再为尚未打开的4个 future target 建立独立预测/答案封存协议。若提出新记忆更新机制，必须先读 `S15_MECHANISM_AND_NEAREST_WORK.md`，排除普通一致性投票和在线置信学习已有近邻；本轮不以工程成功宣称创新成立。
