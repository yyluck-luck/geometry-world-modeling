# S5：72张连续照片的真实模型检查

本机已经完整处理同一房间的三段照片，每段24张。每段只用开头一张的实测深度校准距离比例，后面的照片保持该比例。重点检查的8张照片，平均深度差约7.2厘米；误差曲线有起伏，没有显示始终增加。

## 运行事实

- 模型：独立官方CUT3R，固定224 linear中间检查点，仍使用S4经审查的本机兼容适配。
- 2026-09-05北京时间23:20:38启动，23:21:35完成三块推理；23:22:00完成全部评分。
- 72张照片没有丢弃，504个保存数组全部有限；三块前向分别9.545、9.323、9.376秒，峰值内存约6.425 GB。属于单次运行记录，不作硬件速度排名。
- 参数、输入、保存输出为FP32；官方encoder在RoPE内部会临时用FP16，保留原行为。
- 各段独立初始化，RGB按顺序进入模型。后4张的深度只用来评分；它们的RGB仍会进入顺序估计，并可能影响下一张RGB的状态。

三个块来自同一环境。B0沿用开发标签；B1/B2的最后4张，各4张、合计8张，是预先固定的主测试。表中均按图像等权平均，p90这一列是“各图p90的均值”，不是把所有像素混在一起的p90。

阴影是每段末4帧，主测试只取B1和B2的阴影。第一帧参与尺度校准，仅作描述。各面板范围分别包含全部数值，不能凭曲线的视觉高低跨面板排名。曲线有升有降，单靠这些结果无法把差异唯一归因为“记忆随时间漂移”，还可能包含画面内容、遮挡、相机移动和标定/测量误差。

S4的单张留出MAE32.324mm和这里8图均值72.121mm涉及不同图片及上下文，不能直接解释为随时间恶化；S3稀疏地图重投影和S5密集单图预测也不是同一评分口径，不能拿两组MAE当方法提升。

## 原始证据和边界

所有72张的原图/有效实测depth/预测depth都有图集，按时间顺序完整保留，不挑好看的例子。灰色为预先排除的测量像素，共用颜色范围。照片和depth来自[TUM RGB-D](https://cvg.cit.tum.de/data/datasets/rgbd-dataset)，CC BY 4.0。
