## 必须保留的归因边界

原程序每次在计时外检查新渲染三个数组，并比官方 wrapper 和完整 NMS 追踪；144 行都记录 `exact_regression_passed=true`，冻结代码显示未通过就不会保存该完成行。**本轮只直接取得了 24 份初次完整追踪**；其他 120 次没有逐次完整追踪，新渲染数组也未另存。因此“144 次原回归通过”在本审计中是原运行记录及验证源码证据，不是本审计又比较了 144 套新渲染数组。保存 trace 对旧值一致，亦不等同本次重新执行算法。

已读计时边界与 wrapper：renderer 包括原 ObservedKernel 返回值记录；votes 包含原来源票数、候选配额及其 observer；sort/NMS 从 candidates 开始直到索引 tensor 产生，含姿态距离、FP32 排序、阈值放宽与后备；other 是相减剩余，含上下文包装与插桩间隙。几何 tensor 为 FP64，argsort 使用原默认 FP32；小 latent/embedding 占位数组不是实际模型上下文搬运。没有扣除 observer 或计时器开销，也没有无插桩对照。

环境与资源是本机既有环境的记录：Torch intra/inter-op=8；环境变量为 8 不证明所有底层库实际都用了八线程。300 秒和 16 GiB 为软守卫，Python I/O 钩子不是 OS 沙箱；本审计不重建历史后台负载、调度或内存峰值。24 查询来自两个已见场景，五次重复不能用于独立样本显著性或泛化结论。全部结论限于这个 CPU、160×160、20 历史、A0P0/stride8 包装组件，不能外推完整 VMem 或生成视频。
