# S0：VMem 记忆几何能否被后续观测修正

状态：首次运行前写入的本地实验协议；并非外部注册。日期：2026-09-05。

研究问题：一个错误 surfel 已经通过上游过滤并写入记忆之后，后续正确观测能否改变它的位置？输入顺序是否影响结果？

依据：固定 VMem revision `39291e4f272f6b4f270691d930926ab5930f942e`，运行原始 `merge_surfels`、`Surfel`、`Octree`；对一个例子使用原始渲染函数的 NumPy 分支。提取前后 AST 必须完全一致。没有运行生成网络、CUT3R、点云清理、置信度过滤、上下文选择。

实验对象是 2 个解析 surfel 网格（每个 30 点，平面和深度台阶），不是 2 个真实数据集场景。长度单位人为定义为米。向候选位置注入深度尺度偏差或相机 x 方向平移；不调用 GT 决定写入。GT 只用于构造合成输入和评测。深度扰动允许点间轻微差异，位姿平移在同一帧内保持刚性。

配置列出 2 场景 × 2 污染类型 × 3 强度 × 3 随机种子 × 2 输入顺序 × 3 重观察次数，共 216 个配置。clean 情况跨 seed 和污染类型存在重复，仅作对照，不能当成独立样本扩大统计显著性。

两个顺序分别是 `[noisy, clean] + r × clean` 和 `[clean, noisy] + r × clean`；同一配对使用完全相同的观测多重集合。额外干净重观察次数 r 为 1、4、12，**不是遮挡间隔或长视频长度**。保留原始自动空间合并阈值；法向阈值 0.6 与配置一致。固定半径 0.045 m 是本测试参数，不是原系统的全局半径。输入通过筛选是条件前提，不代表实际筛选会放过相同污染。

主终点：所有存储点到解析 GT 点集的平均最近邻距离；同时记录最坏距离、错误点比例（>1 cm）、GT 点召回率（≤1 cm）、总记忆数量、来源 ID 数以及首批点的位置变化。1 cm 只用于这个人工米制场景，不能迁移为单目重建的通用阈值。双向距离防止仅删点带来的误导。本轮没有新 gate 或预算限制，不报告任何方法优越性、因果公平比较或显著性检验。

辅助视图：同一官方 renderer 渲染存储几何与干净参考几何，分别记录 coverage 和共同有效像素上的深度误差。共享 renderer 可能存在共同偏差，因此这不是独立几何 GT，也不是等覆盖率证据。空覆盖率不得作为零误差。

判读规则：若错误首批点一直保留，记录“该局部合并函数不纠正已存几何”；若远距离错误形成新点，记录“局部多层记忆”。即使上述现象成立，也不能直接声称真实生成漂移或证明 GeoTrust gate 有效。反之若位置被更新，则推翻本次代码阅读推断，检查调用路径与测试提取是否错误。

下一阶段先测自然产生的几何误差能否穿过官方 point-cleaning + confidence/depth filter，再测试其是否改变 view retrieval。只有真实数据和生成输出支持后，才能把此诊断写成世界模型失效结果。
