# S1：几何误差是否改变最终参考帧

首次实验前保存，2026-09-05。本协议是在S0后的新问题，不是对S0的性能追认。

**主终点：固定版本官方 `get_context_info` 返回的 `context_time_indices`。** 同时记录中间权重、候选集、最终有序ID与集合。中间打分变化不算最终检索变化，最终检索变化也不等于错误或生成视频变差。

通过 AST 原样提取官方六个方法与 `average_camera_pose`。使用 CPU PyTorch 2.7.0、NumPy、SciPy；不用模型构造函数或权重。虚拟 latent/embedding 仅用于原函数最后的输出打包，不参与选择；不得称为图像生成。相机遵循原版翻转 y/z 轴约定，焦距保留原版 ×0.65 系数。

## 人工场景

墙面 z=4 有5×4块分离的小区域，各块由3×3 surfel组成，点位置/半径有固定种子的小扰动以减少并列。所有法向 +z。半径和尺寸是测试参数，不是生产设置。

- `shared_history_8`：8个远处历史相机全部看到同一面墙；每个点的来源集合由干净几何的历史相机视锥投影确定。用于检验“改变位置但来源集合没变，最终选择可能不变”。
- `patch_history_20`：20个相机靠近不同的小区域，各自只见相应区域。来源ID根据点中心进入视锥决定；墙面共面且区域分离，不存在跨深度遮挡。目标相机位于远处，看到全部区域。用20来源触发最多14个候选的截断。

来源关联根据干净历史几何一次确定，之后冻结。只对位置施加干预：共享场景全部点，分区场景固定第4/8/12/16区域。平移0/2/10/40cm，或从目标世界原点定义的深度尺度0/0.5/2.5/10%。深度尺度是世界原点射线方向的几何扰动，并不声称模拟所有近壁源相机的真实深度误差。其它位置、半径、法向、来源ID、相机、帧顺序都不变。

NMS阈值由相同干净历史的前5帧通过官方路径预热得到，再冻结给干净和污染配对。默认NMS保持开启。目标相机最后一帧决定此次检索；不扩展成轨迹生成。

## 因子和评测

2场景×3种子×2分辨率×2目标位置×2污染类型×4强度=192个配对配置。干净对照会复用，不能当成192个独立场景。两种分辨率等比例缩放焦距和像素尺寸以保持视锥；逐种子记录是否跨分辨率重复，防止只看到单像素边界效应。

主结果：候选集合改变率、最终帧集合改变率、有序索引改变率，以及空候选/异常。报告14/15名的权重差和位姿距离最小差，不隐藏并列条件。

辅助结果：使用干净目标渲染和原始来源关联，计算选中帧能够支持的可见像素占比。它只衡量这个人工场景中的干净参考覆盖率；共用renderer，不是独立真实几何真值。覆盖率下降不等价于生成视频质量下降。来源的定义基于点中心投影，没有完整真实图像边界处理。

若权重变而最终选择不变，记录负结果。如果只在大扰动或某一分辨率上变化，限定到相应边界，不扩大为“小误差普遍有害”。后续需要原版完整清理、实际估计数据与真实图像，才能判断自然发生频率和生成影响。
