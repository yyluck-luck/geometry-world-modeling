# S4独立CUT3R两帧测量诊断协议

此协议在完整检查点下载完成和任何真实模型输出产生之前记录。实际冻结时间与文件哈希写入research_events.jsonl。S4是S3之后的新探索性诊断，不回写S3主结果，不是完整VMem复现或跨场景benchmark。

## 输入与范围

输入沿用此前固定的TUM freiburg1_xyz两张RGB，来自S2 qa_indices的前两个[0,34]，不可看结果后换图。RGB时间为1305031102.175304与1305031103.475274，来源/哈希见data/cut3r/inference_inputs.json。模型为独立官方CUT3R提交8bc15dc92a6d7fd92920b4ec81540d3dec7d3ecf、224 linear中间检查点；不是最终512模型或VMem fork。

先CPU FP32两图顺序推理，再相同输入MPS。原始点图、位姿和置信度由模型runner原样保存。设备数值一致性与几何测量评分分开。模型只读RGB，不读TUM深度或位姿。

## 对齐规则

按照固定官方load_images的224分支，640×480先缩成299×224，再中心裁成224×224，左上裁剪坐标(37,0)。RGB用官方LANCZOS（缩小），深度和有效性掩膜用相同尺寸/裁剪的最近邻重采样，不做深度插值。有效深度要求原图2像素邻域（5×5）均正且有限，各邻点与中心深度差不超过50mm，原图外圈2像素无效。模型点图有限且Z>0才可评分，单列预测覆盖。不根据置信度挑选像素。

线性head把pts3d_in_self_view通过解码camera_pose变换成pts3d_in_other_view，因此自视点图Z用于相机深度比较，camera_c2w用于相对位姿。必须在真实输出中核对该代数关系、旋转正交性与正向深度比例，失败时记录失败，不擅自翻轴修正。最终运行实际head必须为linear。

仅用CPU第一帧的正值预测和有效测量计算一个尺度s=median(z_measured/z_predicted)，至少100个像素，否则判为不能评分。冻结这个尺度后，对第二帧做唯一的留出深度评分；第二帧测量不能参与尺度、偏移、姿态、阈值或像素选择参数的拟合。不拟合平移偏置或旋转。第一帧分数仅标为校准后描述性分数。保留未缩放深度作单位假设下的对照，不能称已证实的米制误差。

## 预定输出

第二帧报告共同有效预测数量/比例、绝对深度差mean/median/p90、signed mean、30mm内比例和AbsRel。大误差全部保留。S4的深度是密集自视预测对已裁剪测量，不能与S3稀疏投影分数直接比较。

位姿采用RGB图像时间的mocap插值（无外推、最大间隔0.1秒），不同于深度关联时刻。预测相对位姿为inv(P0)@P1；其平移乘CPU第一帧拟合尺度，与inv(G0)@G1对比。记录旋转角误差、平移向量误差、GT相对位移与角度。一次位姿转换只描述这对图，不能算轨迹benchmark。RGB与最近关联深度的时间差同时报告，静态注册深度不补偿运动。

如果MPS真实推理完成，沿用CPU第一帧尺度，对相同输入/掩膜评分。不得为MPS重新拟合尺度来掩盖设备差异。记录CPU/MPS原始数组比较结果；若不满足已有atol=rtol=1e-3，明确写不通过，即使两者推理均生成有限输出。

全部评分使用保存的predictions.npz并验证哈希、输入顺序、形状和检查点身份。记录协议、评测源码和源文件哈希、真实起止时间。不得把一对图的好坏、校准后低残差或CPU/MPS一致性推广到长序列、完整VMem或生成视频。
