# S14C结果：粗略的四图分散指标没有通过预定方向检验

**预定的有限命题被本次结果推翻：主分散量与选图支持损失，没有在两个已有场景都呈正相关。** S7的Spearman相关为−0.3043，S8为+0.0591。本轮已经真实提取、封存后联结原评分，并由不同公式与秩算法核验通过；不是人工模拟出来的效果。

这不是在证明所有几何一致性方法无效。被检验的只是一个普通代理量：两套既定四图在共同历史记忆点上的预测分散差。它没有考虑当前目标像素的可见性或遮挡，也没有生成新的选图或视频。

## 白话解释

G是原来源14候选选出的四图，P是按相机位姿（位置与朝向）选14候选后得到的四图。x>0表示G的预测更分散；y>0表示G的真实支持比P更差。原计划只问：x越大时，y是否通常也更大？相关系数越接近+1，排列越同向；接近−1表示反向；接近0只说明这个样本里的排列联系弱，不能证明总体无效。

两个场景分别有12个已见且相关query，并非12个独立场景。没有计算p值、显著性、置信区间、风险保证或跨场景混合rho，没有拟合/翻转符号去追求正结果。

## 共同域与完整性

24行都可计算，没有被丢弃的query。各query共同点数269–577，占相应地图点数8.2062%–26.9859%。共同域要求G/P各自至少两个来源帧，因此它是有条件的子集，不表示覆盖了全部目标画面。所有25格来源数计数、两端eligible和三种覆盖率都在point_details/rows中保留。

实际计算访问64,656次地图点、10,743次共同点、60,435次来源pair，复用288条已存相机pair距离。它们是访问次数，不能叫新照片、独立点或独立样本。
