# S8：新环境的固定观测机制验证

本协议在S7已知结果之后、fr2/desk压缩包下载和新图片/模型结果读取之前制定。先冻结本文件，再按其确定性规则生成输入清单；执行源码与清单另行冻结。冻结记录只证明本项目的时间先后，不声称第三方注册。本轮使用已读的Supervisor-Skills评测设计与本地Claude科学批判思维skill，具体落实为前瞻采样、成对干预、混杂与失败记录；不调用Claude模型。

## 研究问题及边界

检查S7的条件性机制在另一个真实环境是否出现：固定关联路径的位置更新能否改变参考选择；固定位置规则时，关联路径能否改变选择；同一候选集的NMS是否改变选择与参考支持。三者可同时成立，不强求效应正向或重复原数值。A因素同时涉及点分区、点数、出生属性和来源，不能说是纯来源标签因果效应。

唯一预定场景为TUM `rgbd_dataset_freiburg2_desk`，官方包1893351095字节。原论文确认相对fr1/xyz是不同物理环境、不同实体Kinect；仍是同一数据集及同类设备。未核实模型预训练是否接触此数据，因此“外部”指本次实验开发之外，不声称模型训练未见。地点与设备共同改变，不能分离二者效应。来源与许可见S8_DATA_SOURCE_REVIEW.md/json。

## 先看时间表，按规则取图

RGB/depth最近时间关联沿用 `tum_rgbd.associate_rgb_depth` 的一对一确定性算法，差值严格小于0.020秒。先只解析三个文本列表的时间戳、文件名和行结构，不解码图片，不解析GT的位置/四元数数值。GT相邻时间差大于0.100秒即断开，禁止跨断点或范围外插值。每个入选配对的RGB与depth时间都须落在同一连续GT区间；评分位姿仍取RGB拍摄时刻。

执行顺序固定为完整RGB/depth列表先关联，再按GT时间支持删除配对，不对剩余列表重新匹配。关联候选按绝对差、RGB时间、depth时间排序贪心接受。GT时间戳先排序，非有限、重复或非8列行报错；连续区间为闭区间，孤立GT时刻只支持精确同一时刻。注册深度作为对应RGB的深度观测，不额外做RGB/depth异步运动补偿；最多20ms不同步是沿用测量代理的局限。

合格配对按RGB时间排序；相邻RGB差大于0.100秒或GT区间身份改变时分段。只考虑单一连续段内的固定8.840秒窗口。此长度匹配旧fr1每块约8.836秒的时间跨度；不把99秒新序列均分成三个长窗，以免大幅改变输入间隔。每窗24个等距目标时刻（含两端），各选最近的合格配对，绝对时间差并列时选更早RGB，误差最多0.050秒，24图必须互不重复且顺序严格递增。

最近配对的候选来自该整个连续段，因此最后一图允许位于名义终点之后最多50ms；名义窗口间的100ms间隔仍保证实际取图不重叠。超差或重复直接拒绝该窗口，不找次近图补位；所有比较使用记录的双精度时间值和字面阈值，不额外加数值容差。

确定性窗口算法：逐段、逐RGB时刻尝试作为起点；终点须不超过该段最后RGB。第一个符合上述条件的窗口入列，随后跳过起点不大于该窗名义终点加0.100秒的候选，继续同一规则，得到按时序排列的不重叠窗口。若总数N至少3，取索引0、floor((N−1)/2)、N−1作为B0/B1/B2。若不足3个，保留元数据失败，不改规则、不换序列、不读取图片或运行模型；另立可审查修订后才推进。

全72张RGB与72份depth分别核路径、时间、文件字节SHA及唯一性。保存全部候选窗口、选中索引、目标与实际时刻、实际间隔分布、三个文本文件SHA、包SHA。先冻结清单，后做72张RGB尺寸/格式QA；不得因画面或分数换图。图片损坏、尺寸不符、轨迹无效、缺测或资源失败均停止并保留证据。深度像素只在全部选择封存后的评分阶段解码；输入阶段仅核字节完整性。

三个新块全部test，前20历史、尾4只读查询，共12张不同查询。不得用新块调参。它们在一个环境内相关，不是12个独立场景；与旧fr1的8张测试图分开汇报，不把条件数当样本数。

## 预测、记忆与读出

沿用未改S6模型runner、已核验权重/上游提交/CPU8线程/seed0。每块独立新进程24RGB，history update=True，query update=False，reset全False。核4组flag记录和两个潜在状态字段×4查询的运行内不变审计；状态原张量未保存时，不称独立张量复算。每块900秒、16GiB采样RSS软预算；失败保留，不降低图数或改阈值续跑。

沿用S6预测self-Z、预测pose及已知裁剪K重建几何，首图预测中位数归一化，不用测量尺度选图。K为官方推荐近似(525,525,319.5,239.5)，RGB640×480→299×224→裁剪224；最终K沿用已核代码。深度除5000，0缺失；已含fr2的1.031修正，不重复修正，不额外去畸变。

完全复用未改S6 surfel与S7 observation/event/replay/decision函数。主stride8、敏感性12，width160、K=4、姿态距离平移权重0.1、原NMS阈值/并列排序语义不变。A0首写关联、A1在线平均关联；P0首写位置、P1等贡献帧质心递推平均。四图A0P0/A0P1/A1P0/A1P1。同一路径的非位置属性和来源严格固定；对角重放必须逐值复现本轮直接记录地图，不能比较不同场景旧地图。保留每个(frame,u,v)观测、逐帧事件、build trace、全部地图与来源。

四种读出：原official；同一展开候选去NMS且不强塞末帧；全20候选加原NMS；全20候选不加NMS。独立decision trace必须严格等于official选图，四种均4个不重复历史ID；全候选控制在四图间相同。保留96次原渲染输出、384条完整决定，不能把384条称384个独立查询。

## 封存后评分与完整报告

全部6个案例的预测选择及地图/事件/渲染文件SHA封存后，才解析GT位姿、解码测量depth、拟合每块首图单一尺度。输入采样已用过GT时间戳；所以准确表述为“选择不访问测量深度及GT位姿值”，不能笼统说从未访问GT文件。每块24测量图、有效mask、插值GT位姿及归一化首图保存以供独立核验。

测量目标、5×5有效深度筛选与50mm门限、RGB时刻GT插值max-gap0.1、112栅格投影、20历史的测量支持完全复用S6函数。主指标为每张查询所选4历史对有效目标的联合测量支持率。按3块分别列4图支持，再报12查询算术均值；stride8/12分开，旧场景单独列出。原S7主位置效应A0负/A1正及稀疏抵消作为待验证观察，不将同方向当筛选条件。

预定比较：P在A0/A1下、A在P0/P1下的配对支持差（百分点），以及差中之差；每项列逐查询值、块均值、总均值、升/降/不变数、集合/顺序变化数。支持用逐像素整数计数计算，数值绝对差≤1e−12视为数值相同；不以任意“足够大”阈值包装阳性。H1/H2是否出现选择变化按集合与顺序分开；支持不变但换图也完整记录。H3比较同图official与candidate_no_nms，以及全候选两控制。无显著性检验或独立样本置信区间。

若某固定干预在全部12张查询均不改集合及顺序，报告“本场景设置未重复该选择变化”；若只顺序变，明确报顺序变化而非集合变化。效应反号照实列出，不改以支持率或其他读出替代原比较。单环境12查询的零变化不证明普遍不存在，阳性也不证明普遍成立。

“任意条件作用存在”和“S7具体模式重复”分开判定：主stride8对12查询平均的P效应是否仍A0负、A1正，另列逐块符号，不以任意非零替代同符号模式。stride12只检验预定路径A0P0→A1P0→A1P1：起止有序ID相同且中间有序ID不同，起止支持数值相同而中间不同，报告同时满足的查询数及全部不满足项；不另挑路径制造抵消。跨场景cadence近似相同不等于运动幅度或可见重叠相同，因此不能将结果变化只归因于地点。保存每块RGB−depth时间偏移和实际RGB间隔分布。

辅助几何报四图共同mask逐查询MAE/中位数/p90、共同有效比例与像素数，以及每图自身覆盖和误差；两图对角共同mask单列，不混同四图结果。零有效目标停止评分，零共同像素记为缺失并报数量，不挑图或改mask。低支持、几何更差、零变化和反向结果全部保留。参考支持是组件代理，不是生成视频质量，也不证明新算法普遍优越。

运行后独立重算原PNG/GT的测量支持与保存选择/投影，并核事件重放及完整读出。审查范围、实际检查数和未重跑步骤明写。未通过核验只报暂定结果。全部旧S0–S7及原proposal/draft保持历史快照；只写新S8目录，修复后使用新输出目录。
