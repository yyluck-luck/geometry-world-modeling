## 必须修正：把独立预测误当成代数恒等式

原协议写“线性 head 把 self 点图通过 camera_pose 变换成 other 点图”，`evaluate_cut3r_pair.py:48–51` 因此要求 `other ≈ self @ R.T + t`，不满足即中止。

实际官方路径如下（路径相对于工作区 `work/cut3r-local/`）：

- `src/dust3r/heads/__init__.py:26–27` 将 `linear + pts3d+pose` 路由到 `LinearPts3dPose`。
- `src/dust3r/heads/linear_head.py:318–321` 从 self 分支产生自视点图；`:337–344` 则从独立的 `cross_proj` 和 `postprocess` 产生 other 点图。
- 同文件的另一类 `LinearPts3dPoseDirect` 才在 `:227–233` 对 self 点图调用 `geotrf(pose_encoding_to_camera(...))`。当前 factory 没有选择该类。
- 静态检查点预览中的模型定义确为 `head_type='linear', output_mode='pts3d+pose'`，不是 Direct 类的显式实例。

因此，自视点图与 other 点图之间的差异可以作为额外的模型自洽诊断，必须保留其残差；不能作为理应为零的接口断言。该残差也不是测量几何误差。修正应保留原协议哈希，并记录这是由源码核对触发的运行前更正；不得等看到输出后放宽阈值或翻轴。仍可按预定规则分别评分 self Z 与 camera pose。

`LinearPts3dPose` 对 self 分支设 `pos_z=True`；`heads/postprocess.py:127–129` 会根据 Z 的符号翻转点坐标。因此正向 Z 比例主要是结构与数值检查，不能用它单独证明相机约定或几何预测正确。

## 已确认自洽的部分

**尺度与留出。** `first_frame_scale` 只接收 CPU frame0 的预测、测量与固定有效性掩膜，计算正值测量/预测比值中位数，至少 100 像素。第二帧仅进入固定规则生成的目标与评分；没有第二次尺度拟合，也没有平移或旋转对齐。MPS 直接使用同一 CPU 尺度。第二帧按预先规定的测量有效性与深度边缘规则生成评分掩膜，是定义可评分测量的条件，不构成拟合泄漏。

**裁剪。** 官方 `utils/image.py:65–72,99–111` 的 224 分支先按整数舍入缩放，再中心裁剪。对于固定 640×480 PNG，`crop_geometry` 得到 299×224 与 `[37,0,261,224]`，与官方一致。深度 float32 图和 uint8 有效掩膜使用相同 PIL NEAREST 几何操作，避免深度值插值；原生 5×5 检查排除无效测量、外圈 2 像素和大于 50 mm 的局部深度变化。原图大小、EXIF/方向与这两张固定 PNG 的读取方式没有发现冲突。

**相机约定。** 官方 `utils/camera.py:350–351` 明确编码为 OpenCV cam2world；`:396–420` 解码为该矩阵。使用 self 点图 Z 作为相机轴向深度，使用 `inv(P0) @ P1` 消除预测世界坐标的共同刚体自由度，并将其平移乘第一帧测量尺度，逻辑正确。TUM 使用 RGB 时刻 mocap 插值计算 `inv(G0) @ G1`，没有误用加载器默认的 depth 时刻 pose。旋转误差由相对旋转迹计算，平移向量在第一相机坐标系比较，均正确。

## 可声称范围

这是一对提前固定图像的测量诊断：第一张提供一次测量尺度校准，第二张提供一张留出深度图和一次相对位姿变化。它能描述尺度从第一帧迁移到第二帧后的测量一致性，不能证明零校准米制精度、跨场景泛化、轨迹精度、完整 VMem 或生成视频质量。第二帧与第一帧处于同一短序列且可能观察重叠表面，“留出”仅指第二张测量未参与拟合，不是独立场景测试。

有效性与边缘规则会偏向可测的局部连续表面，应同时报告有效目标数量、预测覆盖和全部预定残差，不据此概括整张图或遮挡边缘。CPU/MPS 共用测量掩膜，但 `valid_prediction` 还分别过滤各自非正预测；若两个最终有效预测掩膜不相同，设备评分分母不同，应明确报告或附共同掩膜诊断。原指标无需更改。

深度是 Kinect 测量；mocap 才是该数据集提供的位姿参考。相机标定、配准、采样与时间关联误差都会进入诊断。S4 密集自视预测分数不能与 S3 稀疏点投影分数直接比较。当前审查不报告任何真实模型效果，也不宣称上述必修问题已经被主任务修改。
