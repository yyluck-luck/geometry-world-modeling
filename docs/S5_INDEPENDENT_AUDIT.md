## 独立实现与检查范围

独立脚本仅使用 NumPy、PIL 和 SciPy 及标准库。原始 uint16 深度除以 5000 转米；在原图通过切片逐个检查 5×5 邻域，要求测量均为正且与中心相差不超过 50 mm，并排除外侧两像素。随后分别以 NEAREST 将深度和固定有效掩码缩放为 299×224，裁剪 `[37,0,261,224]`。72 张重建目标深度及掩码与归档 `measurement_comparison.npz` **逐值完全相同**。

三个尺度独立计算为各块首图有效实测深度与正预测 self-Z 比值的中位数；后续 23 帧不参与尺度拟合。逐图原始和校准后的指标全部重算，并与 JSON 和 72 行 CSV 对照。数值检查使用绝对容差 `1e-7`、相对容差 `1e-9`；角度允许 `1e-5` 度的数值差。此角度容差覆盖独立线性求解与原矩阵求逆在接近零角度时的舍入差，不改指标或筛除帧。

参考轨迹从原 `groundtruth.txt` 独立解析、排序、归一化四元数，并在 RGB 时间做平移线性插值和 SciPy Slerp。禁止外插，插值区间不得超过 0.1 s。相对变换通过 `solve(P0, Pt)` 与 `solve(G0, Gt)` 独立计算，预测相对平移乘该块首图尺度；没有使用后续真值拟合旋转、偏置、尺度或轨迹。全部 72 帧的相对矩阵、旋转差和平移向量差均核对通过。

## 分母、泄漏与可解释范围

72 张图由 3 张校准图和 69 张非校准图组成。主测试 8 张、开发尾部 4 张都已包含在 69 张中，不能相加得到更多独立样本。504 是模型输出数组数，4,516 是程序检查数，都不是科学样本数。三块来自同一个约 26.59 秒环境片段，块内相邻图像与像素高度相关；不能据此声称三个独立场景或统计显著性。

模型仅接收 RGB 和规定的占位输入，没有接收实测深度或参考位姿。每块独立新进程初始化，但块内状态沿时序保留，测试图的 RGB 会参与估计，后一张测试图可利用前一张测试图的 RGB 状态。因此这是后续测量未用于拟合的序列几何诊断，不是排除了查询 RGB 的记忆检索实验，也不是预测未来不可见图像。

所有图的预测覆盖率为 100%，其分母是**已经通过深度有效性和边界筛选的目标像素**。各图目标有效数为 32,864–41,680，而裁剪图共有 50,176 个像素；100% 不能解释成整图都有正确深度，更不能作为准确率。深度结果是与 Kinect 测量的一致性，位姿是与插值后的运动捕捉参考轨迹之差，仍受标定、RGB/depth 时间偏移及测量噪声影响。

点图与位姿由不同预测分支给出，二者共用首图深度尺度是冻结诊断假设。没有通过所有后续深度或轨迹再次优化该尺度，因而没有发现这一路径的后续测量泄漏；同时不能把其误差解释为完成完整几何对齐后的三维重建精度。

S4 单对图的第二帧 MAE 约 32 mm，S5 主测试约 72 mm，样本和序列条件都变了，不能直接归因于序列长度或“记忆漂移”。本次结果也不是随时间单调恶化：例如 B2 最后 4 帧的 MAE 均值为 66.396819 mm，低于该块全部 23 张非校准图的 120.840453 mm。若要区分时长、相机运动、场景内容和状态的影响，需要另行冻结在相同查询图上改变历史长度或状态的配对实验；本次不追加此因果结论。

参数、外部输入与保存输出为 FP32，但官方 encoder RoPE 内部包含 FP16，详见 [精度澄清](S5_PRECISION_CLARIFICATION.md)。signed-RoPE 与阻塞输入搬运属于已记录运行适配，本次结果不是未适配的全 CUDA 上游路径。独立复算没有发现数字或计数错误，保留这些执行与科学范围限制。
