# S16：已见数据的固定来源干预协议

本协议在S16真实计算前固定，但S15B目标20–23的答案及成绩已经公开，因此是**已见数据、已知答案的机制解释**，不是独立确认、部署策略或新模型推理。阅读并继承 `S15B_PREFIX_PROTOCOL.md`、`S15B_CONSUMER_PROTOCOL.md`；不改照片规则、提案、来源、标定、尺度、裁切、目标或评分阈值。文献约束见 `S16_CAUSAL_INTERFERENCE_FEASIBILITY.md`。root负责封存清单、运行、日志和结果解释；独立子任务只读文本/既有JSON并核验人工数组。

## 1. 一个问题与不可越过的结论边界

**固定世界模型给出的旧、新几何及允许的照片规则时，某一来源更新在单独使用或其他来源不更新时改善目标深度，却在其他来源同时更新后使聚合成绩变差的情况是否存在；各类目标像素对这种变化的贡献如何？**

这不是“z-buffer是否非线性”的新问题。非加性是已知算子的数学性质；本轮最多给出本段保存数据上的反向实例、大小和分布。三类像素是空间记账，不是对真实遮挡的三个独立因果干预。单来源投影准确性也不等于原来源视角的真实深度准确性。若没有反向证据，必须明确不支持本段上的有害上下文解释。

## 2. 完全固定的输入和图层

- 四来源次序为0、3、6、9，对应位掩码bit0、1、2、3；四目标依次20、21、22、23。
- 六policy全量报告：`all_new`、`half_blend`、`pool_new`、`split_new`、`matched_absolute_new`、`model_confidence`。加共享`never`用于基线和重建。不能只保留产生最大效应的policy。
- 使用S15B保存的共同来源有效域，即old和new均有限且正；给定source/target c2w、K、12帧标定A/s/c及rule masks全部冻结。K仍为224网格的 `[[245.2734375,0,112],[0,245,111.5],[0,0,1]]`。尺度取保存的完整精度 `scale_model_per_meter`，不从报告四舍五入数值重建。
- 来源相机为S15B规定的RGB时刻；目标相机为对应depth时刻。目标位姿是既有给定输入，不是新预测。没有新照片、sensor PNG解码、训练或模型调用；现有已评分depth NPZ用于答案端诊断。脚本在重建门前读该已见GT是允许的，不能称GT隔离。
- 对每`method × source × target`生成一张单来源图层：同S15B pinhole投影，target-z有限且正、`floor(u+.5)`及`floor(v+.5)`在0–223内；每格取最小target-z，再以source-pixel身份破同深度并列。身份=`source_ordinal*224*224 + row*224 + col`。图层为**模型单位**的target-z；missing=0，identity=-1。
- 合成时对四来源图层取同样最小target-z，完全并列按来源次序；图层内部已按raster身份排序。得到整张图后才统一除s成米。不可先把各层缩放成米再比较，不引入填洞、splat扩张、置信删点或GT调整。
- 保存全部七方法的`source_layers.npz`，每个方法有`(4source,4target,224,224)`深度及身份。图层缓存的两级min与原一次性min必须数值完全一致。

## 3. 强制重建门

在解释任何S16统计前，七方法×四目标共28张米制预测与S15B封存 `consumer_predictions` 逐元素`array_equal`，获胜source-pixel身份也逐元素完全一致。无需放宽容差。任何失败立即保留FAIL回执并停止解释，不修正既有预测来迎合诊断。

此门验证沿用同一消费者；它本身不是新算法证据。读取GT已经发生不能用此门倒述为先封新预测后看未见答案。S15B另一个实现的独立验证结果由root另行引用，本子任务不把读过JSON等同于复跑实数据。

## 4. 十个来源子集及计分

每policy只计算十个预设子集：`[0,1,2,4,8,15,14,13,11,7]`。分别为旧基线B、四个仅改一个来源、四来源全改joint、四个joint-minus-i。被选中的来源应用该policy本来决定的完整source mask，其余来源完全保留旧图层；`half_blend`的处理是该来源应用固定半混合。

这些是十个选定干预，**不是16种组合的全因子实验**，也不识别每个两两交互项。

对目标t，`G_t`是S15B全部有限正GT像素，`N_t=|G_t|`，所有子集/来源/类别共用该分母。已保存的米制GT继承原 `/5000 → nearest299×224 → crop(37,0,261,224)`；本轮不重新解码或变换GT。每像素命中函数：预测有限且正，且 `max(pred/gt,gt/pred)<1.25`；缺失算失败。

```text
h_t(S,p) = 上述0/1命中；C_t(S)=sum_{p in G_t} h_t(S,p)
F_t(S) = C_t(S) / N_t
F(S) = (1/4) sum_t F_t(S)          # 主汇总：四帧等权
J_t = C_t(joint) - C_t(B) - sum_i [C_t(only_i)-C_t(B)]
I_t = J_t / N_t
I = (1/4) sum_t I_t
```

保存每子集的整数correct_counts、GT覆盖整数数、逐目标δ1及四帧等权均值，并保留全部N_t。不得把按像素池化的比值冒称四帧等权。`J_t`为精确整数，`I_t`和I仅用于归一化；I包含所有二阶及以上交互的合计，不是纯二阶系数。负I可能只是两个来源重复取得相同收益，**不能直接等同于有害干扰**。

## 5. 来源边际与反向效应

对每policy、每来源i、每目标t，同时保存：

```text
solo_i = C_t(该来源policy单层) - C_t(该来源old单层)
single_i = C_t(only_i) - C_t(B)
joint_i = C_t(joint) - C_t(joint-minus-i)
```

三者都除同一个N_t形成逐帧量和四帧等权均值。单独层没有其他来源，但仍含来源内部的投影/竞争与缺失，故solo不能代表模型本身的源像素真值误差。保存solo_old及solo_new各自整数命中数，以便复算。

`single_i>0, joint_i<0`是最直接的“其他来源也更新后，这次更新变有害”实例；反向方向也完整记录。程序固定`single_i*joint_i<0`为严格符号翻转，0不算翻转，逐目标及四帧均值分别判定。报告同时保留原始整数差，以免单一汇总隐藏方向不同的目标。`solo_i>0,single_i<0`说明旧竞争环境中出现损害，是不同上下文；可由保存数字解释，不后调阈值。

这些符号翻转是整张目标/四帧聚合的翻转，**不得写成同一目标像素的边际正负翻转**。固定某来源的old/new两个深度，在min-z与单个δ1正确区间下，其他来源只会激活或抑制该像素原有方向的增量；不同像素的正负量相加后才可能翻转。人工例A的逐像素single为`(+1,+1,-1)`，joint marginal为`(0,0,-1)`，聚合才从+1变−1。反向效应在该已见段存在仍不证明稳定普遍规律；四帧/相邻像素不可当独立重复进行伪精确显著性检验。

## 6. 每policy自己定义的三类互斥像素

对**该policy自己的old/policy全部四来源图层**比较；不共用某个较有利policy的分区，也不用GT数值选择类别。按以下优先级决定目标像素类别：

1. `coverage_change`：至少一个来源的图层valid状态在old/policy之间翻转。
2. `source_pixel_routing`：四来源valid状态全部未变，但至少一个来源层的获胜source-pixel identity改变。
3. `fixed_candidates_depth_competition`：四来源valid及每来源获胜identity全部未变。

第三类代码名沿用实现，但它包含无竞争和全空位置；名称不证明每个像素都发生竞争。只有这一类的非零交互贡献才是固定来源候选身份条件下的非加性证据。第一、二类也可能同时存在深度竞争，不可称互斥的物理根因。

令逐像素整数 `j_t(p)=h_t(joint,p)-sum_i h_t(only_i,p)+3h_t(B,p)`。每类保存`|class ∩ G_t|`及 `sum_{p in class ∩ G_t} j_t(p)`；归一化仍除**全量N_t**。三类整数贡献应逐目标精确相加等于J_t；保存三类bool map和j map，报告正负贡献可能抵消，不把类别像素量等同于有害像素量。

## 7. 冻结旧赢家来源：精确零交互负对照

对每目标像素，旧baseline的获胜**来源**为owner(p)。所有子集都只能使用该来源当前old/policy层的数值；允许该来源内部pixel identity随更新改变，**不固定旧source-pixel**。若该来源变invalid，输出missing；即使别的来源有点也不回退。若基线无owner，该像素始终missing。

因为每目标像素最多依赖一个来源的开关，逐像素必有 `j_frozen(p)=0`；这不是经验假说。脚本必须在所有像素、所有六policy上检查精确整数零，不只平均接近零。保存全部十子集的frozen correct_counts、逐帧δ1和等权均值。失败意味着实现/身份/尺度/缺失语义错误，停止真实机制解释。

这个反事实渲染器移除了跨来源赢家切换，也抑制了从无到有的覆盖，因此不是可部署替代算法，不能据其成绩声明性能改进。

## 8. 执行、前审与停止规则

root运行 `scripts/s16_source_interference.py`，其CLI为 `--manifest ... --manifest-sha256 ... --output ...`；必须fresh output、600秒墙钟上限、8GiB资源约束。复用S15C相同进程内监控方式：600秒signal、每0.1秒RSS监测和完成时资源检查；这是进程内保护，非操作系统硬隔离，不能保证监测间隔内绝无瞬时超限。manifest绑定实际Python执行文件、协议、报告、脚本、全部输入及此前预测身份，执行前后核SHA。任何改实现保留原快照、重新前审/封存，不覆盖失败。

独立最小人工检查为 `work/S16_preparation/check_interference_artificial.py`，直接import并调用实现的`classify/compose/diagnose`；不调用`main/layer/load`，不读取实图、GT或NPZ。手算例预期每目标`J=-2`、`I=-2/3`，来源A的single +1而joint marginal -1；frozen J=0。另检三类分区、owner失效无fallback和no-op。此PASS只核软件数学，不是实数据结果。

解释门按顺序：28预测/身份exact重建；全部冻结owner逐像素零；三类精确可加；原始counts可复算；再读完整六policy结果。若只有I非零却无single与joint方向反转，只能报告重复或协同收益的非加性；若固定候选类无贡献，不支持“固定投影身份下的竞争”解释；若效应仅来自覆盖/路由，按其现象记录，不把普通光栅变化包装成新物理结论。S16不训练策略，不用已见GT挑policy、阈值、来源或下一段的胜利指标。
