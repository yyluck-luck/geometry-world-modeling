# S6冻结协议：学习深度接入历史记忆与参考选图

S6是已看到S0-S5后的新组件实验。它检验真实学习深度/位姿进入记忆后，两种位置更新规则是否改变最终参考图及其测量支持。本协议在S6新推理、建图或选图结果之前冻结；不重写旧实验。来源设计审查见S6_BRIDGE_DESIGN_REVIEW.md。

## 固定模型与留出

复用S5的三个固定24图块，RGB路径/顺序/hash保持data/cut3r/S5_inputs.json不变。模型/权重/已审查signed-RoPE与blocking输入搬运不变，参数/输入/输出FP32，保留官方encoder内部FP16 RoPE。CPU 8线程、seed0，每块新进程，16GiB软RSS预算。

新入口单独命名，不修改原run_cut3r_local.py或S5结果。每块frame0-19 update=True，frame20-23 update=False，所有reset=False。当前查询RGB可用于其自身几何/位姿估计，但不写回持久state_feat或pose-memory。保存每帧flags与实际状态检查，要求末4次的两类状态有限并逐值等于第20历史帧完成后的状态；任一不满足则失败。历史20图原始输出与S5按事先atol=rtol=1e-3比较，不更改容差。

三块24图全部保存，不择例。仅0-19进入显式surfel记忆；20-23只能查询。每次查询前后核对记忆全部位置、法向、半径、颜色、counts、来源关联的哈希，要求不变，来源ID范围严格0-19。

## 主支路的坐标与尺度

只使用模型self_view正向Z、conf_self、预测camera_c2w及已知TUM相机标定。self XYZ的X/Y被针孔反投影重新构造，raw other不进记忆。没有VMem 512 DPT、星形全局优化或跨视图clean，不能称完整VMem基线。

模型单位先纯预测归一化：n=1/median(first_self_Z的全部正有限像素)，本块所有Z与相机平移同乘n。相机相对姿态Q_i=inv(P0)Pi，其平移乘n，旋转不改。首帧相机坐标为记忆坐标。建图、阈值、选图、NMS不得读取实测depth或mocap；不得复用S5的实测校准比例。这一轮不运行GT姿态oracle或测量输入条件。

K_crop使用像素中心变换：fx=525×299/640=245.2734375，fy=525×224/480=245，cx=(319.5+0.5)×299/640-0.5-37=112，cy=(239.5+0.5)×224/480-0.5=111.5，视野224×224。RGB采用官方LANCZOS裁剪；depth使用模型224输出，无额外上采样。该K是已知固定标定，不由测试depth拟合。

## 固定记忆构建和对照

3块×2采样间隔（8主、12敏感性）=6案例，各比较first_write和frame_mean，共12地图、24实际条件查询、48查询×检索宽度配对记录。实际相机查询仍是12张，主测试B1/B2的8张；重复分辨率/采样条件不是新增独立样本。

采样网格从像素(0,0)开始，每隔8或12像素取点。法向取相邻原224像素的右/下射线点差之叉积，向相机到点方向翻向。正有限Z与右/下邻居必须有效，原224相邻Z跳变≤0.05归一化单位；法向长度>1e-12。conf_self有限且≥1，历史每帧自身正有限Z的0.999分位作为远端上限，先将未通过中心/邻居筛选的depth标无效后构造法向，记录逐类剔除数。无测量误差剔除，无人工扰动。半径沿用S3足迹公式：0.5×Z / (mean(fx,fy)/stride) / (0.2+0.8×|cos|)。

匹配复用S3已核验单叶语义：cKDTree精确候选按索引排序，首个位置距离≤当前所有旧/新半径mean+0.5std、法向点积>0.6者合并。一帧内冻结旧树/位置，新点不与同帧新点匹配。frame_mean对匹配到同一旧点的本帧观测先取质心，再与历帧各一票平均；只改位置，法向/半径/颜色保持初值。first_write保留位置，只增加来源。两种方法的未来匹配可以不同。调用的Memory记录中原_m字段重命名为_normalized，避免把无量纲单位叫米。

## 完整选帧与控制

仍调用固定VMem的完整get_context_info路径，k=4、translation_distance_weight=0.1（此处平移已归一化，不是米制权重）、NMS开启，初始阈值从本块前5预测姿态的同一距离分布固定。两种记忆共用阈值。渲染网格160×160主、320×320敏感性，已知裁剪K按宽度/224缩放；原路径的surfel标量focal用mean(fx,fy)×width/224，保留其内部0.65拓宽和居中主点近似。不能沿用S3写死640×480的初始化。

保存候选、权重、最终4ID、覆盖和耗时；ID无重复且仅0-19。辅助控制recent4={16,17,18,19}、normalized预测姿态nearest4（相同距离，无NMS），以及全部20历史的支持上界。所有ID先保存并封存，之后才读取测量depth/GT做评分。

## 与选择隔离的测量评分

评分阶段重建TUM S4掩码：原640×480深度5×5全有效且差≤50mm，外边2像素无效，然后depth/mask按NEAREST变为299×224、crop[37,0,261,224]。目标取每隔2像素（0,2,4...）的112×112网格。各RGB时刻GT位姿SLERP、间隔≤0.1s，不外推。

参考支持mask：在相同预定有效目标点上，用GT投影到每张历史裁剪图，最近像素np.rint且必须在范围并通过其测量有效mask，预测到该历史的Z与其测量Z差≤50mm才算支持；只用于评分。每组4个已封存ID取支持并集，除以固定有效目标数；记录recent4/nearest4/all20，支持变化用百分点。换帧本身不等于更好/更差。

几何描述：只在选择完成后的评分副本，用首图预定有效像素median(measured_Z/normalized_pred_Z)拟合一个比例c，将记忆点乘c并由首帧GT姿态放到世界坐标，再投到各查询GT。不使用query depth拟合/对齐，不回写记忆。点中心投到112网格np.rint，nearest-Z buffer；两种记忆都预测且目标有效的共同像素作配对MAE/median/p90/signed/30mm内指标，同时报告自身覆盖与共同像素数。格内同投影不保证同物理表面，保留大残差。没有ICP/全轨迹对齐。

主汇总仅B1/B2、stride8，8个实际查询，分别报告160/320选图变化、支持变化、主几何均值与覆盖。stride12和开发块单列，不用p值/置信区间，不把条件数当独立场景。完整保存6案例、原始地图、所有查询投影、逐帧写入记录、来源与哈希；独立复算所有支持与深度结果。
