# S0b：首次运行后的诊断补充

本补充在 S0 结果产生后写入。S0 的 CSV、JSON 与协议未覆盖；初始代码和配置保存于其结果目录内的 `reproduction_source.zip`。S0b 不能称为事先预注册的主实验。

触发：plane / pose_translation_x / large / seed 0 / noisy_first / 12 次额外重观察，记忆从 30、60 增至 420。用每个已有点查询其自身位置时，默认 Octree 返回结果未包含其自身编号。这说明该合成边界配置中的空间索引会漏查，可能把重复观察当成新点。该结果只针对固定 revision 和这些输入，尚未评估自然数据触发频率。

新增对照只改变官方已有参数 `max_points_per_node`：从 10 改为 100000，使小测试全部留在一个叶节点中，用逐点距离判断替代分区检索。保留原函数 AST、几何阈值、输入、顺序和种子。这个对照不适合大规模部署，只用于排除 Octree 漏查。

同样运行 216 个配置，结果另存 S0b。若输入顺序依赖在此对照中依然存在，可将它归于“合并后不更新位置”；额外记忆增长若消失，应单独归因于索引路径，不能当成新门控方法需要解决的几何问题。

本测试测量离散 GT surfel 锚点集合的偏差，不是连续曲面的几何保真度。特别地，沿平面切向平移可能不改变连续平面的形状；不能仅凭锚点距离声称生成质量下降。两轮均未检测实际 view retrieval 或视频输出。
