# 相机观察器勘误与当前研究判断

本轮完成了两组真实生成视频的全部30个固定帧对测量，并发现、纠正了一处**测量工具**的坐标转换错误。没有重新生成这些视频，也没有改变基线模型。

可以把它想成：指南针的刻度方向装反了，会把正确的左转报告成右转。原模型在计算光线方向前转换相机坐标轴；我们的初版观察器漏掉了该转换。查清源码后，同样的9350个对应点经过修正计算，再由另一路直接射线计算复核，最大差约2.53×10⁻¹³像素。旧文件、错误标签及纠正时间均保留。

| 场景 | 修正后支持的判断 | 仍然不能判断的内容 |
|---|---|---|
| B0：changi | 15对中13对在可匹配区域符合模型声明的相机投影；1对不确定，1对仅为回到起点 | 不能据此证明整幅三维场景正确或长期记忆有效 |
| C1：jesus | 15对中14对不确定，1对仅为回到起点；原13个覆盖/匹配不足案例全部保留 | 不能把不确定解释成相机失败，也不能临时放宽阈值让它通过 |

图上灰色背景和U都表示“无法判断”。下排为明确标出的放大尺度；即使某个点残差低于虚线，覆盖条件不足仍须报告不确定。阈值只在单个真实纹理的人工投影上校准，尚无独立泛化验证。

这对创新的意义是：第一组短片的“模型根本没按要求移动”解释没有得到支持，我们不应继续围绕这个假失败发明算法。原proposal关注的长时记忆、离开视野后再回来、错误是否在历史中累积，仍需要不同于这段九帧小转角视频的直接证据。

原严重变化筛查没有改动：B0主MSE为0.005278160708699555，C1为0.00464396063251803，两者均未严格大于0.01。原三场景中至少两次事件的条件已不可达，但C2仍须完成。新方法尚未选定或验证；修复测量错误不是算法创新。
