## 修补范围与公式

旧文件按字节保存于`work/S15C_pixel_weighted_before/`，原准备检查和回执保留。旧源码SHA为`eea26cc7cbc8acfc96083949214722d0e0c9c79911131f22bee6c1bc645065f9`；新源码SHA为`a67e7dc3691af6d3ea9beb74def2ebaec8c273f43df30d48ad6285061a950653`。

仅新增`pixel_weighted_metrics(rows)`，并在`score`的summary和执行报告中加入`pixel_weighted`键；`equal_frame_means`、尺度/误差/PNG读取/seal验证/main等既有函数和类AST完全不变，详见`source_diff_receipt.json`。没有增加真实输入读取。

对于域像素访问数n_i，辅助MAE/AbsRel取Σ(n_i·metric_i)/Σn_i；RMSE取sqrt(Σ(n_i·RMSE_i²)/Σn_i)，用max(RMSE_i)归一化后计算避免直接平方溢出。辅助δ1和coverage直接从整数访问计数相加再相除。它们是重复像素访问的合并分数，不是独立样本统计，不能替换主等帧分数。

空域总数0给null。非空帧某误差不可用时，辅助该误差给null并列缺失帧，避免忽略难例；无需该误差的δ1/coverage仍由完整计数定义。部分帧GT为空而整段非空时，辅助可以有定义，主等帧完整均值仍维持既有null规则。
