## 对创新判断有用的发现

**本次从A组换到B组参考照片，原条件组装实际改变了内部坐标缩放。** 两组要拍摄的物理位置相同，最终输入模型的部分几何数字却不同。因此，后续若画面变化，不能马上解释成“参考照片内容更好”或“相机位置改变”。

这不是看过结果才补出的解释。运行前已写下[数学预测](</Users/rocket/Desktop/HKUST IT/ip-/geometry-world-modeling/work/S69_tum_camera_conditioning/ROOT_PRE_RUN_PREDICTION.md>)：在相同首参考和目标相机下，目标射线方向应相同；射线的moment通道除去各组缩放后也应相同。外观均值差应符合替换两张照片编码的代数关系。独立核验中三项比较均落在事先给定的绝对＋相对1e-5容差内。

| 核验量 | 实际结果 |
|---|---:|
| A组自然缩放 | 27.322040557861328 |
| B组自然缩放 | 26.265939712524414 |
| 两组目标方向最大差 | 9.54e-7 |
| 目标moment除以本组缩放后的最大差 | 1.95e-7 |
| 外观均值替换公式最大误差 | 2.38e-7 |
| 原射线与独立回投的最大误差 | 7.44e-6 |

独立NumPy和原Torch的缩放计算存在约3.7e-5的浮点差异，按预先固定的绝对＋相对2e-5合同通过；没有宣称两种实现逐字节相同。两组参考的顺序也有变化，13号照片移了槽位，不能把整个实验当成只换一个固定槽位。

目前先检验：**整套参考集合从A换到B，实际画面是否改变、质量是否改善。** 内部坐标归一化是后续可定位的候选影响路径，当前三次生成对照无法单独回答它的影响。现在只确认了输入变化的结构，尚未证明模型对此敏感，更未证明改变缩放能改进结果。普通尺度归一化和置信度方法已有大量前例；这不是已经成立的新方法。

## 接下来怎样得到真正有价值的结果

下一阶段是固定A、A重放、B三次完整的50步采样与解码，并对全部四个目标画面评分。A与A重放用来检测一次相同输入是否得到相同输出；它不是随机性方差估计。A与B首先比较整套参考条件的效果，暂不把差异拆成纯内容、顺序或尺度效果。

当前已有[完整生成源码接线计划](</Users/rocket/Desktop/HKUST IT/ip-/geometry-world-modeling/work/S70_fixed_context_generation/SOURCE_PLAN.md>)，**尚未完成该阶段执行程序或启动生成**。实施时直接消费本轮保存的条件，不重复翻转、居中或缩放相机。必须接原多视角引导采样器，同时记录实际初始噪声与逐步随机状态；仅写“seed相同”不足以排除随机消耗不同。新进程需要重新加载模型，不能冒称仍有上轮内存中的模型。

生成前固定全部目标、评分口径与资源上限；生成后先看重放是否一致，再看A/B实际画面和分数，保留失败和负结果。只有发现可信缺陷、提出区别于近邻工作的机制、并在强基线和更多独立场景上验证，才逐步建立创新证据。
