分开位置、关联路径和选图规则
状态：S7 尚未运行。这是读取 S6 结果后提出的机制实验，不是 S6 的预注册预测，也不是新的独立测
试集。

  摘要：先查清参考照片为什么会改变

  同样 20 张历史照片，更新地图点的位置也会影响后续匹配。S6 的两种地图因此同时改变了坐
  标、来源关系和点数量，不能把结果只归因于“位置更准”。下一轮固定输入观测身份，重放关
  联事件，用四个地图和四种读出规则检查三条解释。
  H1 位置：同一组观测仍归入同一点，只换最终坐标规则。
  H2 关联：同一坐标规则，改换观测归组的历史；同时涉及点数、分区、出生属性和来源集合。
  H3 选择规则：同一地图，改变候选限制或相近相机位置的抑制规则。
  三种解释可以共存；现在不宣布哪项主导。

H1 ｜最终位置是否足以改变决定？
   解释与成立前提
  在同一关联路径内，每个点包含完全相同的历史观测和来源照片；只把最终位置从首次观测坐标
  改为逐帧均值。位置变化可能改变投影格、遮挡先后和可见投票，进而改变所选 4 张照片。
  动机：S6 出现过换图，但同时改变了关联和点数；VMem 原方法已用可见表面上的来源信息检
  索历史照片。两者都不能单独证明 H1。(Li et al., 2025)
  前提：固定路径内点数、出生法线/半径/颜色、来源集合和贡献帧次数必须严格相同；重放不得
  重新寻找邻居。


 预测与可反驳条件

 操作化预测：固定关联路径 A0 或 A1，切换 P0/P1 后，至少一个预先指定的主测试查询改变最终
 参考 ID 集合；记录变化如何从可见点进入投票与选择。
 反驳条件：在两条固定路径、全部 8 张主测试查询中，最终集合均不变，则“只改最终位置足以改
 变本设置选图”的预测未成立。中间投票改变但最终集合不变，只说明选择规则吸收了变化。
 收益另判：换图不保证支持上升。逐查询正、负、零变化全部报告；本轮没有预先假设可推广的
 提升幅度。


设计：两条固定路径内分别比较
          P0：首次位置                            P1：逐帧均值位置
A0 首写路径   A0P0：必须复现 S6 首写                    A0P1：固定 A0，只改位置
A1 均值路径   A1P0：固定 A1，只改位置                    A1P1：必须复现 S6 均值

每个贡献帧先形成一个质心，  再按原递推规则等帧平均；不能改为全部像素等权平均。主要读出采用原选
择器，
  其余三种读出用于检查解释是否依赖选择规则。以支持百分比 Y 记录每查询 Y (Ai , P1 )−Y (Ai , P0 )，
同时报告 ID 集合和顺序。

 先验证，再解释

 A0P0 与 S6 首写、A1P1 与 S6 均值的全部数组、来源表和地图摘要必须严格一致；摘要不含不
 可重复的计时。重新录制的原 Memory 也须与对应重放一致。任何一项不一致即停止，不进入评
 分。


限制：这是固定关联下的反事实重放，不等于新的在线建图算法。共同像素误差不能代表完整表面；即
使 H1 成立，也不排除 H2 或 H3。未出现变化只限制本批数据，不能证明位置永远无关。
证据：S7 协议；S6 结果和独立审查（附录 B，证 1–3）。

H2 ｜历史观测怎样归组是否关键？
  解释与成立前提
  在线更新位置会改变后来观测匹配到哪个点。即使最后采用同一种位置规则，两条关联历史也可
  能产生不同的点组和来源集合，从而改变哪些历史照片获得投票。
  这里的“关联路径效应”包含：点数量、观测分区、点出生时的法线/半径/颜色等属性，以及来源
  照片集合。不能把它缩写成只改来源 ID，也不预先断言关联更正确。
  动机：S6 两臂的点数确实不同，且支持与几何误差并不总同向；这提供检验动机，没有证明关
  联主导。


 预测与可反驳条件

 操作化预测：固定 P0 或 P1，只替换 A0/A1 后，至少一个主测试查询的参考 ID 集合改变。记录
 首次导致可见来源或候选变化的执行步骤。
 反驳条件：两种固定位置规则下，全部 8 张主测试查询的最终集合均不变，则该干预未显示 H2
 的选图作用。若位置干预已产生变化，也不能只凭 S6 对角两臂宣布“关联是唯一原因”。
 不设“主导”胜负：本轮不以少量查询比较绝对效应后选唯一解释；ID 变化和支持差值分别保留。


设计：先记住每个观测的固定身份
每个接受的历史观测用“帧编号、原 224 裁剪图像素 u, v”标识。分别按首写路径 A0 和在线均值路径
A1 记录匹配目标；未匹配观测按原次序出生。两个路径接受的观测身份与原几何顺序必须一致。同帧
新出生点不可被本帧后续观测匹配。
随后只重放既有归属，得到四臂；固定 P0 比较 A1P0 与 A0P0，固定 P1 比较 A1P1 与 A0P1。跨路径
点数可能不同，不按最终点编号硬配对，也不直接交换来源表。

 交互只作描述，不能冒充唯一因果归因

 每个查询的支持交互量为
                   (YA1P 1 − YA1P 0 ) − (YA0P 1 − YA0P 0 ).

 它描述两种干预是否相互依赖。零交互不证明只有一个机制；非零交互也不证明哪条路径在自然
 场景中主导。


限制：H2 仍同时改变多种属性。若要单独研究来源标签，需在同一地图身份上另立干预；当前四臂不
提供该结论。单房间的有限查询不足以支持一般化新方法，所有下降、零变化和开发集结果均保留。
证据：S6 点数表；S7 协议；候选贡献反证审查（附录 B，证 1、3–4）。

H3 ｜选择规则是否放大或吸收变化？
     解释与成立前提
  同一地图提供的候选和票数，经过排序、去除相近相机位置的 NMS 后，未必选出同一组参考。
  H3 检查候选限制与 NMS 怎样改变最终决定；它可以与位置或关联效应同时成立。
  动机：S6 最近预测姿态 4 图的支持稍高，但与原选择器还存在 NMS 等差异；不能据此单独责
  怪某个模块。VMem 已有来源索引及 NMS，AnchorWeave 也已有覆盖驱动检索；“换一种选图
  规则”本身不是新颖性证明。(Li et al., 2025; Wang et al., 2026)
  前提：比较时地图、查询相机、参考数量 4、距离精度和并列顺序固定；只改变表中明确指定的
  因素。


设计：同一地图的四种读出
读出                 候选                           最后选择
oﬃcial             原展开候选，多重计数保留                 原 NMS 和放宽规则
candidate_no_nms   与 oﬃcial 完全相同                排序后前 4 个唯一 ID
all20_nms          20 张历史各一次                    同样 NMS 和放宽规则
all20_no_nms       20 张历史各一次                    排序后前 4 个唯一 ID

  预测与可反驳条件

  操作化预测：同地图下，至少一个主测试查询因移除 NMS 或放宽候选而改变最终集合；保存候
  选排序、每轮拒绝原因及阈值放宽/回填记录，以定位变化。
  反驳条件：所有预先指定同地图对照均保持集合不变，则本设置未显示 H3 的最终选图作用。若
  换图但支持下降，则否定“该改动改善本代理”的方向性判断，不能只展示有利查询。


实施前必须排除两个伪消融
第一，不能直接关闭官方 NMS 开关。该代码分支还会强制加入最后一张历史并改变阈值。辅助实现须
保留候选展开顺序、ﬂoat32 距离排序和并列语义；查询先经过官方单姿态四元数规范化。带 NMS 路径
逐次复现官方最终顺序后才能使用。
第二，不能悄悄补足参考图。任一路径不能得到 4 个不同的 0–19 历史 ID 时立即停止，报告设置局限。
全 20 候选的两种读出不依赖地图，应在四地图间严格一致。
限制：支持是 50 毫米阈值下的实测几何可见性代理，不含视频美观或生成一致性。四种读出、两种采
样密度、多个像素不是独立样本。只报逐查询变化与主 8 图均值，不做总体显著性检验。
证据：S7 协议；S6 简单对照；VMem 方法（附录 B）。
