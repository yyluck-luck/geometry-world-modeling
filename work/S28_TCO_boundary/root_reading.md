# TCO近邻：本轮根任务原文复读与范围

记录UTC：2026-09-06T17:05:26.322136+00:00

根任务实际读[TCO v1 §3.1–3.4](https://arxiv.org/html/2604.03878v1#S3.SS2)，并看相邻背景；本次不称全文精读或重新复现实验。

原文方法事实：TCO通过预测兼容与先验惩罚进行测试时优化；冻结编码器及输出头，用LoRA调整共享decoder。相机平移损失先分别归一化预测/先验尺度；深度先验损失先做全场景scale/shift对齐。采用可微渲染联系跨视图预测。因此“相机反馈→共享表示→未知几何改善”已是直接近邻。以上依据原文§3.2–3.4，不搬它的性能数字到本项目。

## 本项目的推论与待测问题

- 归一化先验损失与我们固定给定米制相机、保持既有地图的约束不是同一验收条件。不能称只复用其损失就一定保持已提交地图；也不能未经完整复现就说TCO做不到。
- 新方向不能仅换成CUT3R state、加个ray gate或改名“几何记忆”。这些是实现位置与输入变化，尚无已证实的新机制。
- S28首先排除autograd工程缺陷；若只修它已解决组件失败，就不能把旧坏结果当新模块的动机。反之，剩余问题也要与普通尺度/初始化修复比较。
- 潜在有意义的研究问题是：允许新证据修订几何时，如何满足真实长期地图与未来查询的约束，并把不可辨识的尺度和已知的错误分开？这是研究问题，不是新颖性声明。传统metric SLAM、先验融合和现有地图重积分同样是必须比较的近邻。
- 最低否决条件：普通输出空间修复或强尺度先验达到同等真实消费者收益；候选只改善未被读的self/pose头；优势来自额外GT/帧/计算；只在已见4帧有效。任何一项成立都不能宣称新方法优于已有路线。
