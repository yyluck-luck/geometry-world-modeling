## 比 MSE 更对症的三个量及限制

以下为**标准投影数学与本项目诊断建议，不是两篇论文的新评测定义**。先把相机适配到明确的正 Z 前方约定；若深度是光线距离 `d`，先按 `z=d/||K⁻¹u||` 转成 camera-Z（齐次像素 `u` 满足反投影方向第三分量为1）。不能先猜 RTMV 存储语义再套公式。以下 `T_ts=[R_ts|t_ts]` 特指源相机到目标相机的3×4变换，输出三维点；`K_s,K_t` 为3×3内参，`π` 为透视除法。

对同一源像素、同一源身份，用预测源深度与独立源参考分别得到

\[
X_t=T_{ts}[\hat z_sK_s^{-1}u;1],\quad
X_t^*=T_{ts}[z_s^*K_s^{-1}u;1],\qquad
e_{xy}(u)=\|\pi(K_tX_t)-\pi(K_tX_t^*)\|_2.
\]

1. **对应位置误差 `e_xy`（像素）及 `||X_t−X_t*||`（已核数据长度单位）**：前者直接问同一个源点被放偏多少，后者补纯旋转时投影对深度尺度不敏感的盲区。behind-camera、出界和无效深度必须计数，不能当0误差。用正确深度作对照，其自身 `e_xy=0` 是定义结果，不是发现某种方法有效。
2. **独立目标表面的深度与可见性检查**：在明确采样位置 `q` 比较 `δ_z=X_t,z−z_t*(q)`。`δ_z>容差` 可能表示真实遮挡，不能一概叫坏几何；`δ_z<−容差` 表示候选落在参考可见面前方，需查几何、相机或采样；接近0也仅是表面兼容，不保证物体身份/纹理对应。容差取决于实际格式、采样与边界误差，当前不指定数字。目标深度只能用于封存后的评分/分层，不回流源选择或优化。
3. **在预先固定共同支持上的颜色残差**：只有前两项分清后，再解释 RGB 差。可见、表面兼容而颜色差大，仍可能是反射、曝光、纹理、重采样或混合；并非自动识别某一个原因。VGG/LPIPS等特征可忽略细小位置变化，不是物理坐标裁判。全图、支持、遮挡/无支持的完整分母同时保留。

三点都只直接检验 **warp 的几何与颜色**。给生成图附上某个 source ID 或 warp 深度，不能证明生成物体真的位于该处；消费者输出仍需要独立位置/轮廓证据。S81已有观察器控制不重跑，S89只在建立匹配数据资格，不能称上述评分已经可执行或通过。

## 为什么往返闭合不够：一行可手算反例

**纯人工教学数值，非 RTMV 或新计算结果；本例数值由 root 指定并手算。** 两平行相机焦距 `f=800 px`，水平基线 `B=0.1` 数据长度单位，真实平面 `Z=2`，两视图却一致估成 `Z=4`。真实视差 `fB/2=40 px`，错误视差 `fB/4=20 px`。源 `u=100` 的正确目标位置是 `100−40=60`；错误位置是 `100−20=80`。用错误目标深度再投回源，`80+20=100`，往返误差恰0，真实落点却偏20像素。如果墙面颜色恒定，RGB误差还可能为0。反之，同一个正确几何点因镜面反射在两视角颜色不同，可以有大色差但零落点误差。相机、深度误差共同一致时，必须有独立答案才能排除这种自洽伪正确。

这同时否决“自洽就是准确”和“大 RGB 残差就是几何错误”。深度阈值、hard z-buffer、多视图加权仍有用，只是各自解决的问题必须分开。

## 只保留一个后续可推翻问题

**待检预测 H：在独立参考确认的位置与可见性范围内，普通源几何修正＋RGB hard 复制已经足以去掉当前这类物体双轮廓；不需要新的可靠性融合模块。** 这是优先推翻复杂方法必要性的假说，不是对 S87 原因的既成结论。
