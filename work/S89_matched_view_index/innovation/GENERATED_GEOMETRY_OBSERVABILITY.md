**答案：正确源深度＋请求相机给出“该源点应该出现在哪里”，不提供“生成 RGB 中哪一点仍是它”。** 生成可以把它移走、画两份、只保留纹理、涂抹到无法辨认，或完全不画。source provenance 记录输入来源/计算参与，不等于输出表面的身份、坐标或深度。即使 warp 正确，附着它的 depth、mask 或 source ID 也不能充作生成图的几何真值。

## 两个精确可识别性反例

**以下均是纸面构造，不是真实实验。** 固定元数据 `m=(源深度,请求相机,warp,source IDs)`，它预期对象在像素20。一个消费者输出只在20画物体，另一个在20和80各画一份，第三个完全不画；三者可共享完全相同的 `m`。任何只计算 `h(m)` 的评分对三者相同，因此不可能判别生成物体位置是否正确。这不证明 RGB 无法被分析，而是证明必须额外观察输出内容。

再设生成图中两个外观完全相同的物体位于20和80。交换二者的隐藏物理身份，RGB完全不变；若源信息也没有唯一身份线索，仅凭图像无法确定哪一个继承了指定源物体。人工或模型应报身份不明，不能制造唯一对应。特别地，候选集合 `Q={20,80}` 与预期20的最小距离是0，但仍含多余呈现；用最近候选作为唯一正确点会把重影藏掉。

## 最简单的补充：一次小规模、有限盲标

未来在尚未看过生成的新独立场景，从已冻结对照中事先指定一个目标编号，并保留该目标的全部预定臂。只使用源 RGB 选一个可区分物体上的少量稳定锚点，例如可明确指认的角点；不得按生成效果挑点。先固定物体/锚点描述、采样规则、全部分母和位置容差来源，再进行以下两阶段：

1. **看生成，隐藏答案。** 标注者看源物体/锚点说明及匿名生成 RGB；隐藏臂名称、warp、投影期望点和目标参考图。对每个锚点标出**全部**可能对应的位置或小范围，并记录“唯一／多个候选／未见／无法辨认”。不要要求一定找一个，不自动选择最靠近几何期望者。最低是一次独立盲标；不同标注者对关键异常复核时，各自原记录和分歧都保留，不用共识替换原始答案。
2. **封存后才对答案。** 先锁定候选集合及状态，再用独立源几何、相机和目标参考的可见性/身份资料计算预期点与评分分层。目标确实可见而未能辨认，记“可见对象未获可识别对应”；它可能是缺物或严重涂抹，不能武断归为物理消失。目标应被遮挡，则“未见”是允许结果。参考可见性未知就保留UNKNOWN。

这只是**臂身份与坐标答案盲法**，不是让标注者不知道研究主题。S86/S87已经被root看过，不能回溯称盲评；新标注者是否接触旧图、是否从样式猜出臂，也须如实记录。当前未安排人员、未发任何消息、没有实际标注。

## 怎样形成反证，怎样避免虚假成功

- 仅对**唯一且可辨认、参考可见、相机/深度已合格**的锚点报告位置误差，同时保留所有未见、多候选、不确定及参考缺失数量；不能只报唯一点的漂亮均值。
- 若所有可信候选位置都离预期位置超过预先确定的参考/标注误差容忍范围，可反证“这个可见锚点出现在请求位置”。若有一个近候选另有远处副本，最小距离只能说“存在一个近候选”，**不能通过无重影要求**；应单列多候选/重复呈现。
- 若观察到目标应可见却没有可辨认对象，可反证“该可见对象被清楚保留”的主张；不能据此推出模型内部没有任何该对象信息。
- 若独立标注者不同意身份或位置、物体无唯一线索、反射制造相似图案、目标visibility未核，就结束为不可判定，不强配、不把无匹配记0误差。也不能从少量锚点推广到全图几何或绝对三维结构。

对已有自动匹配，最便宜的人工核查只是匿名核其接受点对的物理对应是否可信，并另外保留未匹配/多候选；通过核查的集合不能替代完整分母。不要用预期几何筛掉坏点后再声称几何误差小。人工盲标、集合值对应、拒识和这些反例均是普通测量办法，**不是新颖方法**。当前真正缺口是可信输出对应/缺失语义；不是再给同一warp增加一个自洽分数。
