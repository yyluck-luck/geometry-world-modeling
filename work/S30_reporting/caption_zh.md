# S30 图注与阅读说明

**图1｜单位尺度起点的深度较准，但原优化仍使误差明显增大。** C2t 的逐帧等权平均 AbsRel 从 83.338230% 升至 87.471275%，C2a 从 5.039050% 升至 42.379473%；AbsRel 为平均相对绝对深度误差，越低越好，四个柱顶来自封存评分 JSON 的四个均值，16 个符号为全部四帧的起点／终点评分，不是独立重复试验或误差条。起点使用 S29 已封存的零步深度，终点使用 S30 预定第400步结果，两臂共享原消费头、修复后的深度 getter 与给定 GT 相机；C2t 保留原相机对齐估计尺度，C2a 把初始化尺度设为1，两者都按同一公式对齐相机中心均值。此图为已见 fr2_desk common4、GT-pose oracle 条件下的组件结果，原尺度评分不拟合 GT 比例、不按置信度筛点，不代表部署、长期记忆或生成视频收益。

对应文件：`s30_endpoint_accuracy.png`／`.svg`／`.pdf`。

**图2｜两臂原目标下降，但所有帧的深度最终都小于各自初态。** (a) 完整显示每臂400条保存的更新前 objective，加上菱形表示的第400步后单独求值，共802个损失点；横轴为已完成 Adam 步数，0–399的值位于下一次更新之前，400为实际保存的 postfinal 值，纵轴采用明确标注的对数尺度，跨尺度的 loss 数值不能直接当作深度精度。(b) 完整显示每臂四帧、每条401个保存时点的深度比轨迹：对每帧全部384×512像素计算 `d_k(pixel)/d_0(pixel)` 的均值，**不是帧平均深度的比值**，也不是只在 GT 有效区域计算。线形／符号区分F0–F3，颜色与直接文字区分C2t／C2a；曲线没有平滑、抽掉时点或添加逐步 GT 误差，不能据此声称某个未评分中间步更准。

对应文件：`s30_optimization_trajectories.png`／`.svg`／`.pdf`。
