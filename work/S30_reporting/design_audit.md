# Figure Designer 执行审计

1. **图类型：experimental-results。** 用真实保存的四个评分端点和优化过程记录表达工程对照结果，不是方法总览或生成示例。
2. **范式：端点分组柱图＋全部逐帧散点；连续保存轨迹用折线。** 单纯均值柱图会隐藏四帧，箱线／独立误差条会误导为更多独立试验；GT只在起终点评分，因此不用跨400步的GT折线。
3. **布局：两张独立宽图。** 7.5×3.6英寸端点图横排C2t初／终、C2a初／终；7.5×3.65英寸轨迹图左为原目标、右为深度比。蓝/橙为色觉友好配色，帧另有圆／方／三角／菱形及线型，方法有直接文字标签。
4. **标注：** 端点来自S29／S30，四均值标六位小数（底层保存完整JSON精度）；原目标明确log，菱形为postfinal；深度比明确mean pixelwise。最小字体8.3pt，原生图尺寸可读；不把原生尺寸QA说成最终双栏版面认证。
5. **工具：Matplotlib 3.10.9。** 复用已有Homebrew Python 3.13，不改科研venv；脚本读取封存数据并输出PNG预览、原生SVG/PDF矢量版。没有AI生成图像、外部手改图或额外科学运算。
6. **通用审计：** 两PNG实际查看；均值／点可见且无截顶，log轴覆盖所有保存loss；轨迹全部保留；无3D、阴影、独立重复误差条或逐步GT伪数据。PDF/SVG由Matplotlib直接矢量导出，文件中无嵌入栅格对象的静态检查记录在visual_qa。
7. **完整性门1–7：适用项目通过。** 这是结果图，第6条running-example一致性不适用；原文稿最终版式／字体匹配不在本轮检验范围。图注首句给结果，说明oracle、已见数据、原分母与非视频边界。
8. **严重度：0 CRITICAL、0 MAJOR；输出限制保留。** 尚未逐页重新渲染PDF/SVG、模拟色觉障碍或检查论文缩放后字体；报告原生尺寸的PNG检查通过，不声称投稿排版已认证。数学独立复核由root另做，本绘图没有重复该复核。
