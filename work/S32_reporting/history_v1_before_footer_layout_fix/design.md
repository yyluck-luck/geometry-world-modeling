# S32 辅助结果图设计与技能应用

实际先读 `/Users/rocket/.codex/skills/figure-designer/SKILL.md`，再全文读 references/experimental-results.md、tools.md、design-rules.md。此处只应用实验结果图流程，不假称重新完成文献综述或整篇论文前审。

1. 类型：实验结果辅助图；用途是比较相同窗口的三个普通端点及完整缺失分母。
2. 范式：分面分组均值柱与全部帧点叠加。小柱高度与黑线都表示原四帧均值；数据点完整保留，均值不隐藏局部差别。折线易误读为三次连续优化轨迹；箱线图会将四张相关帧误作重复独立试验且掩盖逐帧值，因此未用。
3. 布局：7.2×5.9 英寸双栏原尺寸；2×2 面板按原窗口序，左上缺 pose 明示 NA。所有面板固定同一 0–50% 线性轴，覆盖最大值约42.11%；没有截峰、断轴或挑单帧。每端点四点以固定水平位置对应0–3，不随机抖动、不增加样本。9 个均值全部标注。
4. 编码：蓝/橙/绿 Okabe-Ito 安全配色，加圆/方/菱形和明确端点位置双重编码；三个均值同样黑线，无“Ours”突出。正文与刻度最小8.5pt，按7.2英寸双栏宽度插入；更小单栏缩放需要重新排版，不能声称缩小后仍达标。
5. 工具：已有 Homebrew Python3.13/Matplotlib，集中 plot_utils.py 控风格；输出矢量 PDF/SVG 和300dpi PNG预览。不改科学venv，不调用AI图片生成器。
6. 审查：矢量、完整轴、无3D/阴影/装饰，图注第一句给出有限结果，NA不填0；帧有相关性，单次run不虚造CI。实际PNG视觉检查另写 visual_qa.json；PDF/SVG只按Matplotlib原生矢量导出检查，不冒称已另行栅格渲染。
7. 完整性门：1类型、2布局、3真实标签、4工具、7数据类型匹配已从设计检查；5视觉规则待实际查看后记录；6不是Figure1动机图，不适用Introduction同例要求。当前没有需用户确认的投稿环节，本任务只是有界辅助图。
