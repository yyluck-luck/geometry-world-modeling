## 怎样读这些图

总览上排是“真实历史颜色经预测几何重投影”的显示副本，不是目标相机的实拍图，也不是生成模型的新输出。灰色棋盘格表示没有合格投影候选填到该像素。下排白色表示有投影支持、黑色表示孔洞。孔洞不是物体的黑色，支持掩码也不是目标视角真实可见性的标注。

## 下一步四种生成对照的区别

| 条件 | 改动位置 | 要回答的问题 |
|---|---|---|
| G0 | 不融合几何引导，记录原采样轨迹末步所需量 | 同输入下普通生成的参照是什么？ |
| Gpaste | 在同一 G0 的最终 RGB 上，用共同 warp 与 mask 作像素合成 | 简单贴入历史颜色已能带来多少变化？ |
| Gterminal | 捕获同一 G0 末步的当前潜变量、clean prediction 和两个 sigma；仅融合末步 clean prediction，再重算同一步 Euler 更新及相同 VAE 解码 | 仅在最后一步融合潜空间信息已能解释多少变化？ |
| Gguide | 在预先指定的更早采样步融合 clean prediction，并让变化沿后续采样传播；末步融合规则与 Gterminal 一致 | 更早融合及后续传播是否有额外作用？ |

Gterminal 不能为了简便直接当作“解码融合后的 clean prediction”：即使末步下一 sigma 为零，实际 FP32 Euler 算术也须按同一实现保留。未来 G0/Gguide 须保存相同输入、warp/mask、强度、历史槽不变规则、解码路径、原采样随机流及完整成本；实际合同尚需单独冻结。

若 Gguide 只优于 Gpaste、却不优于 Gterminal，不能据此说早期采样参与有效。若优于 Gterminal 却差于 G0，也不能说整体生成得到改善。只有固定条件下、针对独立参考的比较，才可讨论本轮早期融合及后续传播的额外作用；仍不能单独定位某一步机制、验证长期记忆或宣布创新成立。
