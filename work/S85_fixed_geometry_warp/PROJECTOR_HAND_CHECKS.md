共同约定：光学 c2w 为 `(R,c)`；`Xt = Rtᵀ(Rs · [Z Ki⁻¹(u,v,1)] + cs − ct)`，只在目标 Z 严格正且连续像素落入 `[0,575]²` 时生成足迹。这里使用**人工精确名义值** `Ki=(420,420,255.6,191.6)`、`Kt=(630,630,287.4,287.4)`；颜色以 RGB01 表示。

## 1. 同一相机：检查比例、裁切与半整数足迹

令两相机均 `R=I,c=0`，源 `(u,v)=(200,129)`、`Z=2`。由 `Kt Ki⁻¹` 得

`u′ = (630/420)(u−255.6)+287.4 = 1.5u−96`；
`v′ = (630/420)(v−191.6)+287.4 = 1.5v`。

所以期望 `u′=204, v′=193.5, Zt=2`。2×2 双线性足迹只有 `(204,193)` 与 `(204,194)`，权重各 `0.5`；另两项权重为0，不进入候选。无竞争时两像素均取原RGB，**不把颜色乘0.5后当成赢家颜色**。这项同时检查没有额外加半像素或套用576裁切两次。

实际数据必须读取保存的 FP32 K/c2w 后仅升 FP64，不悄悄替换为上述名义小数。尤其目标主点保存为 `287.4000244140625`，源焦距/主点也用实际读回值；名义恒等式只适用于本人工夹具，不要求真实映射恰好相等。跨相机时必须完整反投影再变换，不能套这条同P公式。

## 2. 源深度为正，目标仍可能在相机后方

源相机仍为单位姿态，目标 `Rt=I, ct=(0,0,2)`，源像素固定 `(200,128)`。分别给三个源点 `Zs=1、2、3`：

|Zs|目标Z = Zs−2|期望状态与输出|
|---:|---:|---|
|1|−1|目标相机后方；不除Z、不反射到画内、不生成足迹。|
|2|0|目标Z非正；不作透视除法，不生成足迹。|
|3|1|有效；`Xt=(−0.397142857… ,−0.454285714… ,1)`，目标 `(37.2,1.2)`。|

第三点足迹 `(37,1)/(38,1)/(37,2)/(38,2)` 的权重依次为 `0.64/0.16/0.16/0.04`。三点都具有正源Z，不能以此替代正目标Z检查。预期记录保留3个源点，其中2个目标Z无效、1个有效、4个正权重足迹。
