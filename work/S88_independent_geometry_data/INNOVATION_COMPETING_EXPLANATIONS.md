## 3. 一个最小、可推翻的后续干预

**只保留“几何来源 × RGB 末端算子”的 2×2 诊断；不加新完整引导链、不续扫强度。** 前提是独立场景有可信的源 RGB/深度、同步相机/坐标约定和独立物体位置/轮廓参照。当前这些访问资格尚待 S88 数据岗确认，论文链接不等于已取得数据。模拟真值与真实传感器参照分开。

在该独立场景只固定一个普通 G0 底图 `a`（若还没有，未来需一条 G0；本批不运行）。同一组历史 RGB、同一目标相机/K、同一投影/孔洞/冲突规则生成 `b_p` 与 `b_r`：前者用预测源几何，后者用独立源几何。**b_r 是额外信息的诊断 oracle，不能当与方法公平同输入的比赛成绩**；不得拿目标 RGB 修正 warp、拟合位姿或选择样本。

取两种几何均有投影支持的交集 `M`，在读评分目标前固定它；共同支持为空或太窄到没有待检轮廓，就报告本诊断不可识别，不挑好区域。对每个 `b_j` 产生：

\[
x_{j,s}=a+0.75M\odot(b_j-a),\qquad
x_{j,c}=a+M\odot(b_j-a),\quad j\in\{p,r\}.
\]

0.75 来自已暴露问题的固定设置，1 是普通全复制基线，不作新强度搜索。这里 copy 就是凸组合的 λ=1 端点，改变了强度，不能另称已识别“与剂量无关的 hard 机制”；两种端点在 S87 已做，本设计新增的判别因素是独立几何来源，不重跑旧例。RGB 整像素三通道共同操作，不把逐 latent 标量 hard 当同一算子。保存 `a,b_p,b_r` 端点以定位重影是否已在输入中；四输出共用量化、分母和颜色约定。交集比较只是受限支持效应，须同时保留全图及各自支持/缺失情况；不能用交集隐去遮挡和孔洞失败。几何替换会同时改变落点、赢家及支持，故其差是**几何来源的合并效应**，不是只识别一个坐标偏移量。

未来协议在看输出前固定独立位置/轮廓测量及其可识别条件，并与原 RGB MSE 分开报告；当前不追加 S87 指标。若只有像素颜色参照、缺物体位置证据，四格只能说明合成外观差异，不能判几何正确。随机隐藏臂标签的形状观察可以保留，但不能冒充物理真值。

**停/走解释：**

- 若普通独立几何复制 `x[r,c]` 已把位置/轮廓问题解决，先接受“已有几何＋复制足够”，不为本例启动新融合方法。
- 若换几何在 soft/copy 两列均改善独立位置误差，说明上游几何来源重要；不能将其全部归因于条件均值。若已核参照却不改善，否决“只要纠正源几何就足够”的候选，保留相机、可见性、底图等解释。
- 若在同一个已核 warp 下，copy 比 soft 少第二轮廓，而 soft 的 MSE 反而更低，支持**该固定 RGB 合成**的保双轮廓效应；若 copy 不改善或 warp 端点已经双重，否决“重影只是末端 soft 制造”的充分解释。hard 的孔洞接缝、复制错误和漏物体仍计失败。
- 两因素存在交互时，不强迫二选一。此诊断不能说明 latent 硬替换、50 步反馈或长期记忆方法有益；要升级那些主张仍需另行公平协议。

## 4. 为什么最低 MSE 不能完成归因

以下是**人工纸面示例，不是真实实验、未运行新数组**。两像素单物体 `a=(1,0)`、`b=(0,1)`，真图暂取 `r=a`。0.75 合成为 `(.25,.75)`，每像素 MSE 为 `(0.75²+0.75²)/2=.5625`；直接选错的 `b` 为1。分数下降，同时两个位置都非零。若几何正确使 `b=a`，soft 与 copy 都变成 `a`，MSE均0：软混合不是一概错误，位置差和混合可以共同造成缺陷。

一般平方损失的凸组合恒等式已在 S87 推导；它是标准代数，不证明这些候选服从某个后验。只有另外假定给定信息下真图在 `a/b` 各占一半，均值 `(.5,.5)` 才是该人工分布的条件均值，风险 .25；随机完整选择风险 .5。这些概率不来自 S86/S87。下一步价值在于排除普通解释，而不是给这种数学常识起新算法名。
