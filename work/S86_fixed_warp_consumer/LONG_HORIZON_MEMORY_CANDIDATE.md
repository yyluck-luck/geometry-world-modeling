## 仅一个待审候选：让有限观测能分开两种原因

具体失败形态是：重访时对象投影移动，系统把相机共同偏差当成对象变化，错误删除/覆盖旧记忆。Khronos 已处理这个问题；本候选只问**在同一严格存储预算压缩后，观测保留策略是否仍有可测差别**，不是重新发明变化检测。

最小纸面反例：设相机横移误差 ξ、对象真实位移 δ。无噪声对象残差为 yₒ=ξ+δ。看到 yₒ=1，(ξ,δ)=(1,0) 与 (0,1) 不可区分；多存一份相同对象残差仍不够。若另有确实静止的背景观测 yᵦ=ξ，则 δ=yₒ−yᵦ：yᵦ=1 指向相机误差，yᵦ=0 指向对象变化。独立同方差噪声下该差的方差为 2σ²；相关时为 2σ²−2Cov(εₒ,εᵦ)，不能把两条记录默认算两份独立证据。**这是标准相对估计，不是新发现。**

可检验的保留策略差别是：共同前端、状态更新器与读出器完全相同，只把一部分有限历史名额用于能分开“对象变化”和“位姿误差”的对象/背景联合观测；普通强基线也允许保背景、关键帧及多假设，不能只给它最近帧。

一个明确但尚未选作实现的数学目标：局部线性高斯模型 r=Jξ+Aδ+ε，W_S=Cov(ε_S)⁻¹ 为所选观测的联合噪声精度（不是直接截取全体精度矩阵）；Λξ 为位姿先验精度。在集合 S 内消去位姿扰动后，对 δ 的信息为

\[
Q(S)=A_S^\top W_S A_S-
A_S^\top W_SJ_S(J_S^\top W_SJ_S+\Lambda_\xi)^{-1}J_S^\top W_SA_S .
\]

可研究在 bytes(S)≤B 下保留使 Q 的最弱方向更可识别的观测。这里只是标准 Schur 补/实验设计表达，**不是创新公式，也不是可直接开跑的算法**。须固定坐标/尺度以解除规范自由度，或明确广义逆；W、位姿先验、对象对应、背景静止假设及重访方向都必须仅由可用前缀确定。当前没有校准 W。遮挡导致对应/可见集合跳变时，这个局部式不提供保证；若稳定背景不存在，应保留歧义而不是宣判世界已变。背景选择、对象关联及前端实现尚待具体冻结。

生成画面只可作为预测，不可充当一次新物理观察。若 G 仅由已有历史 H 与独立随机种子产生，则在 C→H→G 的条件假设下，P(C|H,G)=P(C|H)。生成/重读可能帮助受限读出器计算，不能据其自洽证明新增了真实场景信息；不得把这个等式扩大为任意读出器性能等价。

## 最便宜的否证与真正独立的数据

**最便宜的下一项是无扩散的离线重访状态实验。本批仅作设计，不启动；未来由 root 按已有用户授权和证据决定。** 共同输入是严格按时间到达的真实观测及相同前端输出；共同持久预算包括图像、点/因子、联合后验、关联与来源元数据，报告重读/重整合成本。外部原始历史不能作为免费后备盘。对照至少是普通固定滞后状态估计/多假设 + 同字节图像缓冲，允许常规视角/背景覆盖关键帧、几何纠正后重整合与自由空间验证。候选只换保留集合，绝不更强 reader 或多拿真实深度。

按独立重访事件评价：未变化时误删率、真实变化时漏更率与检测延迟、当前对象位置/存在性；报告全部遮挡与定位失败，不筛掉难例。错误删除和漏更新须并报，永不更新不能获胜。若普通背景覆盖/位姿关键帧已达到同等结果，或充分联合状态已保住所需信息，**否决候选**；若收益来自更多存储、更多重读、独占传感器或不同前端，也否决归因。即便超过该基线，只是继续验证的条件，尚不证明新颖性，更不证明生成受益。

下一数据入口有两种用途，不能混算：

- **可先核 Khronos 的 TESSE 重访序列**：论文 §VI-A 区分 GT 与估计位姿，作者仓库 README 给出模拟与真实序列入口；适合先检查“相机误差 × 场景变化”是否能独立评分。这是已有模拟数据的候选入口，不能冒充真实相机实测。[官方仓库](https://github.com/MIT-SPARK/Khronos)。
- **DynaBench 可能提供真实数据入口**：§4.3 明确时间 t 查询仅用时间戳 <t 的 posed RGB-D，含人工对象位置/缺失标注。但其相机独立精度、遮挡事件标注与完整下载 schema 尚未核实；不能直接声称已满足本实验。[原文 §4.3](https://arxiv.org/html/2411.04999v2)。

要声称真实变化可辨，仍需要：未见独立场景/重访事件；单独保管的对象状态与相机参考，不由同一 CUT3R/生成器给自己打分；可见/遮挡记录及严格时间前缀。传感 RGB-D 若作为输入，所有方法同权且标为 RGB-D 设定；若原 proposal 保持 RGB 预测几何，则独立深度只用于评分。重复像素/四个视角不算多个独立场景。下载许可、文件格式、事件完整性、前缀与训练/验证划分均待核，不在本轮取数据。

**下一决策是先找普通强基线在这种分原因任务上的实际失败。** 若找不到，停止该候选；若找到，再冻结最小保留策略与完整成本。通过后才值得把同一记忆状态送入固定生成 consumer，验证是否改善长期重访预测。
