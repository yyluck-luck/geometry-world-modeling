## 可以先向零基础读者说明的真实结果

本轮用同一历史投影比较四种做法：G0 按原生成链输出；Gpaste 在同一 G0 最终 RGB 上融合投影；Gterminal 改同一 G0 最后一步的 clean latent，再按原 Euler 算术与 VAE 解码；Gguide 从同一初始随机流出发，在完整链的每一步 CFG 后融合。后两种都在潜空间操作，但介入次数与后续传播不同。

**这次固定已见场景中，Gguide 在四个目标各自的整图 MSE 都低于三个对照，完整四帧均值也最低。** MSE 是每个发图 RGB 数值与固定实拍参考数值之差的平方，按 255² 归一化后平均，越小表示这个像素指标越低。它不是几何准确率，也不是“多少物体正确”。

“为何均值更低”需要分两层回答。**算术上，四个目标全都更低，优势并非只由一帧拉低平均。机制上，本轮支持多步介入这套操作在该固定设置中优于这三个对照；没有唯一识别造成优势的原因。** 普通 Gpaste、Gterminal 自身也都比 G0 的整图分数低，说明末端融合已经是一项有实际作用的强对照。多步结果更低，才留下超越本次末步对照的额外像素收益；不能把这一步直接叫新的几何推理能力。

## “所有四目标改善”究竟覆盖哪些量

对每个目标20–23，Gguide 相对 G0/Gpaste/Gterminal 的**整图、固定 support 区、固定 hole 区 MSE**均更低。这句话仅涉及本次三个定义清楚的分数和这四个相关目标，不涉及每个像素都改善、所有图像质量指标都改善、任意相机路径都改善或四个独立场景。

**孔洞区降低不能解释为几何直接填对了孔洞。** mask 在潜空间只保护直接融合位置，8×8软覆盖块与 RGB 单像素区域不完全相同；VAE 编码/解码的空间耦合可传播变化，Gguide 还会经后续去噪网络传播。输入的黑色孔洞本身也参与整体编码。上述机制说明为什么“没有直接写入”不等于“最终 RGB 完全隔离”，并未在本轮各自作消融、测定贡献大小或证明远程记忆恢复。这些解释不能代替下面实际看到的重影与模糊，也不能把此类缺陷全部归因于某一个网络部件。

## 已核验什么，仍不能借此证明什么

不同作者的消费复核为 PASS：123项字段比较标志均通过，覆盖全部50步 Gguide 融合、末步 Euler 和保存身份等。其限制明确：没有重跑 denoiser/VAE；G0 全50步原 clean 未全量保存，透明性依据运行时对象/字节摘要和末步；中间 RNG 是记录的哈希，不是另行重建 PRNG。G0 与 S70 的已保存完整输出和随机流兼容性另有 PASS 记录，不代表原 SD2.1 VAE 身份已确认。

不同作者的评分复核为 PASS：16帧行、48区域行，821项精确标量核对及174项有理数分数核对；174项浮点差均在记录容差内，最大约1.388×10⁻¹⁷。其独立算法用每通道有符号 uint8 差直方图与 Python 整数累计，并以 Fraction 核比例。该核验器**没有第二次复算 raw→uint8**，它依赖已绑定评分过程的发图量化核查。123、821、174不是样本量、实验轮数或统计显著性。两份原回执仍保留当时“待复核”的状态文字；后续 PASS 文件记录了后来完成的复核，无需改写旧回执。

仍须保留四条边界：

1. **几何/相机真值尚未由本轮指标验证。** 像素 MSE 会同时受布局、颜色、纹理与平滑等影响；必须另用可信相机服从/对应或独立几何指标，不能由当前 RGB 分数直接推出。
2. **剂量与时机未分开。** Gguide 做50次、Gterminal做1次融合，相同λ=0.25不等于相同累计作用或实际RGB变化。优势不能唯一归因于更早使用几何。
3. **已见小样本，不能外推长时动态。** 一条已曝光序列、四个相关目标、一份初始随机流；没有验证物体动态、长期遮挡后重访、跨场景泛化或统计优越性。
4. **普通对照不是创新验收。** 几何投影、clean 融合与引导时间已有近邻；当前 `new_method_validated=false`。应由剩余自然失败、强普通解释及后续公平确认决定是否形成方法，而非根据本次更低均值改名为新算法。

最准确的一句话是：“在这组固定已见输入、组件变体和一次共同噪声下，每步融合的 Gguide 在全部四个目标的整图像素误差均低于原生成、末端贴图和末步融合对照；该结果值得保留，但图中同时可见重影与糊化，不能称全面画质提升，也尚未证明几何更准、剂量之外的唯一机制或长期动态创新。”
