# NVS 证明向 S86 转用的边界

记录UTC：2026-09-10T22:07:39.478789+00:00。

来源仅限本次实际读取的[作者 arXiv v2 HTML 附录 A.1/A.2](https://arxiv.org/html/2405.15364v2)，浏览文本行473–507、式19–35；未核会议PDF或所引证明全文。以下是纸面条件检查，不是作者实验复现。

**A.1：**三角不等式本身成立；继续推出误差比较还使用正λ、预测误差随σ及warp误差随位姿差的经验模型、所选λ解、根号/分母与解分支有效性，以及小v₁近似。它比较的是该误差模型下的融合与warp先验，不自动证明胜过原生成。S86固定系数和软mask未验证这些模型或最优解，不能借用“不劣”的结论。

**A.2：**论证依赖去噪映射可视为局部正交投影、雅可比具有切向性质，并使用后验梯度与小步长。把式33作为链式梯度应用，还需说明目标是否停止梯度及雅可比转置约定。S86不做posterior反传，而是直接融合clean后走原Euler；没有建立上述投影性质。式35的步长比也不是曲率、累计步数或Euler离散误差的保证。

**可转用的只有一般算术：**各位置系数a在[0,1]时，融合是凸组合，对任意同域真值y有逐坐标误差界：|μ̃−y|≤(1−a)|μ−y|+a|warp−y|。但warp误差未知，latent误差也不能直接当RGB或物理误差。

**人工反例：**单位圆在(1,0)的切向量是(0,1)。任意非零小步ε得到(1,ε)，半径√(1+ε²)>1；切向方向只给一阶性质，有限一步不严格留在圆上。这不否定作者实验，只否定无条件的结论移植。

HTML中式27的误差下标、式28展开及A.2“posterior/DGS、orthogonal”措辞有版本/转写待核处；本次不据此判论文错误。当前不能声称S86严格保持数据流形、保证外部误差下降或获得几何一致性。未读新模型/数组、未改合同。
