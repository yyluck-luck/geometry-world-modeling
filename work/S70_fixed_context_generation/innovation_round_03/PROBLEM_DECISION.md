# Decision: explicit scene time is established prior art

Recorded UTC: 2026-09-09T03:06:28.316095+00:00. Author: `/root/negative_result_question_triage`.
**Source-only countercheck; NO_METHOD_SELECTED. Stop this literature branch after two primary papers.** S70 sources, arms and pending results are untouched.

**Fatal novelty collision.** Adding timestamps, replacing frame indices by continuous time, or separately conditioning time and camera is already published. This is established prior art, although it is not a universal input contract of every video world model. “Standard” here means an existing mechanism that must be compared against, not that all implementations already use it.

* **4DiM — Watson et al., ICLR 2025.** Section 3, Eq.1 conditions output views on images, cameras and relative scalar timestamps. MaskedFiLM separately receives diffusion noise levels, rays and video timestamps. Its frame permutation equivariance is an architectural property; frame order is not its only timing signal. Section 5.2/Table 4 still reports weak motion with one conditioning image and improvement with more observed frames. That is not a controlled occlusion-memory failure. Appendix B varies timestamp guidance; richer dynamics does not certify the correct hidden state. Read author v2 method, with formal status verified separately. [Official publication](https://proceedings.iclr.cc/paper_files/paper/2025/hash/ef62614753535977071395fb1f1435be-Abstract-Conference.html) · [Method](https://arxiv.org/html/2407.07860v2)
* **BulletTime — Wang et al., CVPR 2026.** Section 3.2/Eqs.2–6 uses continuous world time in rotary attention and adaptive normalization; §3.3 combines time and camera conditions. Appendix A scales time differences by FPS and recovers ordinary frame RoPE for uniform sampling. Section 4.3/Table 4 compares temporal injection mechanisms under fixed cameras. Appendix B still reports fine hand-motion and unseen-background failures, without an oracle-geometry guarantee. Its input is a video; this is re-filming/retiming, not evidence of predicting an unseen future from past-only memory. Read author v1; the final conference PDF was not byte-compared. [Official publication](https://openaccess.thecvf.com/content/CVPR2026/html/Wang_BulletTime_Decoupled_Control_of_Time_and_Camera_Pose_for_Video_CVPR_2026_paper.html) · [Method](https://arxiv.org/html/2512.05076v1)

**Three different meanings of time.** A diffusion noise level identifies a denoising stage. Frame slots, sequence length, cross-frame attention, masks and appearance can encode order or a learned sampling convention. A scene/query timestamp specifies when the requested world state occurs relative to the observations. These need not coincide. Explicit scene time also does not, by itself, certify calibrated physical dynamics or a unique future.

The frozen batch02 consumer trace remains valid only for its bound VMem implementation: `context_time_indices` go to reconstruction; no explicit elapsed/query time appears in the traced generation call. Nevertheless, ordered images, cameras, masks, frame count and cross-frame features remain inputs. The symbolic collision requires the **entire actually consumed bundle**, model/configuration and random stream to be identical while an external physical-gap request differs. Then the conditional output law is identical. This is a known missing-variable argument, not a new theorem or an empirical VMem failure. A time-aware model escapes that premise because its consumed timestamp changes. We must not relabel diffusion `t` as physical time, or claim that VMem receives no temporal information at all. [Prior exact consumer trace](../innovation_round_02/CONSUMER_TIME_INPUT_ADDENDUM.md)

**One surviving conditional question.** With timing and motion history sufficient for the requested state, does an observation interruption introduce an additional state-continuation error beyond ordinary fully observed prediction error? This is scientifically different from adding a missing input: it tests use of available state information. It is not yet a novelty claim; the already-read STEVO work covers the broad occlusion/state-evolution issue, and this project has no verified strict witness that excludes geometry, reference-consumption and domain errors.

**Smallest real-data falsification before neural work.** Identify one existing short, controlled dynamic track with two independently timestamped visible positions, a later independently observed position after a gap, and a fixed calibrated camera. On CPU, compare last-state persistence with the ordinary time-aware rule `x(t)=x_last + v*(t-t_last)`, using only the two prior positions to estimate velocity. Use an additional visible segment of that same track to check that the assumed motion law is adequate; do not choose the law after reading the hidden continuation. This tiny scalar calculation checks task identifiability and potential headroom, not video-generation quality. State annotations are extra information if the neural baseline does not receive them. No such paired dynamic witness has been verified in the local TUM records; no pixels were scanned to invent one. Current short static-view tasks cannot answer this question.

For a later matched-input neural comparison, 4DiM is a strong published time-aware candidate because it accepts a small set of observed images and target timestamps. Local executable availability and cost have not been established. BulletTime is a strong alternative for a full-input-video re-filming task; giving it future source frames would invalidate a past-only comparison. Neither is authorized to run here.

**Competing predictions and stop conditions.** If the specified future is not identifiable even from the declared timestamped history, stop calling an arbitrary single future the uniquely correct target. If constant velocity already fails on the visible control, stop the constant-velocity or occlusion-specific attribution. If a time-aware consumer succeeds across the interruption under a fair contract, reject this chosen failure case. If it fails equally without interruption, prioritize ordinary model/domain inadequacy. Only extra failure after interruption, with actual camera obedience and consumed references checked, motivates a memory-use explanation; it still needs multiple independent scenes before a broad conclusion.

This separates stale-evidence conflict from absent timestamps.
