# 这轮研究正在回答什么

我们现在检查一个很具体的问题：**给模型同样数量的历史照片，按几何依据挑出的照片，是否真的让它生成得更准确？** 过去只确认过照片被选中、条件确实进入模型；这轮要看最终画面，避免把中间分数当成实际收益。

这次固定生成三组：A组生成一次，再把同样输入完整重放一次，最后生成B组。A、B都用4张历史照片、预测相同4个目标时刻，图像大小、采样步数、模型和实际随机数保持约定一致。第二次A用于检查同输入能否复现同结果；一次重放不能测出随机误差的分布。

模型正在本机进行真实计算。不是用示意图、已有分数或公式模拟生成。完成后，会核验实际保存结果，用真实目标照片对全部四帧评分，再保留完整图片供查看。若B更好或者两者相同，就停止声称本例支持“A的几何依据带来画质收益”；不会为得到好结果而换目标或重跑种子。

即使A更好，这也只是一段已经看过的短序列上的线索。两套输入同时改变照片内容、顺序和内部坐标缩放，因此不能马上断言某一个原因有效。这一步属于可信基线和失败分析；新方法、长视频、多场景推广和论文贡献仍需要后续证据。
