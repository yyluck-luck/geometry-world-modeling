# 真实动态照片：固定历史片段检查

已实际导出并查看Coffee Martini的cam06在0、0.5、…、4.5秒的全部10张预定画面，以及4.5秒的676×507单图。原视频2704×2028，导出仅作统一四分之一缩放；总览另作显示缩放。不是AI生图，也没有生成模型或运动预测。

画面清楚，全部10个时刻保留，未见缺图或异常黑屏。固定相机面对桌面；预定画面中有人手持金属容器向玻璃杯倒液体，杯中液面随所见时刻变化。容器在这些观测中由人操作，没有看到一个适合当前假设的自由运动刚体在遮挡后重新出现。每隔0.5秒的观察不能证明中间所有时刻的连续状态、物体速度或精确遮挡。

**本次固定片段不满足当前“无新外力、可由过去简单外推的遮挡运动”见证需求。** 未知的后续手部动作仍会影响结果；不能把未来RGB不同直接解释为记忆压缩失败。液体的中心/轮廓也不是稳定的刚体材料点。本次停在数据资格检查，没有为了得到好例子改时刻、换物体、读取未来或运行一个容易误解的运动评分。

这不表示数据集没有科研用途：它提供真实动态拍摄、相机标定和两流容器时间轴一致性，可用于另外明确范围的多视角重建研究。但“两个同步视角”只是同一次事件的两份观察；当前未完成跨视图对应、物理同步误差或3D真值核验。
