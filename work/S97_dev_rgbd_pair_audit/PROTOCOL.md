# S97（本地已暴露 TUM RGB-D 全序列配对审计）

目的：核对项目已有开发数据的 RGB/depth/GT 时间配对和文件可读性，修复“本地无RGB-D”与“可做未见确认”两个不同判断。不是S91、不是GRC验证、不是新模型推理。

输入仅为项目内已有的两个TUM目录：fr1_xyz、fr2_desk_timestamp_guard。两者已经用于早期开发，明确标记 DEVELOPMENT_SEEN。固定关联规则：对每个RGB时间戳选择绝对时间差最小的depth和groundtruth，最大差值0.02秒；平局按时间戳升序、路径字典序。报告唯一匹配数、重复使用、文件存在、尺寸/模式和深度非零率样本。规则在读取配对结果前冻结；不使用模型输出、future query或调参结果。

深度按TUM约定记录uint16/5000，零为缺失；内参只记录项目已有近似(525,525,319.5,239.5)，不重新估计。结果仅证明开发数据工程可用性，不能作为未见跨场景GRC确认或连续视频未来预测证据。
