# S16 数学定义审查与解释边界

本次10个子集为`0,1,2,4,8,15,14,13,11,7`：空集、4个单来源、全部来源、4个leave-one-out。它们足够计算本轮定义的“全部改写相对四个单独改写之和的剩余项”与两种上下文中的来源边际。没有包括6个二来源子集，因此不能称完整16格析因分析，也不能分离所有二阶、三阶和四阶效应。

令某个像素正确与否为f(S)，则本轮：

`I = f({0,1,2,3}) - sum_i f({i}) + 3 f(empty)`。

若用包含排除展开`f(S)=sum_(T subset S) c_T`，代入可得`I=sum_(|T|>=2) c_T`。因此I聚合所有二阶及以上项，不能命名为纯四阶交互。分到三个空间掩膜的整数和是完备记账，不是独立干预并识别三个物理原因。

三类按以下优先序定义，数学上互斥且完备：先检每来源是否从有效变缺失或相反；没有此变化再检每来源获胜source-pixel是否改变；剩余为可用性与来源像素身份都固定。最后一类包含完全空或完全不变像素，不代表其中每个像素都实际发生竞争。

## 固定旧获胜来源为什么必须零

某像素旧winner为j。固定owner后，f仅依赖是否改写j：旧值h(a)、新值h(b)。于是full为h(b)，四个single之和为h(b)+3h(a)，base为h(a)，I恒为零。若旧像素没有owner，协议规定所有frozen结果为0，结论仍成立。这是代数/软件检查，不能作为额外独立的物理机理证据。

## 聚合符号翻转与逐像素不同

固定一个source在某像素的old/new深度a、b，其他source共同提供最小正深度c。缺失视为正无穷，输出为`min(a,c)`或`min(b,c)`；没有任何预测时正确性为0。给定正GT和尺度，δ1正确深度组成一个连续开区间。

不失一般性令a≤b。如果a在区间下方，旧结果始终不正确，改写的增量只能为0或正；如果a在区间内，增量只能为0或负；如果a在区间上方，两候选只会在同一个更近竞争者下被替代，增量为0。a>b取相反方向。因此改变其他source上下文可以使同像素的收益出现或消失，但不能把它从正变负。

整幅图仍可能翻转，因为不同像素的正负收益在不同上下文中被激活。人工两像素例，GT均1、其他未列来源深度均3：

| 像素 | source 0 old/new | source 1 old/new |
|---|---|---|
| A | 1.4 / 0.9 | 2.0 / 0.7 |
| B | 0.9 / 1.4 | 0.7 / 2.0 |

仅改source 0比base多正确1像素；在source 1已改的新上下文中，改source 0反而少正确1像素。然而A的边际从+1变0，B从0变−1，没有任何单个像素从正变负。故S16每target或四帧平均的sign reversal是有效聚合诊断，但不能改述为同像素符号反转。
