# 下一次真实动态实验：先让普通状态和旧图像缓冲接受检验

决策记录：2026-09-10 16:08:35 UTC（北京时间 2026-09-11 00:08:35，时钟实读）。**这是待执行的小规模诊断设计；本批没有下载数据、写新框架或运行模型。** `NO_METHOD_SELECTED / novelty_authorization=NONE / new_method_validated=false`。

**只问一个问题：球被杯子遮住后，普通的身份/容器后验加图像缓冲，能否在固定存储下判断它现在在哪只杯里？** 若已经能做到，就淘汰这个任务中的“必须保留特殊旧见证”动机。先做当前动态状态辨认；它不是未来预测，也不是原 proposal 的长期 RGB 生成验收。

## 为什么选这个问题

三项已核来源分别要求：ObjectPermanence 的身份/容器栈必须作为普通基线；Physion++ 已覆盖早期互动支持后续判断，不能据此称新颖；V-information 要求把 reader 会不会用与信息是否丢失分开。两个精确玩具又表明，持久状态在 T1 与旧见证同为零风险，三个后验代码在 T2 与旧见证同为 `3/20`，普通点估计的 `39/220` 不能代表强基线。iSAM2 的重新求解和 3D-Mem 的原图重读进一步排除了两个宽泛新机制故事。

已先核读 [S80_RESULTS.md](</Users/rocket/Desktop/HKUST IT/ip-/geometry-world-modeling/work/S80_lightglue_observer/S80_RESULTS.md>)：其结果只削弱“原几何现象完全因为旧匹配器接受匹配太少”的解释；**没有检验动态旧状态记忆，不能拿来作为本实验的必要性证据。**

| 普通强基线 | 持久目标/容器状态、最多 6 个杯身份排列的联合假设及概率、有限窗口位置/速度与来源时间；合法新观察到来时重新估计，不能只锁死一个标签。普通图像缓冲保留对象相关的互动前后帧，分别跑“最近相关互动”和“关联最不确定互动”两条预先固定规则。无关对象活动不清空目标状态。所有规则在开发视频后冻结。 |
| 唯一候选差别 | 保持上述状态更新、reader、容量、重读次数完全相同，**只把旧图像两槽改为首次球消失前最后可见帧与首次不可见帧，并持续保留**。若“前后帧”与普通规则相同，照实记录。这只是普通关键帧策略的一次诊断替换，尚不是新算法；即使获胜，也只能先说保留时机值得调查。 |
| 共同输出与评分 | 同一状态读出器输出 τ 时目标属于杯 1/2/3 或杯外的四类概率；主指标为未除以类别数的多类 Brier 分数，辅助为错判、身份切换和无法评分数量。评分者独立核 τ 的关系，可看隔离的完整视频，但其观察不得返回在线输入；不读取原 QA 答案。无法可靠核实的片段标记“真值不明”，不能按系统输出补标签。逐视频配对报告，不把帧数当独立样本。 |

这里的后验只是普通有限模型的估计，不称精确 Bayes 后验。若本机廉价前端连共同初始化后的杯/球候选都无法稳定产生，先记录前端失败；不能只给候选补人工轨迹。当前固定结构化 reader 的分数差至多是这个实现的效用差，不能推为 Shannon 信息损失或生成器收益。

## 淘汰条件与数据门槛

**先淘汰：** 两条普通强基线中任一条消除候选的配对优势，或一个普通身份假设/互动关键帧修复即可消除差别，就停止在此任务开发“特殊旧见证”。候选须在两条冻结视频上相对两条普通强基线都严格降低 Brier，且不增加错判，才保留待扩大验证；否则结束本轮候选。这不否定所有视频中的假说。若只击败最近帧或确定性单标签，不进入方法设计。即使两条均改善，也仅保留待扩大验证的现象；此样本量不能验收泛化或新颖性。

**尚未可开跑：** 已核官方仓库说明，但唯一 sample 注释请求实际为 curl 35 / HTTP 000 / 0 字节，无五字段投影、视频或合格 ID；访问失败不是假说否证。本计划不重试该合同。另行取得数据后仍需核官方来源/许可、ID 与视频绑定、实际帧数和展示时间戳、杯球内容、前缀初始化、评分关系可辨认性及评分隔离。自定义截断消除了本任务对未知 QA 映射的依赖，**没有自动解决这些数据问题**。未满足就停在具体缺项，不能靠猜字段启动。ObjectPermanence 和 Physion++ 是模拟数据，不替代此处所需实拍证据。
