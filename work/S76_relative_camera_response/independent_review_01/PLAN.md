# S76 independent saved-result verification — frozen preparation

Two sequential, separately bound modes: generation_01 verifies the actual completed generation before scoring; score_01 verifies the actual later saved coordinate/scoring evidence. Each is create-only and preserves FAILED_PRESERVED/discrepancies. No current output arrays, generated images, model weights, SIFT features or real numerical experiment were read/executed during preparation. Installed scientific packages were not imported by the compiler checks. Compile-only checks ran once on the initial file and again after adding explicit independent scale/progress/snapshot checks; both returned zero.

Execute only after root supplies the actual receipt SHA values, using the lexical absolute `.venv-cut3r/bin/python -B` path (not resolving the venv symlink), cwd=repository, and an actual outer subprocess timeout of 120 seconds. Inner limit is 110 seconds and sampled self peak RSS 2 GiB; neither claims an instantaneous OS memory limit. There are no retries, alternative angles, model calls, image loads, matcher calls, or get_cond/renderer imports. Source/import dependencies are stdlib + NumPy 1.26.4 for array I/O and independent arithmetic.

```
verify_saved.py generation --worker-sha ACTUAL --external-sha ACTUAL
verify_saved.py score --worker-sha ACTUAL --external-sha ACTUAL --score-sha ACTUAL --score-external ABSOLUTE_RECEIPT --score-external-sha ACTUAL
```

Both modes bind the fixed contract/root accepted source list, actual terminal evidence, and all saved numeric geometry fields. Generation additionally verifies original accepted condition arrays and every new saved NPY/NPZ array's file SHA, layout, finite values and body SHA; scalar local yaw, lower-median/0.97 camera centering and natural scale, independent world/source-camera ray directions and moments; unchanged appearance/history/masks/K/centers; initial noise bytes, actual 50-step RNG traces and canonical states, model value/mode/local-identity metadata and recorded consumed model hashes; and emitted uint8 from the original NumPy content-dependent quantization. It does not re-read any weight bytes or claim independent live model-state observation. The inherited Torch advisory `min < -.1` branch is retained separately and cannot override actual NumPy mapping.

Scoring reconstructs scalar homogeneous projections, inverse projections, each matched residual with math.hypot, sorted/interpolated quantiles, same-match signed deltas, coverage, complete four-target events with unknown precedence, and all reported ratios. Both all-valid and common-FOV subsets remain. Correspondence truth is not validated. N and Nc use recorded source feature counts: unmatched keypoints were not saved by the frozen scorer, so independently rebuilding all-source SIFT availability/common-FOV membership is impossible without a prohibited feature re-extraction. This limitation is reported, not concealed or used to invent another run.

The fixed H is independently assembled from scalar dot sums of the actual old/new FP32 optical rotation values promoted to FP64. All 576×576 integer-grid FOV bits are compared. A separate diagnostic uses the true inverse of Rnew instead of Rnew.T, reports H coefficient and full common-in-frame projection discrepancy, and never replaces the frozen prescribed H. This quantifies FP32 orthogonality approximation, not a correction or exact noise-equivariance theorem. Rays retain the original half-pixel 72×72 convention; the feature/FOV diagnostic uses the separately declared integer 576 coordinates.

Tolerances fixed before outputs: scalar statistics absolute 1e-8/relative 1e-10; H absolute 1e-12; scalar yaw absolute 2e-7; independently evaluated rays and camera normalization absolute/relative 2e-5. Layout/bytes, IDs/counts, masks, unchanged-field bodies, hashes, sign/event/null logic are exact. Failure or missing evidence remains a recorded discrepancy and is not silently skipped. Output SHA descriptors can establish saved-byte identity, not unseen live inference correctness.

This is team independent saved-result arithmetic for one full-system relative-camera intervention, not external independent model replication, camera calibration, significance, whole-image geometric validity or a new method. S73 UNKNOWN/NO_METHOD remain outside the outcome of this arithmetic verification.
