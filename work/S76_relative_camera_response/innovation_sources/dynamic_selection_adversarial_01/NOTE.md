# Adversarial baseline: select for the predicted state, not generic scene information

**The strongest next ordinary baseline is a task-focused belief selector, with an uncertainty-aware state estimator as a separate competitor.** This is a hypothesis about an appropriate baseline, not a result or new method. No universal strongest selector is established here.

**Concrete baseline, derived from those established ideas:** define the future state of interest Z before viewing future data; fit or specify the observation/dynamics model independently. Under a fixed k-slot budget, greedily add the historical observation with largest conditional information gain I(Z; observation_i | selected observations). A Gaussian realization minimizes future-state posterior log-determinant covariance. For a tiny preregistered pool, exact subset enumeration can remove a greedy-search explanation if its computation fits the same declared selection budget. Neither entropy reduction nor a Kalman implementation is a new mechanism.

Two important limits prevent a weak comparison. First, linear-Gaussian covariance reduction with fixed noise depends on measurement geometry/timing, not observed pixel values: it cannot recognize an unexpected mode-changing event unless the state/observation model represents that distinction. Second, an all-history RKN summary has already consumed all observations; it is only an auxiliary state-prediction competitor unless both arms receive the same summary/feature access and its cost is charged. Do not insert that summary into only one video consumer.

**Simple falsifier of generic novelty:** if this ordinary task-focused selector or calibrated filter matches the proposed event-aware approach on the predeclared future-state outcome, reject the claimed need for the new allocation mechanism. Hold k, eligible history, annotations/features, preprocessing access, selection-cost ceiling, training access, consumer, actual noise, and denoiser calls fixed. A failure of an intentionally misspecified Gaussian model alone cannot establish novelty. No numeric cutoff or new protocol is selected here.

**Why generic information gain is an insufficient straw man (symbolic only):** let independent Z~N(0,1) be task state and N~N(0,L), L>1, be nuisance, with equal measurement-noise variance. Observing N yields more joint-state information than observing Z, but zero information about Z. Task-focused selection chooses Z. This ordinary distinction already undermines a claim based only on beating coverage or scene-wide uncertainty.

The remaining question is whether an event-informed allocation supplies predictive information beyond a fair, task-aware belief baseline under misspecification and occlusion. That question is not yet validated; NO_METHOD_SELECTED remains in force.
