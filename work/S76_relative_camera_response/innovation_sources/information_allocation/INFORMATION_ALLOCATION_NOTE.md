# Dynamic-state information allocation: ordinary competitors first

**Status: proposed question, no method selected.** This is a three-work primary-source check, not an experiment or a literature-completeness claim. The works below address active acquisition or belief/history representation; none establishes an equal-history-frame/equal-denoiser-budget video-diffusion comparison. That budget contract is our proposed setting, not a new mechanism by itself.

**A hand-checkable baseline, not a discovery.** Assume one-dimensional constant velocity, known timestamps, exact common coordinates and independent observation noise of variance sigma². With p(t)=p0+t v, two observations yield rows [1,t1] and [1,t2] for the state [p0,v]. Their determinant is t2−t1, so distinct times identify both quantities in the noiseless case; a single time does not. The two-point estimate v_hat=(y2−y1)/(t2−t1) has variance 2 sigma²/(t2−t1)². Identical spatial coverage can therefore conceal very different temporal information. Maximizing time separation is not universally optimal: acceleration or a mode change invalidates constant velocity, and future-position loss differs from velocity variance. This is classical observability/least squares, not evidence from project data.

**Smallest strong competitors.** Preserve exactly k historical frames, but reserve the two most recent valid, temporally distinct observations of the moving object and spend the remaining k−2 slots on the same greedy spatial-coverage rule. Compare this timestamp-aware rule with the original coverage rule before designing a learned selector. If image-derived tracks are needed, every arm receives the same extractor, candidates, timestamps and failures; annotated centroids/poses cannot silently be added to only one arm. A standard constant-velocity Kalman or least-squares predictor with uncertainty provides a cheap state-sufficiency diagnostic. It is an auxiliary baseline, not an alternative video generator.

A stronger conventional selection score is expected reduction in uncertainty of a declared future state, I(S_future; O_i | O_selected), under a fixed dynamics/observation model. Calling that score “future-aware memory value” does not create novelty. The model, calibration and integration cost must be disclosed; no general greedy approximation guarantee follows without the required structural assumptions. High observed pixel variation can be noise, not useful state information.

**One falsifiable difference worth isolating:** does an older observation of an actual, visible mode-changing event add predictive information beyond a recent motion pair and spatial coverage, under the same k and generation budget? This is a proposed allocation question, not a proposed event-memory architecture. Fix the event definition and available history before viewing the future. The prediction is that exchanging only a redundant coverage frame for the predesignated event-bearing history improves independently scored future-state prediction while retaining recent-motion evidence. If the ordinary temporal/kinematic baseline matches the benefit, if success requires extra labels/samples, or if no past observation reveals the branch-determining event, reject that claimed advantage. In the last case future uncertainty is intrinsic to the permitted information; selecting harder cannot recover an unobserved random branch.

Equal denoiser calls and frame count must be accompanied by equal candidate access, source-derived features, supervision and selection cost accounting. Recompute downstream conditioning for any source exchange. Do not treat a changed selected ID or sharper confidence as a predictive gain, and retain null/occluded cases. None of the three papers certifies current local dynamic data or makes this direction ready to run. No S76 output was accessed or protocol changed.
