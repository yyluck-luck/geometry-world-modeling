# 02_Idea_Generation：当前项目的重点应用

用户于2026-09-06要求重点关注此章。根任务本轮重新全文读取2.1、2.2、2.3；固定上游207bc6f7a1aa107e544099c2c7cc86816fba9628。此文是选题与实验决策，不是创新成果或录用保证。

## 2.1：选题必须匹配实际条件

目标保持PhD研究深度与CCF A类投稿质量。当前是MSc新手、本机64GB、暂无远程GPU；有三种几何基线、原VMem源码和部分组件，缺完整生成资源。优先能在本机检验机制、随后有明确生成接口的假设；不先承诺大规模重新训练，也不把最终目标缩成轨迹benchmark。

手册的生命周期和每周时间数字是作者的经验建议，不是本用户实际投入、更不是发表的必要充分条件。用户proposal的14周是原计划，不能拿S24编号或代理实验数量兑换成已经完成的周数。热点新论文密集，普通门控/关键帧/重复帧去重等表面想法要迅速排除，真正的机制则用有边界的实验验证。

## 2.2：五个维度要落到实际基线

本轮源码审计改变了问题定位：VMem几何调用会重放全部历史，每次重新初始化内部S/M；GA不直接消费raw相机头，而用anchor self和后续other点图，固定给定相机与旧深度，最终重建点云。因而自由ATE、非首帧self-depth、长期跨chunk隐状态保留，都不能直接替代原消费者证据。详[源代码追踪](../work/S25_consumer_relevance/consumer_relevance.md)。

| 维度 | 当前有根据的切入口 | 最便宜的判别与否决条件 |
|---|---|---|
| 更高 | 改善真正进入受约束GA的几何，而非只改善未被使用的输出头 | 同RGB、给定相机、旧depth和GA预算，比较anchor self/后续other→GA depth/focal/conf→候选Surfel与可见性。仅raw ATE变好而消费者无改善，就否决其生成创新依据。 |
| 更快 | 原调用反复重放不变历史，计算随历史增长；完整state捕捉有实际工程用途 | 先做“连续完整重放”和“前缀缓存后续跑”的全头/状态兼容与实际资源对照。普通缓存本身是已知工程控制，不包装为新算法；GA耗时仍须单列，不能把局部省时说成完整生成加速。 |
| 更强 | 区分新证据适应、旧几何保持与自生成错误强化，定位究竟哪条写入影响实际几何 | 保留S/M四臂因果草稿，但只有自然事件、正常恢复兼容和消费者有效路径都成立才执行方法实验。普通全部跳过/同步gate解释收益则拒绝新机制定位。 |
| 更省 | 固定预算下保留未来控制所需的空间关系，而不只保留图像数量 | 先核自然淘汰/离开/回访事件；无事件停止该片段。关系记录要自包含并计费，普通空间融合/可观测性选择达到同效则否决。 |
| 更广 | 区分通用的几何证据管理与某个生成器特有的条件接口 | 先让一个真实消费者链条有效，再考虑另一接口；只换任务名称、适配器或数据集不能证明通用性。 |

五维不是要求一个方法同时拿满分。当前选择以“更高/更强”的消费者因果问题为科研主轴，“更快”的前缀复用仅作为可复现的工程对照与资源支撑。所有候选先排已有工作和替代解释。

## 2.3：从任务本质重新提问

**第一性原理：** 生成世界模型的目的，是在用户改变视角、离开和回访时仍给出受历史约束且几何合理的内容。优化一个独立几何头，只是手段。真正需要保留的是能约束未来生成的证据；证据进入哪种状态、何时失效、怎样被消费，必须沿代码和实验追踪。

**被忽视的重要问题：** 图像看起来相似、几何代理更准、缓存命中更多，都可能没有改善回访输出。相反，一个对平均深度影响很小的错误可能改变遮挡/参考选择。但后一句目前只是待测机制，不能拿S23少量远距误差当证明。

**技术周期：** 新几何模型和视频模型让这些判别更可行，同时近邻方法也已覆盖许多简单设计。现阶段优先借已有权重做严格干预；不因出现新模型就另换proposal，也不把“无限算力”的思想实验写成实际资源。

**重要问题清单：** 下列是本项目应长期追踪的10个问题，不宣称学界尚无人研究，也不声称都能成为论文。每题通过原文排重与真实判别后才能升级为方法方向。

1. 怎样判断旧几何证据在未来视角上仍然有约束作用，而不只是仍存于内存？
2. 几何代理指标变好，却不改变或反而损害实际生成条件时，原因位于哪一层？
3. 来自同一生成分支的多个观测，何时会重复强化同一错误，普通去重能否完全解释？
4. 已被提交到长期地图的错误，怎样在保留正确历史的同时得到可证伪的修订？
5. 暂时遮挡、物体确实变化与模型凭空补出的内容，怎样用可获得的历史证据区分？
6. 固定容量下，哪些跨观测关系比单独保存更多帧更有用，哪些又只是已有空间融合的另一表述？
7. 相机是已知控制输入时，模型在哪个环节利用它最有效，是否仍有必要优化无关的相机代理输出？
8. 几何S、pose memory M与外层Surfel的不同更新周期，在哪些真实条件下产生互相冲突的证据？
9. 历史反复重放、增量状态复用与几何重新对齐，何时严格等价，何时会因合法修订而必须重算？
10. 怎样以可复现的真实离开/回访和反事实控制，证明方法约束了生成世界，而不只是改善静态重建？

第1/3/5/6题已有直接近邻；第2/7/8/9题也可能归入已有任务驱动优化、相机条件、SLAM或缓存技术。清单不是新颖性声明。不能因为题目听起来大，就跳过最简单的反例和现有方法。
