# RAIMA V4审查后的研究决策

状态：结果前范围收束；不是新方法，不启动现有Stage C。

本记录接续Supervisor handbook 2.2的“强基线→真实错误→根因→方法”、2.3的隐藏假设检查，以及idea-evaluator的资源匹配/可验证性审查。使用本地Claude科学批判技能区分观察量、构念和总体推断。本轮没有调用Claude模型。

## 采纳的结论

RAIMA V4两阶段计数公式内部一致，不能因此推断测量器准确、20场景具有总体代表性或数据可取得。本机时间索引证明现有两条TUM单RGB流无法满足三张±10ms参考。原V4完整确认设计的最小CPU外推90.53天，扩展控制约140.46天；这是预算估计，不是已发生的实验。

保存V4及所有旧否决记录；完整确认分支暂停扩展代码。S48 V7已经形成待审的有限实现，先不因其完成继续增加模型条件。当前优先完成C1数值核验/盲评分和C2下一组真实基线。

## 对独立报告的一项解释收窄

独立报告`RAIMA_V4_STATISTICAL_FEASIBILITY_REVIEW.md`的“单张R即可识别条件成对风险”须读作更窄的**该张已观测reference上的成对损失差**：

`D_R = loss(G_original, R) - loss(G_replacement, R)`。

它是给定两次输出和一个实拍观测的可计算量，不自动识别对传感器噪声、参考分布或场景分布取期望的conditional risk，也不等于绝对记忆价值。若只运行一个seed，不能称跨seed稳定。报告原件保留；root不替审查者改写签署的结论。

例如，使用同一固定有效像素域上的均方误差，令参考`R=T+e`，则直接展开可得：

`D_R = D_T + (2/n) * <e, G_replacement - G_original>`。

因此参考误差会影响差值的符号。只有在额外成立的条件零均值/独立性或误差界下，才能作相应期望或符号推断；本项目尚未验证这些假设。三张参考可能减小随机方差，但不会自动消除共同的相机、曝光、遮挡或对齐偏差。也不能把多张参考当作多个独立场景。

独立报告提出的40-cluster registry是未来确认抽样建议，没有被采纳为最小本机发现性试验的必要条件。完整确认试验仍要另外论证抽样框、测量联合误判率、缺失机制与算力；当前不建立新的宏大确认计划。

## 下一步的最小数据见证

在新输出产生前，先以元数据检查一条候选链是否存在：

1. 一个真实场景、固定source与target capture身份、可用相机内外参和时间信息；原始图片/权重不重新下载。
2. target从当前生成和上游几何构建的全部输入、记忆、条件、替代来源中排除。此前已用于选规则的数据不能伪称独立确认数据；跨历史实验的使用范围须披露。
3. 原始记忆和替代记忆身份、位姿/覆盖范围匹配以及预先定义的差异；不按新输出或target误差挑选替代项。
4. 同一目标视角的有效评分域、遮挡/缺失处理和参考误差检查；没有合格见证则标记缺数据。

这一步只产出候选清单、排除理由和协议范围，不读新答案来选择获胜规则，不新建S48/V4正式arm。如果见证成立，再另冻一个明确标为发现性的成对损失诊断；保留与该诊断主张相称的重放、匹配与负控，重新审查，不继承V4的功效或确认结论。若见证不成立，转向适配的真实数据来源，而不是复制参考或篡改时间。

## 何时才产生方法创新

必须先观察到可信、可重复的实际失败，再检查“选择了历史却在消费者中发生了什么”。候选机制为slotwise latent与全局平均semantic路径的来源信息不对称，现阶段只有源码依据。只有普通重放噪声、相机偏差、来源质量、检索与已有几何attention等解释不能说明结果时，才考虑针对机制的新算法；联合测量框架和新的名字本身都不构成创新证据。
