# Gemini 辅助审查的核验与采用决定

这次真实使用了已授权 Gemini 网页 Pro Extended。原答在 `RAW_RESPONSE.md`，取得方式和实际记录时刻见 `ACTUAL_CONSULTATION_RECEIPT.json`。它是第二意见，不是独立实验或原文依据。以下核验不改任何旧实验、参数或指标。

| Gemini 的意见 | 实际核验 | 处理 |
|---|---|---|
| SIFT-LightGlue 要标准 SIFT，RootSIFT 会造成接口域偏移 | 固定官方 commit 的 `lightglue/sift.py` 第81行默认 `rootsift=True`，第214–215行实际应用 RootSIFT；函数还在开方后作L2归一化。当前设计用的正是官方提取器。 | **拒绝这条接口判断。** 它没有给出支持证据，且与公开适配器相反。不能因此把当前提取器改为未经验证的 raw SIFT。实际训练数据、特征分布和生成域外表现仍是另一问题。 |
| 近似内参/未去畸变是整个观察器对照的 blocker | TUM官方页面确有fr2非零RGB畸变参数，也说明OpenNI预配准和ROS默认参数的使用建议；本项目已记录近似K、原图处理及其局限。 | **保留成像近似为归因限制，拒绝将它升级为本次条件比较不可执行。** 同一批特征、同一固定F下BF/LG接受点及残差分布仍可真实比较；不能由此验证绝对相机真值。也不能假设畸变必然解释当前全部大误差。 |
| 1500个特征可能被生成伪影占据 | 是合理的竞争解释；当前没有伪影占据率、密度或因果来源测量。相同封存特征使BF与LG共享此限制。 | **作为未验证解释保留。** 保存全特征、强度/描述子/分母与空间覆盖；不按这批新结果调整数量，也不把对照自动命名为伪影密度实验。 |
| 两者匹配少说明特征被毁；LG匹配多而误差大说明过度匹配或三维结构不存在 | 也可能是视差、遮挡、低纹理、描述子域外、两者共用提取器的局限或成像假设不符。 | **拒绝唯一归因。** 只能记“在这些设置下支持稀少”或“观察器返回不同支持/残差”。 |
| 错标签下低误差证明生成器记住另一视角 | 低极线误差不是位姿或对应身份的充分条件；多个几何关系或误配都可能给低误差。此前S77甚至仅相对降低，两标签下仍全大于10px。 | **拒绝。** 替代标签仅作固定负对照，不将它解释为恢复出的生成相机。 |
| 真实图拟合差可以为生成器免责；真实图好而生成图差证明非欧几里得幻觉 | 真实控制失败能指出测量链有问题，但不能排除同时存在生成问题；真实控制通过也不能排除生成图上的匹配域外误差。RANSAC挑出的内点不是独立物理真值。 | **拒绝两条“证明/免责”。** 这是必要条件与充分条件混淆，且忽略共同原因和域间匹配差异。 |
| 下一步以RANSAC拟合F再与请求F比较 | 可另立诊断，但需考虑F的任意尺度/符号、退化构型与拟合后的选择偏差；直接矩阵差不能当相机误差。当前12对已有真实控制，S72/S74已经做过有边界的评分。 | **本轮不加入。** 先完成已清楚定义的共享特征观察器比较；有新的解释缺口才另定拟合试验，不临时改变评分器。 |
| 重复砖纹与极线示意可帮助初学者 | 重复纹理说明外观相似不等于同一点；正确F仅把候选限制在一条线上。 | **可用于教学，明确简化。** 给定两个已配准相机和一对确切像素，三角化深度并非任意；这里的不确定性来自线上的候选点尚未确定。数学示例另标人工教学，不称实拍实验。 |

官方核验来源：

- [固定官方SIFT实现](https://github.com/cvg/LightGlue/blob/eb42fee2d71449efb0aa5c10549752b5d75384d8/lightglue/sift.py)。本机全文SHA `9fa24851ff25b6f09cb06fa62aed1d07fa9cb6aa340c79d6467b3bdfdd4508cd`；root已逐段读实际提取和预处理实现。
- [TUM官方格式与内参表](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/file_formats)，本轮网页读取并定位Freiburg2表及其上下文；不将先前fr1参数套用于fr2。实际使用的旧输入和F不改，历史适用性勘误见 `work/S72_fixed_requested_geometry/S71_DATASET_ERRATA.md`。

## 修正后的结果决策表

| 新观察结果 | 可以作的决定 | 仍不能作的决定 |
|---|---|---|
| 两者都无/少匹配 | 当前特征与两条匹配规则下的可用支持不足，空集保留。 | 图中没有真实对应或生成器必然毁坏三维结构。 |
| LG增加大量匹配但残差仍大 | 匹配器会改变所观察的支持；新增支持也不满足当前请求几何。 | LG必错、BF必对，或错误唯一来自某个模块。 |
| 两者残差分布/错标签排序不同 | 诊断对匹配规则敏感，需要保留两种结果和各自分母。 | 选择更符合作者故事的一种作真值。 |
| 两者都保持大残差与类似排序 | 现象并非只由旧BF规则这一实现决定；共享假设仍待检。 | 已排除共同RootSIFT、近似K、生成域外和内容形变解释。 |
| 某方在少量支持上残差更低 | 局部条件统计较低，必须同时报覆盖和未匹配。 | 生成质量改善、模型更准或新方法成立。 |

S80保持全12对、同一份新特征、原请求F与固定错标签，禁止几何残差先筛点；所有结果仍是探索性观察器敏感性研究。
