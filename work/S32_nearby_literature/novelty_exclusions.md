# S32 期间检索：哪些表述不能直接当作新意

本轮实际检索时间为 2026-09-06 19:23–19:25 UTC，精确本地归档时间及失败见 `retrieval_receipt.json`。这是相邻工作的定向排查，不是全领域综述，也没有据此改变已选窗口、基线或评分规则。

**Scal3R（2026-09-03 首次提交）已经提出保留局部几何、改变全局位姿估计。** 本轮实际阅读其摘要、引言、方法 3.1–3.4 和实现 4.1：方法冻结主干，通过额外查询 token 预测多个历史参考的相对位姿，再用位姿图优化。它讨论的是长序列固定首帧参考带来的位姿退化。我们目前的四帧、给定真实相机位置的消费者实验没有复现这一长序列机制，也不能把“保护原模型局部几何”本身宣称首次提出。[原论文 v1](https://arxiv.org/html/2609.04201v1)

**LASER 已处理单个整体尺度变换无法消除的分层深度错位。** 已核摘要及官方 CVF 论文条目：其方法将离线预测按窗口接起来，划分深度层并跨窗口和时间传播尺度。我们 S31 的优化前后对数深度变化分解不等于它的跨窗口分层错位机制；将“整体尺度之外还有变化”作为唯一创新理由不够。[原论文摘要](https://arxiv.org/abs/2512.13680)、[官方 CVF 条目](https://openaccess.thecvf.com/content/CVPR2026/html/Ding_LASER_Layer-wise_Scale_Alignment_for_Training-Free_Streaming_4D_Reconstruction_CVPR_2026_paper.html)

由上述来源作出的当前判断：真正值得继续检验的范围更具体——在给定相机的同一消费者初态上，原优化是否反复损坏预测，以及能否在不使用测试深度真值的条件下判断哪些更新可信。后半句仅是研究问题，尚无新算法或提升证据。直接冻结深度、加深度先验、乘公共尺度、套稳健损失，都必须先作为普通强对照，不能靠命名获得新意。S32 仍按已固定的三个端点执行。
