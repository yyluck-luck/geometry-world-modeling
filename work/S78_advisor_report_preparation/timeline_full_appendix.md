# 附录：项目 S0--S77 可核查详细时间线

本附录供导师汇报 PDF 的“完整工作记录”使用。它根据截至 2026-09-10 的 `RESEARCH_LOG.md`、各阶段正式结果文件、冻结合同、实际回执和独立复核记录整理；不补造缺失结果。

## 如何阅读

- **真实模型**：该阶段实际执行神经网络前向、优化、编码、解码或视频采样。
- **真实数据计算**：读取真实照片、深度、位姿或已存模型输出进行数值计算，不代表再次运行模型。
- **保存量/源码**：对保存数组、日志、合同、合成案例或代码做复核；不是新科学样本。
- “检查 N 项通过”是程序和身份检查条目数，绝不是 N 个独立场景样本。
- 所有阶段均在本机完成，主机为 Apple Silicon M3 Max 64GB；项目期间无远程 GPU。除另注外，日期为北京时间。
- 早期数据主要是 TUM `freiburg1_xyz`；后期 VMem 生成链路的真实照片是 TUM `Freiburg2/desk`（`fr2_desk`）。两者不能混同。S72 已纠正一度误把 Freiburg1 标定文字延伸到 `fr2_desk` 的问题。
