# root 补充阅读：评价者本身也是一个模型

本轮在S56最终交付后额外打开 [WorldStereo 作者原文](https://arxiv.org/html/2603.02049) §4.2–4.3可见正文（实际工具返回范围约§3.3后部至§4.4），不含正式PDF逐页比对或原图放大。

§4.2用WorldMirror从生成视频恢复相机，再与相机指导比较，另列画质指标。其单图条件消融只在记忆内存初始图信息，不能当作长期多来源收益实验。§4.3另外进行点云重建、对齐及精度/完整性评价。以下是本项目迁移判断，非论文已经证明的结论：生成条件、观察器输出、外部几何真值属于三个不同层次；换成标准SIFT也不会自动消除观察器误差。S57只能作已声明模型默认相机条件下的二维残差探索，不直接等同物理相机角或长期三维世界正确性。

因此保留一个真正可推翻的下一步：如果控制集都不能将已知运动与静止分开，停止解释生成相机；如果生成片段与名义运动相容，则接受该有限结果，不继续坚持“画面没动”猜想。没有从这次补读增加新方法、性能结论或生成授权。
