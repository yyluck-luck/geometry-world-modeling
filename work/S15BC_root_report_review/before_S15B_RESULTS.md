# S15B 实验结果：后到照片能否帮助选择几何改写？

**真实实验已经完成：在一段此前看过答案的 TUM 数据上，普通照片代价选择 `pool_new` 的 δ₁ 为 67.108084%，比保留旧值高 1.066127 个百分点；共同有效像素的深度 MAE 从 15.050939 厘米降到 14.076649 厘米。这个正差值得解释，但还不是新方法、跨场景规律或论文创新的证据。**

本报告生成时间：2026-09-06T10:44:15.969033+00:00（北京时间 2026-09-06 18:44:15）。作者：项目内独立分工 agent `s15b_bonn_resolution`。S15B 与本 agent 较早处理的 Bonn S15C 是不同实验；本报告只讨论 TUM。模型与评分已经有不同实现的内部数值复核；本文图表、文字等待根任务最终审阅。

## 给初学者的解释

可以把模型记下的深度理解成“这张照片每个位置离相机多远”。模型第一次看来源照片时留下一份旧答案；看完前 12 张照片后，我们在相同来源相机位置再次询问，得到另一份答案。接着，用第 12–19 张真实照片检查哪份答案在几何投影后更符合照片纹理。最后，将选好的四份来源几何投影到第 20–23 个目标相机，用真实深度传感器读数打分。

这轮的活动假设是：**后到照片提供的相对代价，能否帮助选择比保留旧值、全部换新、简单混合和置信度选择更好的几何？** 实际测试包含预训练 CUT3R 的本机 CPU 推理、真实照片上的纹理代价和真实传感器评分。没有训练新模型、运行 VMem 视频生成器或产生视频质量结果。消费者阶段复用已保存模型输出，不再调用模型。

## 实验固定了什么

- 数据只有 TUM `fr2_desk` 的 S8 block 0，一个独立序列片段。前缀输入为索引 0–11，来源固定为 0、3、6、9；后到照片为 12–19，目标为 20–23。这四个目标在 S14E 已被查看和评分，因此本轮属于**已见答案上的探索**，不是未接触测试集上的确认实验。
- 对同一 12 帧模型状态执行查询顺序 0、0、3、6、9；第二次 0 用于完全重复校验。新候选分别来自调用 0、2、3、4，旧候选来自来源首次观察。重复的六个输出头逐字节相同，五个状态字段在查询前后保持相同。没有把后到八张照片送回模型训练或更新状态。
- 使用允许的 TUM 光学相机姿态。只用前 12 个相机将模型坐标对齐到给定相机，尺度为 **1.1100240750960042 模型单位 / 米**；没有用最终目标深度拟合尺度。目标相机也按协议给定，不是模型预测未来相机轨迹。旧、新候选共用相同来源相机和内参，避免把相机变化混入深度改写。
- 后到照片评价使用 5×5 Census 纹理描述、共同可投影位置和 16×16 来源块。RGB 原生 640×480，缩放 299×224、裁切 `[37,0,261,224]` 到 224×224。纹理评价没有遮挡过滤，因此照片代价仍是几何质量的代理。
- 七种选择全部冻结后，在相同来源、相同目标相机和同一显式投影器中评分。每个目标像素保留投影深度最小的来源点；完全相同时按来源及像素顺序裁决。每个胜出点的来源身份都有存档。缺口不填补、不额外读取目标 RGB、不根据目标答案调阈值。

完整条件见 [前缀协议](S15B_PREFIX_PROTOCOL.md) 与 [消费者协议](S15B_CONSUMER_PROTOCOL.md)。查询网络的条件射线编码与显式物理针孔投影分开：官方编码中的方向为 `normalize(R K⁻¹p + t)`，消费者的空间点为 `R (z K⁻¹p) + t`。数值复核检查了这个区别；不能将两式中的方向直接互换。

## 七种方法与真实分数

主分数先在每个目标内计算，再将四帧等权平均。δ₁ 要求预测和真实深度的最大相互比值严格小于 1.25，分母为该帧全部正值 GT；缺失预测算失败。覆盖率表示正值 GT 中有有效预测的比例。共同 MAE 是七种方法**都能预测的同一批像素**上的绝对深度误差，单位厘米，越小越好。它控制了比较位置，但不惩罚这些位置之外的缺口，因此必须和 δ₁、覆盖率一起读。

|---|---:|---:|---:|---:|---:|
| `never` · 保留旧值 | 66.041957 | +0.000000 | 70.391911 | 15.050939 | 0 |
| `all_new` · 全部换新 | 66.628832 | +0.586875 | 72.147165 | 15.600066 | 200,704 |
| `half_blend` · 旧新各半 | 65.571653 | -0.470304 | 71.435034 | 15.988363 | 200,704 |
| `pool_new` · 合并照片代价 | 67.108084 | +1.066127 | 71.128725 | 14.076649 | 102,144 |
| `split_new` · 两时间组同意 | 66.777504 | +0.735547 | 70.985867 | 14.639862 | 51,712 |
| `matched_absolute_new` · 等数量新代价排序 | 66.367266 | +0.325309 | 70.982261 | 15.203283 | 51,712 |
| `model_confidence` · 模型置信度 | 66.384285 | +0.342328 | 70.625355 | 14.369359 | 85,248 |

`never` 保留旧值；`all_new` 全部使用新值；`half_blend` 用旧新深度的算术平均。`pool_new` 将全部允许照片中的旧、新代价相加，只有新代价更小时才改写。`split_new` 要求前四张和后四张两组都支持改写，而且每组至少有 64 个共同观测。`matched_absolute_new` 在与 split 完全相同的可比较块中，按绝对新代价由低到高取同样数量。`model_confidence` 按每块新旧 `conf_self` 平均值选择；跨首次观察与查询的置信度尚没有可靠概率校准，这里只作为固定组件对照。

一共预定 784 块，其中 682 块有配对观测，557 块符合 split 的两组支持条件。pool 接受 399 块，split 和 matched 均接受 **202 块，即各 51,712 个来源像素**；相同支持域和相同改写数量排除了“只因改得更多”的直接解释。matched 的 K=202 来自 split 的照片决策，未使用 GT；这个对照获得 K 的额外信息，因此是匹配数量的诊断，不是独立部署策略。half blend 的 200,704 表示来源值被替换为混合值，不表示全部采用了新候选。

## 结果支持什么，哪里仍不清楚

pool 相对 never 的 δ₁ 提高 **1.066127 个百分点**，共同 MAE 减少 **0.974290 厘米**；相对 all new，δ₁ 提高 **0.479252 个百分点**。在匹配 202 块的比较中，split 比 matched 的 δ₁ 高 **0.410238 个百分点**，共同 MAE 小 **0.563421 厘米**。这些是同一个固定片段上的描述性差值，最多说明这里存在可测量的选择信号。

同时，all new 的覆盖率比 never 高 **1.755253 个百分点**、δ₁ 高 **0.586875 个百分点**，但共同 MAE 反而增加 **0.549127 厘米**。这说明“填得更多”“已有位置预测更准”是不同现象；单报 δ₁ 会丢掉这个差别。half blend 在四个目标上的 δ₁ 和共同 MAE 都比 never 差，也说明这里的收益不能简单归因于新旧平均带来的平滑。

**普通代价选择不是本项目的新发明。** [DTAM 作者原文 §2.2、式 2–3](https://www.doc.ic.ac.uk/~ajd/Publications/newcombe_etal_iccv2011.pdf) 已在固定来源像素上累计后来图像对多个深度候选的照片代价；[DSO 作者代码](https://raw.githubusercontent.com/JakobEngel/dso/master/src/FullSystem/FullSystemOptimize.cpp) 也有能量下降才接受、否则恢复的逻辑。本轮 `pool_new` 已通过与普通二候选 argmin 的严格等价检查。它使用 CUT3R 候选和不同纹理代价，不等于运行了完整 DTAM / DSO；这些实现差别也不足以单独构成新机制。更完整的五篇原作对照及“拒绝通用改写创新、转向新问题”的判断见 [S15B 强近邻审查](S15B_MECHANISM_PRESSURE_TEST.md)。

S14E 约 93.1% 的数值不能与本轮约 66–67% 横比：S14E 的目标射线组件使用 20 帧历史直接输出目标网格，而本轮模型前缀只有 12 帧，消费者只从四个固定来源显式投影，覆盖率约 70%。输入预算和生成预测的过程都不同，这个数字差不是同条件退步或提升的结论。

本轮还没有证明跨轨迹泛化、自动发现新来源、照片检索收益或视频生成收益；没有检验完整原作系统之间的优劣。994,557 个纹理配对观测的单位是“来源像素 × 后到照片”，不是独立实验样本数。四个目标都已经在先前研究中暴露，不能在这些答案上迭代后再称无偏测试。

## 下一步：S16 来源竞争诊断

S15B 提供了一个更具体的问题：**修改深度后，分数变化有多少来自原来源点变准，有多少来自投影覆盖和遮挡顺序改变、从而换成了另一个胜出来源点？** 两者混在一起，可能让“深度变好”与“消费者变好”出现相反方向。

下一阶段应复用已经封存的七方法 × 四目标共 28 份预测和胜出来源身份，先冻结干预定义，再分别记录覆盖变化、同来源点仍胜出时的变化、来源点换人时的变化，以及其对 δ₁ 和误差的贡献。应同时区分“同一来源照片换了像素”和“换成另一张来源照片”。这些是已知答案上的机制诊断，不需要为了做解释重复跑模型；它们也不是新的盲测结果。S15B 的本报告不把尚未在本阶段完成的 S16 干预当作已验证机制。只有找到稳定、可复查、普通代价选择解释不了的规律，并经过其他独立轨迹验证与原作检索，才有依据再提出方法和论文贡献。
