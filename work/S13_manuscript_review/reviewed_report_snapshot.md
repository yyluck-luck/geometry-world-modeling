# S13：四张参考图还能选多好？

**结论：两个已见场景的当前四图都有测量支持余量，但这个余量使用了真实测量答案，并取消了原来的 NMS 约束。它不是已经实现的算法提升。** 独立实现重算全部164328个组合，数值通过；原协议的文件绑定偏差保留披露。

通俗地说：这次先看“如果知道答案，最多能做到哪里”，以免在已经没有空间的地方反复优化。下一步真正要研究的是，在没有答案的情况下，能不能找到可靠的改进信号。

## 比较对象和数据

- 24个已经看过的查询，来自两个TUM物理场景、六段：S7开发4、S7测试8、S8测试12。三组分别报告，不合成一个总效果。
- 主设置固定 `A0P0 / stride8`，每个查询有20张历史图。来源14与姿态14分别留下14个候选，当前规则再按姿态排序/NMS选4图；两者都使用预测相机几何。
- 支持率是有效查询测量点中，被选定四图至少一张满足固定50mm条件的比例；不是四图共同可见的交集，不是颜色或视频质量。
- 本次上限在每个14候选池穷举1001个四图子集，在全20池穷举4845个子集；总计 `24 × (1001 + 1001 + 4845) = 164328`。同样选四张不代表相同候选预算或相同计算成本。
- **上限没有 NMS（非极大值抑制，即原规则中的相近视角抑制）约束。** 所以“池内上限减当前四图”同时涉及知道GT答案和放松选择限制，不能据此单独测出排序或NMS造成的损失。

## 将差距分成两段，决定下一步检查哪里

定义三个分数：当前四图 `C`、同一14候选池上限 `O14`、全20候选池上限 `O20`。它们满足以下**算术恒等式**：

`O20 - C = (O14 - C) + (O20 - O14)`

第一段是池内余量，第二段是在该支持指标下限制候选集合带来的上限差距。第二段是同一个查询和指标下的候选域限制差，不是部署时得知的损失；第一段不能纯归因于原NMS或排序。这个分解是本轮结果之后追加的描述分析，不是事前预定的因果实验。
