## 2. 必须先做的核验（P2，评分前一步）

**P2.1 位姿列序核验。** 结构检查推断 CUT3R 的 `pred[i].camera_pose` 是 `(qx,qy,qz,qw,tx,ty,tz)`，而真值是 `(tx,ty,tz,qx,qy,qz,qw)`。**必须用代码核验，不能靠肉眼。**

判据（全部满足才接受该列序）：

1. 第 0 帧四元数模长 ≈ 1，且旋转 ≈ 单位阵；
2. 四帧四元数模长均 ≈ 1；
3. 相邻帧相对旋转角随帧号递增（相机在移动），且**不出现**接近 180° 的跳变。

若判据不满足，**停止并报告**，不得改猜另一种列序。

**P2.2 索引错位。** rgb/depth 是 0 基（0–1508），真值位姿是 1 基（1–1508）。本次用到的 1/31/61/91 在两套索引中均存在（第 0 帧无位姿，未使用）。

**P2.3 尺度关系记录（不用于调参）。** 记录预测点云的三维范围与真值米制范围，仅作为背景信息写入结果。

## 3. 待冻结的关键决策

以下每项给出**推荐值**与**理由**，需确认后才能执行。**执行中不得更改。**

### D1 · 比较对象 —— 用哪个输出？

| 选项 | 说明 |
|---|---|
| **(a) `pts3d_in_self_view`（推荐）** | 每帧自身相机系的三维点，与真值各自相机系反投影点直接对应 |
| (b) `pts3d_in_other_view` | 另一帧坐标系，语义尚未核验 |

**推荐 (a)**，并将 (b) 作为**次要报告项**（不改动主指标）。

### D2 · 分辨率不一致怎么办？

预测 **384×512**，真值 **480×640**（CUT3R 输入时做了 640×480 → 512×384）。

| 选项 | 说明 |
|---|---|
| **(a) 真值最近邻降采样到 384×512（推荐）** | 指标在预测原生网格上计算；最近邻不引入插值伪影 |
| (b) 预测升采样到 480×640 | 会引入插值，改变预测值 |
| (c) 把预测点投影到真值像平面比较 | 需额外插值查找，且引入投影遮挡问题 |

**推荐 (a)**。降采样比例 640/512 = 1.25，非整数，须固定**采样规则**（取 `round(u*1.25)` 落格）并记录。

### D3 · 尺度对齐方式

CUT3R 输出处于**任意尺度**（见 `PREDICTION_STRUCTURE_CHECK.md` §2.3），必须先对齐。

| 选项 | 说明 |
|---|---|
| **(a) 首帧 Sim(3)（推荐）** | 在**第 0 帧**（ICL-NUIM 第 1 帧）上用 Umeyama 求 旋转+尺度+平移，**全局**应用于第 1/2/3 帧 |
| (b) 首帧仅尺度 | 只求单一尺度因子（项目 `src/learned_pair_metrics.py: first_frame_scale` 的先例）；可暴露相机系朝向不匹配 |
| (c) 逐帧各自对齐 | **禁止**——会把漂移抹掉，使指标失去意义 |

**推荐 (a) 为主指标，(b) 同时报告。** 两者都只在第 0 帧求解参数、全局应用。

**第 0 帧自身的结果必须单列并标注「对齐帧（乐观偏差）」**，不与第 1/2/3 帧混入同一平均。

### D4 · 参与比较的像素（分母）

- **主条件：真值深度 > 0 的全部像素。** 归档审计记录 5 帧抽样 `zero_count = 0`，但**本协议不预设全部为零**，按实际逐帧统计。
- 预测点非有限（NaN/Inf）的像素**必须排除并计数**——结构检查显示无 NaN/Inf，但评分时须重新统计而非引用。
- **次要条件（预登记）：`conf_self` 高于该帧中位数的像素。** 阈值写死为「该帧中位数」，不得事后调整。

**禁止**：按误差大小裁剪分母、只报告获胜帧、删除难例。

### D5 · 主指标

| 指标 | 定义 | 角色 |
|---|---|---|
| **中位绝对深度误差（mm）** | 逐像素 \|z_pred − z_gt\| 的中位数 | **主指标**（沿用 S4/S5 的 mm 口径） |
| 中位 AbsRel | 逐像素 \|z_pred − z_gt\|/z_gt 的中位数 | **主指标（并列）** |
| 平均 AbsRel | 同上取均值 | 次要 |
| 覆盖率 | 有效比较像素 / 该帧全部像素 | 必须报告 |
| 分位误差 | p90、p99 | 必须报告（尾部不能藏） |

**每个目标帧（1/2/3）单独报告，并给出三帧汇总。不得只报一个平均数。**

### D6 · 判定与失败条件（**先声明，后执行**）

| 判定 | 条件 |
|---|---|
| `CALIBRATION_OK` | 第 1/2/3 帧的**中位 AbsRel 均 < 5%**，且三帧汇总中位绝对误差 < 50 mm |
| `CALIBRATION_MARGINAL` | 中位 AbsRel 在 5%–15% 之间 |
| `CALIBRATION_FAILED` | 中位 AbsRel > 15%（任一目标帧或汇总） |
| `ALIGNMENT_FRAME_ONLY` | 第 0 帧良好但第 1/2/3 帧显著退化——**须报为漂移，不得报为校准成功** |

**无论落在哪一档，都不得回头调整 D1–D5 把结果做进更好的档位。** 若需改进，另立新协议版本并声明「已看过结果」。
