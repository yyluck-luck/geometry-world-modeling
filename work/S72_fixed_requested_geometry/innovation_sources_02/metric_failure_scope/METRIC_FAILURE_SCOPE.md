**Outliers and denominators.** All ratio-passing matches, once the minimum count is met, are passed to `find_fundamental`. The wrapper stores `ransac_thresh` but never uses it; no RANSAC loop or mask is present in this file. We did not inspect the installed Kornia implementation/version, so library-internal behavior remains unverified. Its score calls `sampson_epipolar_distance(..., squared=True)`, then takes `sqrt(value+1e−8)` before averaging **all** returned match distances. The exact Sampson denominator and its epsilon handling are delegated to Kornia and are not reimplemented here. The reported inlier fraction counts distances≤5 over all these matches; it does not filter the error mean. Missing pairs change the video denominator to valid_pairs, while an individual pair's error denominator is its retained match count. There is no spatial-coverage denominator.

**Paper/code comparison.** The previously read v2 §3.2 explicitly describes normalized eight-point estimation inside RANSAC and mean Sampson error as defined by its squared equation. This public wrapper does not establish the stated RANSAC behavior and instead averages the square-root-transformed distance with an added1e−8. These are concrete limits on treating the released metric entry as an exact paper implementation. The paper's pair-averaging description does not specify theseNone/−1/NaN paths.
