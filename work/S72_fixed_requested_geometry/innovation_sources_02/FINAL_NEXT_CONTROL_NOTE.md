# Final next control: retain missing support before comparing residuals

**Minimum decision:** run the same fixed real19 anchor, requestedF and matcher for all four already-generated A0/B targets, but do not rank camera accuracy by independent matched-set medians. Matching is an outcome of image content; a generated image can lose difficult regions and retain only an easy wall. A smaller median can then coexist with worse support. Reporting alone does not identify the missing correspondences; it must make that uncertainty visible.

Root reports real-control counts20–23 as323/160/80/75; median symmetric-mean residuals1.34/3.16/1.41/4.22px and p95 values4.19/6.14/3.36/121.10px. These figures were supplied by root and were not re-read or recomputed here. In particular, target23's large real-control tail rules out treating its whole correspondence population as an already-clean calibration oracle. This does not invalidate every match or prove camera error.

**Minimal reporting, for each target and real/A0/B:**

- Keep the complete fixed anchor feature population as a common denominatorN, its ordered IDs and image coordinates. Use the same anchor feature extraction for all compared destinations; if older saved IDs are reused, verify identity rather than assuming integer IDs remain stable across separate extractions.
- Record matched/N, unmatched/N and invalid-residual counts separately; preserve every pair's identity, all residual quantiles and the existing4×4 anchor/target coverage. Unmatched/invalid entries are **unknown**, never zero residual and never silently removed from the experiment's four-target denominator.
- Retain the existing2/5/10px descriptive cutoffs, without choosing a new favorable cutoff from these results. Show counts of valid matches below each cutoff divided byN **alongside** the conditional matched-only fractions. The former measures detected geometric agreement among available anchor features; it is not global image quality, and does not declare all unmatched points wrong. Anchor features also do not uniformly represent all image pixels.

This compact two-part report separates whether correspondence support exists from how the observed support fits the request. It prevents a matched-only median from being presented as an unconditional improvement; it cannot eliminate non-random missingness or validate every SIFT correspondence.

**One secondary paired statistic:** for each targetj define `I_j = M_real,j ∩ M_A0,j ∩ M_B,j` using common anchor IDs, before applying any geometric residual filter. Keep raw intersection size and coverage, plus which pairs have undefined residuals. For valid shared IDs compare `delta_G(i)=e_G(i)−e_real(i)` for G=A0/B; report the median paired difference and positive/negative/zero counts. This is preferable to subtracting two independent medians because the observed source support is held constant. It remains conditioned on survival in all three images; matching can still associate an anchor to the wrong destination feature, and the intersection may discard the most severe generated failures. It is neither a global camera score nor a global quality score. Never select the intersection by low residual or report only the better-supported arm.

**Short prospective decision rule:** before the generated matching pass, register the descriptive event “armG has positive median paired residual difference on common observed support for every target20–23.” The rule uses the zero sign boundary, not a threshold tuned from the real residual distribution. All four targets must be retained. If every target's paired statistic is defined and positive, report that exact conditional event; if defined but any target is nonpositive, the all-four event is false; if any target has no common valid support or undefined geometry, the all-four event is unknown and the missing-support profile remains a result. Even a true event rejects no unique cause and establishes no significance, effect-size importance, calibrated pose error or new method. Sparse/limited coverage must remain explicit. This is an exploratory followup to already-seen images, not restored blindness.
