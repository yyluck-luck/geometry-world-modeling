## 2. 原始GRC公式逐项判断

| # | 对话中的主张 | 核验结论和必须修正的内容 |
|---|---|---|
| 1 | New Problem + Method，理论潜力较高 | 可以作为研究意图；不是已建立的新问题或定理。方法尚未实现，近邻高度重叠。 |
| 2 | 低几何风险历史 ⇒ 更低未来位置误差 | 是待测的预测假设，不是定理。低风险可能同时低覆盖、缺乏动态信息；应测试在同候选池、预算、覆盖等条件下的增量预测价值和真实选择收益。 |
| 3 | 三维残差向量r_i可直接取Q_(1−α) | 当前未定义分布、单位和多变量排序，公式不完整。可以先冻结标量化，也可定义联合区域；不能说数学上不存在向量分位数。 |
| 4 | q_i就是每条记忆的未来风险上界 | 不成立。普通经验分位数、conformal覆盖、CRC期望损失控制不是一件事；个体条件保证更不能自动推出。 |
| 5 | 候选池分位数适用于实际选出的记忆 | 不自动成立。已有人工例中pool q90≈0.135，策略只选风险0.9候选，超阈值率1。它说明选择偏移，不是否定合法CRC定理。 |
| 6 | I(Y_future;H_S)必然泄漏答案 | 后来审稿意见说得过头。互信息作为总体目标本身合法；在训练集学习预测价值也合法。测试时用真实未来图像、深度、位置给候选打分才是泄漏。 |
| 7 | Σq_i是集合风险 | 一般的集合消费损失不具可加性。旧0.1+0.1对0.8是手指定的集合条件损失，不是同一概率空间的事件并集反例。若q_i确实界住同一批失败事件概率，union bound仍成立；也可在已证明次可加条件下使用和界。 |
| 8 | 信息收益减风险/成本可以直接贪心，并有1−1/e | 尚无依据。须核实际目标、非负归一化、单调/子模和约束形式；风险/成本惩罚会改变性质。人工协同例贪心2、最优4，否定的是通用套用，不证明未来GRC实际目标必然非子模。 |
| 9 | 固定k就固定计算成本 | 不成立。候选特征、几何重建、搜索、上下文编码、模型和解码都要计时/计量；同k可作为先控制条件，不能写同总FLOPs。若Cost只有常数c·k且恰选k，成本项也不会改变排序。 |
| 10 | 动态Update超过阈值就丢弃记忆 | 只是框架描述，尚无可执行转移规则。必须定义失效、遮挡、变化、空集合和恢复策略；误删长期证据与保留过期证据都需测量。 |
| 11 | 三个目标联合本身足够新颖 | 不能成立。必须明确比最近论文多解决什么可测问题，而不是把常见项写入一个目标函数。 |

## 3. 反事实、因果分解和变点：哪些论断站得住

| # | 主张 | 核验结论 |
|---|---|---|
| 12 | 两次生成输出距离就是记忆价值τ_i | 错。输出变化只测敏感性。旧合成例输出距离同为2，但真值损失收益分别+4/−4。需使用有符号真值损失差。 |
| 13 | 固定噪声、相机等就证明了现实世界因果机制 | 过强。合格干预可测这个固定生成器对输入操作的效应；不自动证明真实物理世界的因果机制。种子相同还须验证外生随机量确实匹配。 |
| 14 | 删除i，同时固定所有下游状态 | 测不到总效应。受i影响的attention、融合、latent、输出应自然重算；只固定非目标初态及外生条件。 |
| 15 | 删除i同时保持恰好k条记忆和相同实际算力 | 数学上没有同时满足：删除变k−1，至多k的上限仍相同。可做固定槽mask消融，或用预先规定替代j维持k；两者估计量不同，不能混称删除收益。 |
| 16 | 单条留一分数足以排序所有集合 | 有交互时不成立。τ_i依赖S。coalition分布/Shapley等是可选已有归因工具，也不自动形成新贡献。 |
| 17 | 总误差=几何+外观+交互是一种已证明因果分解 | 目前是定义草案。四格差分可以测受控交互；需定义基准项、独立干预、指标和混杂，不能把任意生成误差唯一分成三种物理原因。 |
| 18 | RGB MSE下降且有重影 ⇒ 已证明条件均值导致 | 不成立。平方损失偏好条件均值是一般事实，但固定blend不等于该生成器的Bayes条件均值。残差几何、遮挡、VAE及融合均可能参与。 |
| 19 | S87的λ端点就是几何准确度干预 | 错。它改变混合/条件强度，不是独立改变几何正确性。新的轴应明确为几何来源×RGB合成方式，并保留oracle额外信息标签。 |
| 20 | 2×2直接验证GRC；零交互足以否定GRC | 错，见新可执行反例。它诊断几何/合成之间交互，没有直接操纵risk-aware历史选择。两者可以并行服务不同问题。 |
| 21 | 不显著就不存在关系，可以停止 | 不成立。应预先给出最小实际有意义效应和精度要求；区间宽时结论是信息不足。等价检验或有足够精度的负结果才支持具体停止决定。 |
| 22 | 所有2×2都不需新完整链 | 有条件：同数据、同消费者、同缓存底图的后处理对照可能省链。新RTMV场景不能借用TUM底图；额外VAE/几何处理也非零计算。 |
| 23 | 当前没有任何可执行实验 | 过强。合成逻辑、旧档探索、组件核验可做；但新的独立配对未来几何确认实验尚缺合格数据和观察器。 |
| 24 | 共用支持像素就保证公平 | 不充分。交集可能只保留容易点。报告预先固定主分母、覆盖、每臂失败率以及共同支持条件指标，不把无效点计为零或删除。 |
| 25 | warp源身份/深度可当生成物体位置真值 | 错。它们只界定输入投影。生成RGB里物体可能重影、缺失或改变；需独立验证输出测量器并保留多解/缺失。 |
| 26 | SWIM已经是世界模型变点方法 | 当前未核实。已找到的官方SWIM是Structured World Models from Human Videos，不能据此指控变点方案重复。若另有所指，须具体题名/作者/正文；不能用缩写猜。 |
| 27 | BOCPD、IMM直接覆盖项目全部变点方法 | 只能确定它们提供相关已有建模工具。BOCPD衍生的recent-regime选帧是我们拟定的baseline，不是原论文明示的同一视频选择器；项目IMM记录是摘要/DOI级，不能声称精读了全文。 |
| 28 | 常数均值模型协方差打平、误差差d²证明所有Fisher方法无效 | 只在所构造错设模型条件下成立；可启发强对照，不能外推所有动态Fisher/coverage方法。 |

| 30 | exact enumeration就是模型oracle上限 | 要区分枚举代理目标与枚举每个子集的真实模型真值损失。前者只保证代理最优。后者计算昂贵、使用答案，只能标oracle上限，不可部署。 |

## 4. 近邻原文核验改变了什么

GIM-World已经用训练几何监督塑造固定memory，并在§3.4用GP pose-time信息准则、预算K和贪心剪枝；所以“几何＋信息增益＋固定预算”的组合不能单独作为我们的新贡献。它的目标关于保留与丢弃历史的信息关系，不能直接等同于我们尚待测的未来几何风险。[GIM-World原文](https://arxiv.org/html/2606.02436v1)

## 5. CRC修正版仍然不能直接保证GRC风险

原附件正确地把目标从逐候选q_i移到了完整选择策略的未来损失，但漏掉了关键前提。CRC基本定理需要可交换的损失函数、随控制参数单调不增、右连续、上侧有界，以及最保守端点损失不超过α。项目选用[0,B_L]是方便的更强规范；原定理不要求损失非负。保证是校准样本和下一查询联合随机性下的**边际期望损失**（E[L]≤α，即控制平均损失），不是每个场景、每条记忆的确定性上界。[CRC §2.1 Theorem 1](https://arxiv.org/html/2208.02814v4)

固定k换图时，收紧风险阈值会排除有用视角，生成损失未必单调。因此“完整策略重放＋交换性”还不够。必须冻结训练后的特征和策略族，明确校准单位，证明适用条件或改用另有依据的风险控制框架。不能自由用同一校准答案选择phi、损失指标、阈值/策略族后，仍照搬原定理。临近视频帧不是自动独立/可交换样本，按时间切割也不是自动修复漂移。

新合成程序演示k=1：阈值0.20选A，未来损失0.10；阈值0.05选B，损失0.60。它驳斥“控制参数变严格必然让消费损失更低”的无条件推断，未测任何真实GRC。见`agents/threshold_consumer_loss_counterexample_results.json`。

在这些条件未解决前，应称“过去几何分数驱动的候选选择”，保留GRC为工作名，移除已成立的conformal保证。即使经验校准通过，也应报告覆盖/风险的实际定义、误差条和失效条件。

## 6. 用新增可执行反例审查2×2推论

每个矩阵对应一种memory选择策略；矩阵内的行表示两种几何条件，列表示两种外观条件，元素均为人工指定未来损失。策略比较是矩阵之间的比较，几何/外观交互是矩阵内的比较。

情形A：低风险memory矩阵[[.2,.3],[.1,.2]]，高风险memory矩阵[[.6,.7],[.5,.6]]。两者交互均精确为0，平均损失却为.2和.6：有记忆帮助不需要2×2交互。

情形B：memory A四格全.3，memory B为[[.1,.5],[.5,.1]]。后者交互−.8，但两种memory的均匀四格平均损失都.3：非零交互不能保证平均记忆帮助。这里明确了平均目标；单格效应仍可不同，不能扩大为所有条件下都无帮助。

`agents/two_by_two_logic_results.json`保存浮点执行，root另用十进制有理数独立复算消除2.8e−17舍入差。两个新程序没有真实RGB、深度、相机或模型输入；只是检验逻辑蕴含关系。

## 7. 四个方向的审稿式决策

| 候选 | 当前可保留价值 | 当前不允许的主张 | 决策 |
|---|---|---|---|
| GRC-Memory | 在已知选择机制之外，测试过去几何风险是否增量预测未来真值损失 | 高分新颖性、逐项保证、未经证明的贪心定理、已达顶会 | **修订后开展有限验证**；按当前证据尚不具备投稿条件 |
| 反事实记忆评估 | 固定生成器、匹配外生条件下测有符号真值收益 | leave-one-out天然新颖、输出改变即帮助、由此证明现实因果 | **作为测量协议优先保留**；独立论文贡献尚未确立 |
| 几何×外观2×2 | 查重影的竞争解释，决定是否值得再改融合 | 已建立因果分解、直接确认GRC、零交互否决全部研究 | **作为诊断支线保留**；数据资格通过后执行 |
| 变点/共同合法前缀 | 在过期记忆、遮挡再现条件下形成具体失败问题 | 普通前缀规则新颖、SWIM重复已证实、静态RTMV验证动态 | **暂缓主方法投入**；先有动态资格数据及强变化模型对照 |

## 8. 真正应先验证的研究合同（仍是待冻结草案）

**问题。** 在同一个合法历史池、同一冻结生成器和明确预算下，过去可得的几何风险，能否比近期/相机距离/覆盖/utility-only更好地预测并选择对未来几何有帮助的记忆？

1. **数据资格先于新生成。** 在当前已核实材料下，RTMV仅用于静态投影/合成诊断筹备；它的视角数字ID不能当时间轨迹。固定一个开发配对核单位、坐标、遮挡和EXR语义，再确定不同用途的独立划分。**动态未来验证尚需合格的真实时间序列、物体状态与参考，这是当前数据缺口。**不能把同一场景的像素数当样本数。
2. **区分已知输入与答案。** 过去RGB/估计几何、已知请求相机可输入选择器；测试目标RGB/深度/物体位置仅供封存输出后评分。用于oracle几何的额外源答案单独标记。目标真值不返流选帧或调参。
3. **先测风险是否提供额外信息。** 训练/开发部分冻结分数；独立查询检验风险与signed future benefit的关系，并控制/分层报告相机距离、覆盖、时间间隔与可见性。简单相关不是选择器改善，也不是因果效应。
4. **再做同预算选择试验。** 同候选池、相同槽数/解码设置，先比较简单可运行baseline及risk+utility。特征/搜索/消费成本分别记录；同总算力只有测量后才声明。COVRAG/Fisher等移植若改变实现，要写明适配；不能冒称完整原论文复现。
5. **有符号效果定义。** 删除式τ_i(S)=E[L_geo(F(S\{i};ξ),Y*)−L_geo(F(S;ξ),Y*)]；正值表示保留有益。固定k实验应另定义替换式τ_(i→j)，预先固定j规则；不要混用估计量。当前生成RGB输出必须先有经过核验的独立位置观察器，失败/多物体匹配不能静默丢弃。
6. **把风险校准放在效果和条件都清楚之后。** 先判断分数能否预测、策略能否获益，再问能保证什么风险。无合格单调策略族时不加CRC装饰；协议必须明确端点/空集合fallback的实际输出及损失。
7. **停止规则与确认规则分开。** 在有足够精度时，risk项不优于utility-only或简单coverage，收束该选择器机制；数据少/区间宽则判信息不足。2×2零交互只约束该诊断问题；oracle几何失败需核其他误差和测量器。普通修正足以解释旧结果时停止相应新融合主张，不能自动宣称边界论文成立。

这不是一个已可启动的大规模实验协议：样本ID、划分、位置指标、观察器资格、最小重要效应、种子和预算还未冻结。**下一实质工程步骤**是修复S90索引前审列出的身份绑定、严格读取及断点问题，然后有限取得配对数据；索引本身不是创新。之后开展上述小规模测量，2×2服务诊断、风险选择服务GRC，分别验收。
