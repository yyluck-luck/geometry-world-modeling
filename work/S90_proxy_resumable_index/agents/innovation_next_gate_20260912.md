## 结论

按当前证据，下一步不应直接实现或宣称 GRC-Memory。最有价值的顺序是：

1. **数据资格检查（硬门）**：确认每个研究单位真的有历史 RGB/几何/相机、未来 RGB-D 或等价几何真值、可追溯的时间和坐标。
2. **2×2 机制诊断（便宜支线）**：只回答几何条件与外观混合是否共同造成旧重影；它不是 GRC 验证。
3. **GRC 小型选择实验（资格通过后）**：直接检验低风险历史是否改善未来几何误差，并与同候选池、同预算的简单选择器比较。
4. **独立确认**：仅在开发结果有清楚信号后，使用未调参场景/时间段复核。

因此，“数据资格”是必须先做的工程—科学硬门，“2×2”可以并行作为低成本解释支线，但“直接 GRC”不能先于二者。当前 RTMV 仅取得相机和 tar 头；S86/S87 是单一已见静态生成场景；它们都不足以支持未来几何选择器结论。

## 为什么不是先做直接 GRC

GRC 的核心可证伪命题是：在相同合法历史池、相同槽位和相同消费成本下，历史几何风险较低的选择，能降低**未见未来状态**的位置/几何误差。若没有成对的未来真值，任何“选择有效”都只能是模型内部分数或视觉印象。当前缺口不是算法代码，而是：

- RTMV 新配对的 RGB、EXR、相机三件套尚未取得；
- 视角数字 ID 不能当时间轨迹；
- S86/S87 只有一个静态场景和相关目标，不能当跨场景未来测试；
- 旧 S81/S84 传感器对照是有限锚点诊断，不包含已冻结的 GRC 选择比较。

在这些条件未满足时实现 selector，会把数据缺口误写成方法结果，且会浪费本机 CPU 时间。

## Gate 0：数据资格（必须全部通过）

这是一个有界、低算力的读取和元数据审计，不需要新生成链。每个候选研究单位至少保存：

- **历史池**：候选帧的 RGB、来源 ID、时间戳、相机内外参，以及选择器可用的历史几何特征；
- **未来查询**：目标 RGB 和独立深度/三维参考，目标相机参数和坐标变换；
- **对应关系**：明确的时间配对、单位（米/毫米）、坐标方向、有效深度/可见性 mask；
- **隔离记录**：选择器运行前不读取未来 RGB、深度、物体位置或由其计算的阈值；
- **身份记录**：数据版本/归档 commit、文件 SHA、脚本 SHA 和完整缺失清单。

建议的本机 pilot 最低规模是 **3 个彼此独立的场景或时间段，每个至少 6 个候选历史和 3 个未来查询**。这是判别性试验的最低门，不是统计普遍性保证。若数据只能形成一个场景或静态视角集合，只能标为开发诊断，不能进入 GRC 主结果。

**Gate 0 停止条件：** 任一单位缺少未来几何真值、时间/相机无法配对、深度单位或坐标未核清、候选历史和未来重叠导致答案泄漏，立即停止 GRC 实验；先修复数据或降级为静态机制诊断。不得用 RGB warp 身份、生成图像清晰度或模型 confidence 代替未来真值。

## Gate 1：2×2 诊断（低成本、独立于 GRC）

目标是检验 S86 的重影是否依赖“几何质量 × 外观条件”交互。四格为：可信/受扰几何 × 普通/几何约束 RGB。几何轴必须是预先定义的来源或扰动，不能把 S87 的 λ 端点直接称为几何准确度；外观轴必须记录实际混合/生成操作。

- 优先复用已保存的同一底图、噪声和消费者状态，避免新完整去噪链；
- 每格保留全图、有效支持、遮挡/边缘区域和失败样本；
- 若使用 RTMV 的静态投影，明确它是投影诊断，不是动态未来实验；
- 预先固定交互差分和最小实际效应，报告区间而非只报单个 MSE。

**Gate 1 能回答：** 重影是否在受扰几何和某种外观条件组合下增加。**不能回答：** 哪条历史应被选择、风险是否校准、未来位置是否变准。即使交互为零，也不能否定 GRC；交互显著也不能证明 GRC 有收益。

**Gate 1 停止条件：** 可信几何仍出现同等重影且普通融合/解码因素已解释，停止“几何修复融合器”主张；若只是静态或无独立参考，则保留为探索诊断，不升级为论文方法。

## Gate 2：直接检验 GRC 的最小实验

仅在 Gate 0 通过后执行。先冻结风险特征和候选池，再读取未来答案评分。

### 预注册的选择比较

同一个候选池、同样的槽数 `k`、同样的历史特征和消费设置，比较：

1. 随机（固定种子，多次）；
2. 最近时间/相机距离；
3. 覆盖贪心；
4. utility-only（不使用风险）；
5. risk-only；
6. risk+utility（候选 GRC）。

所有策略必须公开其搜索、特征提取和消费成本。`k` 相同不等于总 FLOPs 相同；若成本不同，单独报告并做成本匹配。任何 oracle 选择单列为上界，不参加可部署方法排名。

### 主要测量

- **主指标**：未来查询上的三维位置误差；若只有深度参考，使用固定相机/单位下的深度或重投影误差，并明确它不是完整物体位置真值；
- **辅助指标**：覆盖率、可见性分层误差、遮挡后重访误差、无效/缺失率和总推理时间；
- **风险关系**：在同一候选池内，记录每个历史风险与其 signed future benefit（保留该历史相对于预定替代的未来误差变化），不能只记录输出变化距离；
- **不确定性**：以查询为配对单位给出 bootstrap/permutation 区间；连续像素不能冒称独立样本。

低风险假设只有在以下三层都成立时才算有支持：

1. 风险在开发集上预测 signed future benefit，而不是只预测相机距离或覆盖；
2. GRC 在固定候选池和预算下优于 utility-only、coverage 和简单距离基线；
3. 同方向效果在未调参场景/时间段保持，并且不是由额外历史、额外未来信息或更高计算成本造成。

在正式运行前固定最小实际效应 `δ`（建议以一个传感器像素等价误差或基线误差的 10% 中较大者为参考），并写入合同；这个数值是决策门，不是事后显著性包装。

**Gate 2 停止条件：**

- 风险与未来 signed benefit 的区间跨过零，且在预定样本量下无法达到 `δ`：不称风险校准有效；
- GRC 不优于 utility-only/coverage，或优势在成本匹配后消失：停止 GRC 选择器主张；
- 只有静态单场景、同一场景调参或 oracle 几何有优势：降级为探索/上界；
- 可信普通基线已在 `δ` 内达到同样误差：停止新增 selector，保留失败边界；
- 结果不精确但区间很宽：结论是“信息不足”，不能写成“假设被否证”。

## 给老师的可解释表述

“我们先不把 GRC 说成新方法。当前最关键的问题是，过去几何风险能不能在不看未来答案的情况下预测未来位置误差。为避免把数据或计算差异误认为创新，我会先核对历史—未来 RGB-D 和相机配对、坐标和答案隔离；同时用一个低成本 2×2 对照解释已有重影。只有在独立配对数据上，风险选择在相同候选池和预算下超过最近帧、覆盖和 utility 基线，我才把它升级为方法；否则就停止这个主张并报告边界。”

## 审稿式最终判断

当前最值得投入的是 **Gate 0 数据资格 + Gate 1 低成本诊断**；直接 GRC 属于 Gate 2，尚未授权。该顺序能够用最小成本区分三种情况：数据不合格、重影可由普通混合解释、风险确实提供未来预测增量。它不能保证产生顶会创新，但能防止在没有未来真值时把工程选择器包装成创新。
