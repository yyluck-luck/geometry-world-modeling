审查对象是用户附件中的 GRC-Memory、CRC 和反事实记忆公式。结论只修正可写入协议的条件；没有运行模型，也没有把这些条件当作实验结果。

## 1. CRC 可以合法使用的最小条件

固定策略族 `pi_lambda` 后，每个校准查询必须完整运行同一策略，产生一个**集合级**未来损失 `L_j(lambda)`。CRC 原文的保证不是逐候选分位数，而是对下一个可交换查询的边际期望损失控制。其定理还要求：每条损失曲线关于 lambda 单调不增、右连续；`sup_lambda L_i(lambda) <= B` 几乎处处成立；并且最大 lambda 的损失已不超过目标 alpha。官方实现 `core/get_lhat.py:8-11` 对校准行取均值并返回一个全局 lambda；它没有返回每个历史候选的 `q_i`。

因此，项目协议应明确：

* 在训练/校准阶段先冻结特征归一化、候选生成、选择规则、解码预算和损失定义；若这些量由校准答案调参，交换性对象已经改变，必须另分训练集和校准集。
* 校准单位应是“场景-时间查询”或预先定义的目标块，而不是同一查询内的候选条目。时间相邻轨迹不自动交换；若存在动态漂移，CRC 的原始保证不能直接外推。
* 多个 lambda 只能在**事前冻结的策略族**中选择一个全局参数；不能看测试未来结果再挑最好 lambda。若选择器本身改变了风险曲线的单调性，不能套用定理。
* 每个 `L_j` 必须有完整分母并限定到 `[0,B_L]`，包括无效深度、出界和 behind-camera 情况；缺失值不能当作零损失。

若确实要控制一次送入模型的 k 条记忆的联合损失，应直接定义 `L_j^set(lambda)` 并对完整集合策略重放。只有在额外证明下，`sum_i q_i` 才能作为上界；独立候选风险的相加不是一般的联合风险模型。CRC 文献的 U-risk 扩展表明，集合/多点目标需要重新定义集合损失和交换性对象，不能从单点代码自动推出。

## 2. 反事实效应的条件

附件原式 `E[L_geo(Y(h_i),Y(h_i^-))]` 若比较两个输出之间的距离，只测输出敏感性，不能判断记忆有益还是有害。建议使用：

`tau_i(S) = E_xi[L_geo(Yhat(S\\{i};xi),Y*) - L_geo(Yhat(S;xi),Y*)]`。

必须预先固定场景、目标相机、目标真值、非目标记忆、预算、推理步数和随机噪声；删除目标来源后，其注意力、融合状态、latent 和输出全部自然重算。若把目标来源的下游状态冻结，只能叫受限路径诊断。正值表示保留该来源降低真值损失。

`tau_i` 依赖当前集合 S；存在协同时，单条 leave-one-out 不能代表所有集合。若汇总成单一 item 分数，必须预注册 coalition 分布或使用明确的 Shapley/留一法估计，并报告 Monte Carlo 不确定性。输出影响、几何支持局部性和对独立真值的 signed benefit 必须分开报告。

## 3. 不能把不显著当作否定

`H0: interaction=0` 的不显著结果只表示当前样本和方差下没有足够证据拒绝零交互，不能证明不存在交互，也不能自动停止 GRC。停止规则应预先定义为效应置信区间落在实际等价区间内，或在多个场景/种子下效应方向不稳定且不超过预注册最小重要差异。对于因果语言，2×2 四格必须是可分离干预、配对随机流和相同预算；否则写“受控交互诊断”。

## 4. 可执行修订清单

1. 把候选风险向量先固定成有单位归一化的标量 `a_i=phi(...)`，并在训练集冻结 `phi`；不要写 `Q(r_i)` 的向量分位数。
2. 将 CRC 目标改成策略级集合损失，并在场景/时间隔离的校准轨迹上完整重放；报告平均损失、分母、alpha、B 和选择后风险。
3. 以 recent-k、相机距离、coverage、Fisher/EIG、utility-only、random 和 oracle 为预先冻结对照；相同候选池、k 和总计算预算。
4. 先做 matched-seed 的单来源反事实小实验，随后再做跨场景确认；若输出敏感性与 signed benefit 不同方向，删除“敏感性即价值”的表述。
5. 把 `1-1/e` 从当前方法主张中删除；只有在实际集合目标证明非负、单调、子模且约束为基数约束时才可恢复，否则用小 k 穷举作参考。
