## 1. 给老师看的结论

目前最有潜力的不是已经成立的“GRC-Memory方法”，而是一个可检验的新问题：**在固定记忆和计算预算下，过去观测的几何风险，是否能在不查看未来答案的情况下预测并改善未来几何状态？** 这比“把深度、uncertainty、information gain拼在一起”更明确，但仍处于候选阶段。

GIM-World已经覆盖几何监督、固定预算和信息增益/贪心剪枝；WorldPack覆盖空间相关性驱动的固定预算压缩；R2M-Bench覆盖重访/间隔匹配的未来一致性评价；CAP说明自适应选择后不能直接照搬普通校准保证。因此，GRC只有在**独立未来几何真值、同候选池、同预算、同消费成本**下，击败这些近邻基线，才可能形成独立贡献。

当前没有证据支持“方法成立”“保证成立”“达到顶会/PhD水平”。`new_method_validated=false`，`novelty_authorization=NONE`。

## 3. 具体可证伪实验（保留S编号，使用具体名称）

### 试验A：未来几何风险增量预测试验（GRC-Pilot；建议作为下一项）

**问题：** 风险分数是否比时间距离、相机距离、覆盖率和utility-only提供额外未来信息？

**固定设计：** 同一合法历史候选池；训练/开发/测试按场景或序列拆分；选择器只能看到过去RGB、过去估计几何、历史时间和请求相机；未来RGB、深度、位置只用于封存后的评分；固定`k`和完整消费预算。

**主指标：** 未来物体中心/关键点位置误差、深度误差、3D重投影误差；RGB MSE仅作辅助。统计单位为场景/序列/查询，不是像素。

**必须比较：** 最近时间、相机距离、覆盖率、utility-only、WorldPack式空间相关性、GIM/GP或同等pose-time信息准则、risk-only和risk+utility。

**推翻条件：** 风险与未来有符号收益没有稳定方向；增益被覆盖/距离完全解释；开发集有效而未见场景失效；或优势来自更多算力/未来答案。

**当前状态：** 未执行。Gate 0目前因RTMV配对文件不可用而REJECT；因此不能把S86（单场景四目标几何条件注入基线实验）或S87（末端引导强度控制与多步引导必要性反例实验）的RGB结果替代本试验。

### 试验B：固定槽位反事实记忆增量试验（Counterfactual Signed Effect）

**问题：** 单条历史的保留是否对未来几何误差有有符号的增量帮助？

**两种估计量分开报告：** (1) 固定槽位mask删除；(2) 预先规定替换规则、保持槽位数为`k`。两者不能混称“删除收益”。固定外生噪声、请求相机和非目标条件；受目标记忆影响的下游attention/latent自然重算。

`tau_i = L_geo(F(S\\{i};xi),Y*) - L_geo(F(S;xi),Y*)`，正值表示保留记忆有帮助。

**推翻条件：** 方向随种子/场景随机，区间足够窄仍覆盖零；只改变外观不改变几何真值；或必须看未来答案才能决定替换。

**当前状态：** 合成反例只证明“输出距离不能代替有符号真值效应”；没有真实模型验证。

### 试验C：几何来源×外观融合四格诊断试验（Geometry–Appearance 2×2）

几何轴必须真正改变几何来源/可信度，不能重复S87的末端混合强度。外观轴为普通RGB与明确的几何约束RGB。报告四格均值、交互项、置信区间、覆盖率和失败率。

交互项可写为`E11-E10-E01+E00`，但它只是受控诊断量，不是“因果分解定理”，也不直接证明GRC。

**推翻条件：**交互项在位置、深度和感知指标上接近零且精度足够，或效应完全由VAE、孔洞和覆盖差异解释。

**当前状态：**尚未执行新四格；已有合成逻辑例仅检验逻辑蕴含，不含RGB、深度、相机或生成模型输入。

### 试验D：动态变点—记忆失效试验（Changepoint Prefix Validity）

需先取得真实动态RGB-D/状态序列，定义遮挡、移动、重访事件及标签。比较固定窗口、最近帧、普通cache、变点检测+合法前缀四组，测变点precision/recall、检测延迟和未来位置/深度误差。

**推翻条件：**变点与事件无关、延迟无法影响生成、清理旧记忆反而降低性能，或简单窗口达到相同效果。

**当前状态：**数据和事件标签尚不具备，暂缓主方法投资。

## 4. 最小实验路径（资源受限本机）

1. 先完成S90（RTMV归档配对数据恢复与索引协议审查）的剩余REVISE项：结构化超时回执、最终重定向身份校验、崩溃窗口去重/孤儿回收文档；不要在Gate 0 REJECT时偷偷启动新网络索引。
2. 通过Gate 0后，只构造一个小开发集和一个严格隔离测试集；先不训练新world model，使用冻结生成器或现有可运行消费者完成试验A的选择协议。
3. 只在试验A显示风险具有跨场景增量预测后，开展试验B；再根据失败类型执行试验C。试验D等动态数据具备后再做。
4. 预先写停止规则：若risk+utility不优于强空间/信息基线，或优势不跨场景，则停止GRC主张，保留负结果与诊断。

## 5. 证据边界

- **真实模型证据：** S86完整生成链和S87缓存解码/派生对照；仅有局部已见场景RGB统计，不能推出未来几何或长期泛化。
- **数据资格/协议证据：** S88（RTMV相机JSON元数据与静态投影数据资格检查）、S89（RTMV配对数据TLS接续失败审查）、S90（RTMV归档配对数据恢复与索引协议审查）。S90的512B头部不等于深度正文。
- **合成/数学证据：** 阈值非单调性、2×2逻辑反例、输出距离与真值效应反例；它们只检查逻辑，不能替代RGB-D或完整视频实验。
- **文献证据：** 本轮核读范围内未见“逐历史校准几何风险+固定消费预算+独立未来位置误差”的完整组合；“未见”不是文献空白证明。

## 6. 给主研究记录的最终判断

当前最值得推进的是**试验A：未来几何风险增量预测试验**，而不是立即实现复杂的conformal选择器。它能最快回答最核心的第一性问题：低风险历史是否真的带来未来几何收益。若该关系不成立，应停止把GRC写成方法；若成立，再用固定槽位反事实试验检验增量效应，最后才讨论风险校准和方法化。
