## 2. 我实际核到的事实

### 2.1 S86/S87 是有价值的基线反证，但不是 GRC 证据

- S86 接受的是一个已见静态场景、四个相关目标和一个噪声流中的保存数据消费与描述性 RGB MSE。四帧平均 MSE 为 G0 `0.13116666776908745`、Gpaste `0.09096801252375357`、Gterminal `0.09819160239669339`、Gguide `0.05242222252907684`。记录明确写着 `novelty_authorization=NONE`、`new_method_validated=false`，且没有几何准确率、感知盲评或长时动态证据。
- S87 的有限事后末步强度反证得到 Gterminal(λ=0.75) 平均 MSE `0.05116758166201706`，低于旧 Gguide `0.05242222252907684`；目标 22 仍更差（`0.074832433214` 对 `0.068264387690`）。它只否定“当前这项 MSE 必须由 50 步持续注入得到”，不证明记忆选择、未来位置预测或新方法有效。
- S86/S87 的图像和分数均来自一个已看过的静态场景、四个相关目标和复用的原噪声；S87 的 λ 包络是在看到旧结果之后提出，不能当作独立确认集。MSE 降低不能等同于几何真值、形状恢复或未来世界状态预测。

因此，前几轮从“重影仍存在”提出研究假设是合理的；从这些结果直接跳到“GRC-Memory 已经是创新方法”是不成立的。

### 2.2 S90 恢复的是数据访问，不是科学结果

S90 经 `127.0.0.1:7897` 对固定 RTMV archive 发出一条精确 512B Range 请求，返回 HTTP 206，解析出一个 `00134.depth.exr` tar header；没有取得 JSON/RGB/depth 三件套，没有模型、生成或几何评分。它只能把“HTTPS 路由暂时恢复”写成工程事实，不能写成数据集已可用于验证 GRC，更不能写成实验支持了假设。

### 2.3 原文和官方代码已经覆盖了候选的多个部件

已固定/读取的官方代码证据：

- Conformal Risk Control（commit `3eff946390a8f188b1e5ab700fce21a66a215e7c`）的 `core/get_lhat.py:8-12` 接收有序的校准损失表，求每个 lambda 的平均损失，并返回一个全局 `lambda_hat`。这不是对每个历史候选的三维风险向量做分位数，也不自动提供选择后条件保证。
- FisherRF active mapping（commit `8b196cd22b1f4030f205778ad14b23fbd796c3b7`）在 `tester.py:619-621, 794-799, 858-888` 计算 Hessian/Fisher 型 EIG、排序候选和路径；它是未来视角选择而非过去记忆选择，但必须作为信息增益类强基线，不能把“使用 EIG”本身包装成新意。
- Neural Visibility Field（commit `be6b583adde3a99f7bb0f638fed96ab2ead2f310`）的 uncertainty/visibility 渲染器显式使用 visibility 与熵；可见性和不确定性特征是已有设计空间，不能单独构成 GRC 的贡献。

对应的正式来源包括 [FisherRF (ECCV 2024)](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/2130_ECCV_2024_paper.php)、[NVF (CVPR 2024)](https://openaccess.thecvf.com/content/CVPR2024/papers/Xue_Neural_Visibility_Field_for_Uncertainty-Driven_Active_Mapping_CVPR_2024_paper.pdf)、[Conformal Risk Control (ICLR 2024)](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html)、[VMem (NeurIPS 2025)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/467655d26fcc207bca08915dc91964c6-Abstract-Conference.html) 和 [GeoVideo (NeurIPS 2025)](https://proceedings.nips.cc/paper_files/paper/2025/hash/536d18fbb454f80221465f1a42c6f389-Abstract-Conference.html)。这些来源证明“相邻部件存在”，不证明 GRC 已被完全重复，也不替代本项目的直接对照。

本轮窄检索还发现 **MemLearner: Learning to Query Context Memory for Video World Models**（arXiv:2606.31734，2026-06-30，当前按预印本处理）。原文明确把历史上下文检索用于预测未来世界状态，指出手工规则在遮挡和动态物体下失效，并用 query tokens 让预测 token 自适应查询历史 context；实验直接比较 VMem 与 Context-as-Memory。它不是 GRC 的逐字复现：GRC 候选强调显式几何风险、校准和固定预算，MemLearner 强调端到端学习查询。但它已经占据了“面向未来生成的自适应历史记忆选择”这一高层问题位置，故 GRC 的近邻风险应上调，必须在任何新方法实验前加入直接比较或明确不可比的输入/训练边界。[MemLearner 原文](https://arxiv.org/abs/2606.31734)

## 3. 逐条审查前几轮的核心说法

### 3.1 “New Problem + Method”——目前只能写 candidate

“未来几何状态，而不是当前相机接近度，决定记忆是否值得保留”是清楚、有潜在价值的研究问题。可是 New Problem 需要证明现有方法没有以相同的信息条件和目标评价它；Method 需要一个可运行的策略、输入限制、训练/校准过程和消费者闭环。目前仅有候选公式和名称，尚未满足任一要求。论文定位应暂写为 **candidate new problem with a candidate method**，而不是已成立的 New Problem + Method。

### 3.2 `q_i=Q_{1-alpha}(r_i)`——定义不完整

`r_i=(r_i^repr,r_i^depth,r_i^visibility)` 是向量，向量没有唯一的分位数。必须事先固定一个标量非一致性分数，例如经过开发集尺度固定的 `e_i = w^T r_i` 或集合损失 `L_i`，说明各项单位、缺失值、相关性和阈值。还必须说明校准答案来自何处、是否可在目标到来前获得，以及是 item-level、set-level 还是 policy-level 的保证。没有这些定义，所谓“几何风险上界”只是标签。

### 3.3 互信息目标存在未来标签泄漏和维度问题

`I(Y_future; H_S)` 只能用于离线训练/评价；测试时选择器不能读取未来真实状态、未来深度或目标答案。实际部署目标应写成由历史和当前查询可计算的效用代理，训练/校准和最终评价按 scene/time split 分离。`I`、风险和成本还必须放到可比较的尺度；原表达式中的 `-lambda Cost(S)` 不能凭直觉解释为同一量纲。

### 3.4 “1−1/e 型保证”不能预先写入

固定预算的贪心选择只有在明确的非负、单调、次模效用和相应约束下才有经典近似结论。未来预测效用通常是学习的、存在冗余和协同项的；风险惩罚、候选交互和选择后的分布变化会破坏次模性。必须先测边际增益或给出证明；否则删去 `1−1/e`，用小规模精确枚举与经验比较代替。

### 3.5 反事实记忆评价的公式测量的是敏感性，不是帮助

前几轮的

`tau_i = E[L_geo(Y(h_i), Y(h_i^-))]`

只比较删/换记忆后的输出差异；输出改变可能变好，也可能变坏。若要测“记忆 i 的帮助”，至少应在相同噪声、目标相机、其他记忆、步数和预算下定义

`tau_i(S)=E[L_geo(Y_hat(S\{i},xi),Y_true)-L_geo(Y_hat(S,xi),Y_true)]`，

并说明正号代表删除后变差。由于记忆之间有交互，单项效应依赖 coalition；必要时需报告二阶交互或 Shapley 类分析。离线反事实评价本身仍是测量协议，只有把它变成目标到来前可预测、且消费者真正使用的路由器，才可能成为方法贡献。

### 3.6 2×2 几何/外观表是诊断，不自动是因果分解

`E11-E10-E01+E00` 是二因素交互对比。只有几何和外观被明确干预、同一目标和随机流重复、操作不互相泄漏时，才可称因果交互；否则应称 controlled diagnostic。它很适合作为最便宜的第一道门，但不能预先写成机制发现或论文贡献。

### 3.7 在线变点、对象级记忆、信息瓶颈、普通 gating 都有较高近邻风险

共同合法前缀、变点检测、对象状态、集合覆盖、压缩记忆和门控路由分别有 HMM/BOCPD、object-centric memory、submodular coverage、information bottleneck、retrieval/router 近邻。它们可以作为后续机制，但“换一个名称 + 加 geometry feature”不足以构成独立贡献。

以下是**方向优先级**，不是已验证的性能分数；分数采用整数并标出证据状态，避免把模型直觉伪装成精确评价。

## 5. Fatal / Major / Minor 问题

### Fatal（对当前论文主张致命）

1. **没有方法实验。** GRC 尚未接入真实消费者，也没有 held-out future position/reprojection 结果；当前不能把候选名称写成 validated method。
2. **未来信息泄漏。** 直接用 `I(Y_future;H_S)` 选择测试记忆会读取答案；若不改成 past/query-only utility，所有性能都会失去解释。
3. **风险量和保证未定义。** 向量分位数、集合风险、校准分割和 coverage 口径都缺失；不能称 conformal upper bound 或安全选择。
4. **评价数据资格未闭合。** S90 只有一个 depth tar header，尚无匹配 RGB、depth、camera 和未来真值三件套；S86/S87 的 RGB MSE不能替代它。
5. **直接近邻尚未排除。** MemLearner 已报告与未来视频世界状态绑定的自适应上下文查询；若 GRC 只把 learned query 换成 risk gate 或 uncertainty score，审稿人可能判为已有问题上的普通替换。

### Major

1. 选择后分布与校准候选分布不同，直接套 CRC 可能失效；至少要按 scene/time split 在同一 policy 上做校准，并正确表述为边际期望风险控制。
2. 单项风险相加忽略记忆之间的冗余和协同；必须报告 joint risk、交互项或承认只是启发式。
3. 所有 selector 必须使用相同 eligible history、同一特征可见性、同一 `k`、相同生成/推理预算；不允许本方法额外读取未来或所有历史摘要。
4. 反事实实验要固定噪声、目标、其他记忆、步数和预算，并分离“输出变化”与“输出变好”。
5. 2×2 诊断必须有真正的 geometry/appearance intervention、重复随机流和多场景；否则不能使用“因果”。
6. 静态四目标不能支持动态长期、遮挡重访或跨场景结论；需要独立开发/确认场景和明确动态协议。
7. “3–5 天收敛、7–14 天 MVP、14–28 天论文结果”只是计划假设，不是依据当前数据的保证；数据访问、模型资源和本机 CPU 成本足以使它失效。
8. 必须把 MemLearner（以及其 VMem/CaM 对照）加入近邻矩阵，逐项记录是否使用相机/深度、是否训练选择器、历史预算、遮挡/动态划分和未来几何指标；不能仅引用摘要后声称方法不同。

### Minor

1. 论文中应把 RGB MSE、几何误差、未来位置误差和感知指标分开，不用“更清晰”概括它们。
2. 公式中 `q_i` 的标量化、cost 单位、阈值和缺失值规则需写入 protocol，而非留在文字解释。
3. “真实实验”“保存量复算”“合成反例”“代码加载”需在表格中分栏；检查数量不能写成样本量。
4. 近邻表应给出正式版本、公式/代码行和比较的信息条件；“没有搜到”不能证明首创。

## 6. 下一轮允许做的最小、可证伪路线

1. **数据门。** 完成一个同一视角或可严格配准的 RGB–depth–camera–future tuple；记录数据许可、单位、外参方向、无效深度和场景划分。若 RTMV 不能在有界预算内取得三件套，先用已有合格实拍数据，不把元数据探针当结果。
2. **四格诊断门。** 在开发场景上固定随机流和目标，实施可信/受扰 geometry × 普通/几何约束 RGB 的 2×2；预先定义 `H0: interaction=0` 与 `H1: interaction`，同时测未来重投影/位置误差和 RGB 指标。若交互不稳定或可信几何仍同样失败，停止把 GRC 当首要机制。
3. **选择器门。** 固定 eligible history、`k`、总 FLOPs 和训练信息，比较 recent、camera-distance、random、coverage、confidence-only、Fisher/EIG、utility-only 与 oracle；按 scene/time split，报告每场景结果和置信区间。
4. **校准门。** 先定义单一标量风险和 policy-level loss；在独立 calibration scenes 上运行完整选择策略，再在未见 scenes 评价。只有覆盖率和未来风险同时可复现，才可使用 conformal 术语；否则写 calibrated heuristic。
5. **反事实门。** 对同一 target 和 matched seed 做保留/删除/替换，至少重复多个 seed；报告 `tau_i`、输出敏感性和真实未来损失的区别。若效应不能由选择前特征预测，反事实结果留作分析，不升级为路由方法。
6. **次模门。** 小规模候选集做 exact enumeration；若发现协同反例，删掉 `1−1/e`，不强行使用 greedy 理论。

### 必须停止或降级的条件

- 几何风险与未来位置误差没有稳定、跨场景的预先关系：**停止 GRC 主线**。
- utility-only、相机距离或普通 coverage 在相同预算下解释全部收益：**停止新选择器主张**。
- 校准只在未选择候选上成立，选择后 coverage 失效：**删除 conformal 保证**。
- 2×2 没有可重复交互：**保留诊断，停止风险敏感生成故事**。
- 只在 S86/S87 已见场景和 RGB MSE 上获胜：**只能写 baseline/探索结果**，不能写顶会贡献。

## 7. 最终审稿意见

用户前几轮最有价值的判断是：先从自然失败中提炼问题、把未来几何状态作为目标、并要求固定预算和强基线。这些可以保留。必须撤回或降级的是：已经达到 PhD/CCF-A、候选的 8.0/8.5 精确评分、3–28 天的确定性时间表、把反事实输出变化叫作帮助、把二维交互表直接叫因果、以及把 `1−1/e` 和 conformal upper bound 当作已获理论保证。
