# 严格审稿式实验设计：Gate 0 受阻条件下的低成本下一步

**日期：** 2026-09-12（Asia/Shanghai）  
**角色：** 独立实验红队审查  
**范围：** 2×2 几何×外观诊断、固定槽位反事实、GRC-Pilot；不联网、不读取未来答案、不宣称方法成立。

## 结论

目前 Gate 0 为 `REJECT / DATA_NOT_AVAILABLE`，所以不能启动需要真实未来 RGB-D/三维真值的 S91 类实验。最有科学判断价值的低成本工作，是先把**“未来几何风险增量预测试验”**冻结成可执行的协议，并使用当前已有的 S86/S87 结果只做输入/失败类型审计；这不是替代真实实验。

建议下一项真实试验命名为：

> **S91（未来几何风险增量预测试验，GRC-Pilot）**：在相同历史候选池、固定槽位数和固定消费预算下，检验过去几何风险是否能预测未见未来查询的几何收益。

## 为什么不先做另外两个实验

- **S92（固定槽位反事实记忆增量试验）**需要可重复的未来几何损失。当前没有独立未来真值，任何 `tau_i` 都只能是合成或伪评分。
- **S93（几何来源×外观融合四格诊断试验）**可以在现有单场景生成器上做，但它主要解释重影/模糊来源，不能回答 GRC 选择是否改善未来几何；而且 S86/S87 已经提示 RGB 改善与几何改善可能脱钩。
- 因此，S93可作为数据具备后的故障诊断支线；S92应在S91显示跨场景关系后再做。

## S91 的最低可执行协议

### 输入和隔离

1. 研究单元按物理场景或轨迹拆分为 development/calibration/test，不能按帧随机切分。
2. 每个单元至少 6 个历史候选、3 个未来查询；历史时间严格早于查询。
3. 选择器只能看到历史 RGB/几何、历史时间、历史位姿和请求相机；不能读取未来 RGB、未来深度、未来位姿、未来 mask、未来误差或生成结果。
4. 选择前冻结候选池、随机种子、槽位数 `k`、总时间/显存预算和消费者版本；选择 ID、风险、utility、成本在答案读取前封存。
5. Gate 0 的 manifest 检查器通过后才释放未来答案。检查器返回 0 只表示资格合格，不表示 GRC 有效。

### 公平对照

固定同一候选池、`k`、消费者和随机状态，至少比较：

- random-k（固定种子，重复多个 seed）；
- recent-k（最近时间）；
- nearest-pose-k（相机位姿距离）；
- coverage-k（视锥/空间覆盖）；
- utility-only（只看 past-only 信息增益）；
- risk-only（只看几何风险）；
- risk+utility（候选 GRC 规则）。

如果实现和定义已经冻结，补充强空间/信息基线（例如 WorldPack/GIM-World 风格的相关性或信息剪枝）；不能只与随机和最近帧比较。

### 主指标

预注册一个主指标：未来查询下的三维位置误差；若数据只有目标深度，则明确降级为相机-Z 深度误差，并把像素 RGB MSE、覆盖率和失败率作为辅助量。统计单位为 scene/trajectory/query 的 paired difference，不把像素或历史帧当独立样本。

核心检验不是只看相关系数，而是比较：

- risk 分数与未来几何损失的 Spearman/分桶趋势；
- risk+utility 与每个强基线的 paired future-loss difference；
- 场景层 bootstrap 区间和每个 query 的方向。

## 推翻条件（预先写死）

出现以下任一情况，就停止把 GRC-Memory 写成已成立的方法：

1. risk 与未来几何收益在未见测试场景中方向不稳定，或区间覆盖零；
2. risk+utility 不优于 nearest-pose/coverage/utility-only，且公平计入特征计算成本后仍无优势；
3. 只有单一场景、单一相机轨迹或单一随机种子有效；
4. 选择器需要未来答案、目标 mask、未来位姿或生成后质量分数才能获得优势；
5. 增益只出现在 RGB MSE，三维位置/深度主指标不改善；
6. 删除/替换某条记忆改变了槽位数量或总计算预算，无法与基线公平比较。

## 低成本准备（真实数据到位前可做）

- 用现有 `verify_gate0_manifest.py` 审计一份真实 manifest；不创建伪造文件取得 PASS。
- 固化每个选择器的输入路径白名单、输出 JSON schema、seed、槽位数和成本计时器。
- 用 S86（单场景四目标几何条件注入基线实验）和 S87（末端引导强度控制与多步引导必要性反例实验）只建立失败标签：重影、目标间误差不一致、末端强度变化；不把它们改写成未来几何证据。
- 用 `two_by_two_logic_check.py` 保持逻辑单元测试；其输出标记为 `synthetic_logic_only`，不进入实验结果表。
