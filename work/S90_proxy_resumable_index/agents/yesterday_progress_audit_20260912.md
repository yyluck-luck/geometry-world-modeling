## 已证伪或已撤回

1. “本例达到 0.05242222 的 RGB MSE 必须持续 50 步引导”已被 S87 的有限反例否证：Gterminal(λ=.75) 为 0.051167581662，低于旧 Gguide 0.052422222529；但这是同一已见静态场景、四个相关目标、复用缓存的 RGB 结果，不能外推为几何收益、动态收益或新方法。
2. “低风险历史必然带来更低未来位置误差”、逐条 q_i 风险上界、直接 CRC 保证、通用 1−1/e 贪心保证均已收回。S90 只确认它们是待测假设或缺少前提；2×2 与阈值反例是人工逻辑证据，不是真实 GRC 效果。
3. “输出变化距离就是记忆价值”“2×2 零交互即可否定 GRC”“S87 λ 端点就是几何准确度干预”均已否定。正确方向是有符号的未来真值损失差、独立位置/深度观察器，以及把 2×2 作为重影竞争解释诊断。
4. RTMV 数据访问也没有形成创新证据：S88 得到相机 JSON，S90 仅成功传输一个 `00134.depth.exr` tar 头；没有取得 RGB/EXR 正文、可配对未来真值或几何评分。索引脚本仍受独立审查判为 `REVISE`。

## 待验证

1. GRC-Memory 是否比 utility-only、coverage、recent/distance、random 等同候选池同预算基线更能预测并选择对未来几何有帮助的记忆，仍无真实方法实现、独立未来几何误差或端到端验证。
2. 数据资格仍未通过：缺少严格配对的 RGB/深度/相机/时间/单位/坐标语义、独立划分、GT 隔离和缺失清单。RTMV 视角数字 ID 不能当连续时间轨迹；非零 tar 头也不能证明 EXR 可读或物理同步。
3. “风险指标有增量预测价值”与“选择策略实际获益”必须分开检验；CRC/风险校准只有在损失、交换性、单调策略族、校准单位等条件冻结后才可讨论。
4. 2×2 几何来源×RGB 合成诊断仍未执行；它不直接验证 GRC。S87 的重影、target22 失败和 VAE/warp/融合混杂仍需独立位置测量器拆分。
