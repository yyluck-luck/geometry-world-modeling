审查对象：`PROBE_PLAN.json` 与 `probe_proxy.py`。

结论：**仅允许一次传输恢复探针**，不等价于允许后续批量索引。

已核条件：

- 绑定 S89 已冻结计划 SHA、固定 commit、归档大小和续扫偏移。
- 仅一个 512 字节 Range，请求数写死为 1，curl 自动重试为 0。
- 保留系统证书校验；没有 `-k`/`--insecure`，没有修改系统代理或 TUN。
- 最终验收必须同时满足 curl 成功、HTTP 206、精确 `Content-Range`、正文 512 字节和安全 tar 头解析。
- 响应中的带查询 URL 只保存脱敏版本；不读取 NinjaDesktop 配置、订阅或凭据。
- 成功只说明传输和一个 tar 头可读；脚本固定写入 `scientific_result=false`、0 模型、0 JSON/RGB/depth 请求。

尚未满足：独立 Agent 源审当前仍在等待；即使本探针成功，后续可续索引也必须另行审查和冻结。
