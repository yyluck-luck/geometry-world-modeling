# Persistent physical evidence versus the latest event

Status: source-only hypothesis; NO_METHOD_SELECTED. This batch does not use S76/S77 results. Two accepted papers were verified; one new preprint was screened but not used as established venue evidence.

## Closest collisions

**Physion++ directly occupies much of the motivating problem.** Its diagnostic phase exposes material properties before a later contact prediction. Paired trials can share the first prediction image yet have different physical outcomes. Some scenarios rearrange objects behind a curtain while their physical properties persist. Thus, the most recent visual discontinuity need not erase useful earlier evidence. Its comparisons include observation with and without diagnostic interactions, and a fully observed readout control. These are separately trained readouts, rather than an equal-frame, unchanged-consumer memory exchange. The benchmark uses simulated TDW scenes; a privileged DPI-Net condition receives physical states/properties. Neither is an equal-information real-video baseline for our project. [Tung et al., NeurIPS 2023, §§3–4](https://papers.neurips.cc/paper_files/paper/2023/file/d3e8011c912e651ab2a76e7935a1e464-Paper-Datasets_and_Benchmarks.pdf).

**PHYCINE already models the distinction between transient motion and persistent properties.** Its object-centric predictive representation includes velocity, mass and charge, with explicit interaction mechanisms. Property inference uses an observation window and iterative prediction-based inference; it is not a free selector of a few RGB frames. In the inspected formulation, mass and charge persist during prediction. This defeats a broad novelty claim based on merely remembering physical attributes separately from recent motion. We did not inspect its complete evaluation protocol and cannot infer whether a particular deployment window would cross our future cutoff. [Tang et al., CVPR 2023; inspected author v3](https://arxiv.org/pdf/2303.01869v3).

## A concrete, falsifiable question

Can a fixed-budget history selector preserve **the earlier diagnostic interaction of the queried object**, after newer events involving other objects, better than a simple task-conditioned physical-property estimate? The question concerns which past information reaches an unchanged consumer. It does not propose a new filter, change-point detector, or physical predictor.

An elementary counterexample to “same pose and recent motion suffice”: consider one-dimensional impacts against a stationary wall, no unmodelled force, and two visually indistinguishable balls with different restitution coefficients e. Before the next impact, position and incoming velocity can agree over the recent window; after impact, v_out = −e v_in differs. A previous visible impact identifies e = |v_out/v_in| under these assumptions. A newer unrelated event contains no such evidence. This is ordinary parameter identification, not a novel mechanism. Unknown forces, uncertain identity or an unseen earlier impact can destroy identifiability.

The strongest cheap falsifier is an ordinary object-identity tracker plus a scalar property estimate from the last informative contact of that object, followed by task-conditioned frame selection. Compare it with latest-event, recent-motion-plus-coverage and the proposed selector using the same k frames, feature access, consumer and denoiser budget. If a filter scans all history, charge its preprocessing and memory costs to every relevant comparison; trajectory/property annotations cannot be given to only one arm. Define the task and eligible past window before seeing outcomes.

The hypothesis fails to establish an advantage if the simple property baseline matches it, if the latest event already provides the relevant evidence, or if even the diagnostic-history condition does not change the consumer's prediction. The last outcome implicates consumer use or observability rather than proving selector failure. Separate physical-outcome consistency from camera-response consistency; a correct view change is not evidence of correct hidden-state inference.

## Cheapest local real-data possibility and stop condition

No local real sequence is certified here as a paired hidden-property/contact test. Previously documented TUM desk data do not establish this intervention; the coffee-martini container/calibration records alone do not establish informative repeated contacts or controlled forces. No new media were opened. The smallest prospective real-data candidate would be a short fixed-camera repeated-bounce sequence with tracked object identity, an earlier diagnostic impact and a later held-out impact, with recent pre-impact state matched or explicitly conditioned. It still needs actual input feasibility and confound checks before any generation. If only synthetic Physion++ scenes qualify, label that study synthetic; do not promote it to a real-video result or substitute it silently.

A third screened author project, “Can Video World Models Track Unobserved World States?” (arXiv:2608.30692), addresses hidden-state persistence in controlled synthetic tasks. Only its abstract/project text was read; conference acceptance and released official code were not verified. It supplies additional collision pressure, not evidence that this particular fixed-budget selection test is solved. Absence of an exact reported comparison is not novelty.
