## Smallest defensible next step, if root chooses to continue

Inspect Perception Test **annotations only**, starting from its public sample, for object identity, earlier informative state, an intervening action unrelated to that object, and a provided reveal cutoff. Prefer a single containment/cup-state question with a genuine observed suffix. This is a state-memory diagnostic; do not relabel it as restitution inference. Freeze eligible IDs and temporal rules before viewing suffixes or model output. If the sample contains no eligible case, record that outcome; do not concatenate unrelated clips to manufacture a continuous causal history. Same recent pose/motion or paired causal interventions remain additional unverified requirements.

The ordinary strong baseline is identity plus a compact state estimate (for example, which container holds the item); retain the scalar-property estimator for a genuinely identified physical-property task. All selectors receive the same eligible past and feature access, k history frames and unchanged consumer/denoiser budget. Ground-truth future boxes, action labels or object state are evaluation information, unless supplied equally and explicitly to all arms. If the simple state tracker matches the proposed selection or the consumer ignores even informative full history, no new selection mechanism is established. This is not a claim that a dynamics-capable generator has been found or qualified.

## Actual access evidence and remaining gaps

Two anonymous GETs saved only documentation/metadata: README **30,386 B** and cutoff mapping **39,498 B**, total **69,884 B**. The mapping parses as **2,185 keys**; the paper reports 2,184 training videos. Treat that as a version/identity discrepancy requiring an actual annotation join, not proof of an extra usable training video. No per-video eligibility was inferred from the mapping.

The video-sample HEAD returned HTTP 200, `Content-Length: 225370639`, and advertised byte ranges; it transferred **zero archive body bytes**. The separate annotation-sample HEAD returned curl 35 / TLS failure and was not retried. Range support is advertised, not experimentally validated. Thus public video access has header-level evidence, metadata access has body-level evidence, and full media retrieval/decode remains untested. CoffeeMartini is not relabelled as a passive-bounce dataset; its local footage was not reopened.
