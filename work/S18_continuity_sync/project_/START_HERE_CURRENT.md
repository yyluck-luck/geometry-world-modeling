# 现在的研究在做什么

我们在研究：**AI记住一个房间后，后来照片带来的新几何，什么时候应该改写旧记忆？** 更新太少会保留错误，更新太多也可能让不同照片提供的几何互相遮挡。

项目已从“让模型跑起来”，推进到“用真实照片和距离测量，检查改写究竟有没有好处”。当前阶段的完整时间与接手入口以 [研究记忆](../RESEARCH_MEMORY.md) 和 [研究日志](../RESEARCH_LOG.md) 为准。

## 这轮已经有的真实结果

| 实验 | 做了什么 | 得到什么 |
|---|---|---|
| S15B：几何改写 | 模型实际看12张照片，对4个位置提出新几何；再用后来8张照片筛选，最后用4张传感器深度评分 | 普通照片代价筛选的δ1从66.04%到67.11%，提升约1.07个百分点。它是已有方法的小幅单段信号，不能宣称原创算法 |
| S15C：另一数据来源 | 用Bonn实拍的已有模型预测，前4张深度统一单位，后16张深度评分 | 有1张完全没有真实深度，完整16帧主成绩保留NA。15张可评分帧均值65.22%，按像素合并却94.14%，提示只报平均数会掩盖困难情况 |
| S16：来源之间的影响 | 用已保存的真实预测，比较“只改一个来源”和“多个来源一起改” | 已真实完成并复算。发现聚合收益随其他来源改变，但目前符合普通投影行为，未形成新方法 |
| S17B/C：真实512模型与建图 | 在本机实际处理两张Bonn实拍，并调用VMem内嵌几何入口完成400步全局对齐 | 已运行且独立复算通过。原始点云含393,216点；这是已有建图组件的结果，尚无GT精度和完整视频 |

δ1是预测与真实深度的比值落在0.8到1.25之间的比例（严格边界），越高越好。S15B把预测缺失计为失败；S15C没有传感器答案的位置无法判断对错。

## 怎样争取更有分量的创新

目前“比较新旧几何的照片误差再决定是否修改”已有DTAM、DSO等直接先例，所以不会把它换个名字当新方法。下一步要寻找具体且可重复的失败机制，再设计能解决它、同时超过公平强基线的方法。

Supervisor的 `idea-evaluator`、`vibe-research-workflow`，本地Claude的 `sci-scientific-critical-thinking`，以及 `figure-designer` 分别用于问题排重、实验执行、科学批判和图表设计；并行agent互相审代码、复算和核原文。没有调用Claude模型。

博士与CCF A类论文标准是质量目标。新颖性、跨场景收益、完整视频质量和导师认可仍需后续证据，不能靠保证或自评分完成。30分钟接续任务会按最新主账检查并推进；本地文件保留实际时间、失败和下一步。

最新补充：公开512权重完整下载、作者SHA核对、两张实拍模型及VMem嵌入几何都已真实完成。S17B独立检查第一次因审查者漏读网格规则失败，原记录保留；修正检查器后通过，没有重跑模型。S17C整个程序约33.42秒，400步几何优化；独立70数组复算通过，全部置信度清理结果精确一致。
