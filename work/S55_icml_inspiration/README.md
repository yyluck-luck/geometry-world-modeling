两篇的对象分别是**历史条件的score**和**学习算法适配后的外推**；输入粒度分别是历史帧子集/噪声等级和同状态/异状态的任务输入。我们当前对象是**固定VMem中同一来源的语义与latent消费**。这个对象差别并不自动构成创新；四条件消融、来源归因和非加性交互均是已有通用工具。

## 数学怎么借鉴，哪里不能搬

HG的§5式(5)可简写为

`s_HG = s_empty + Σ_i ω_i [s(H_i, noise_i) − s_empty]`。

它组合的是同一采样状态下的score估计，不能据此把CLIP均值和latent当作相同单位的估计器。附录A.3的广义最小二乘解释依赖零均值、联合高斯误差及可用协方差等强假设；不是任意融合的最优性证明。附录A.2的频率收缩形式为`S = Σ(Σ + σ²I)^−1`：低能量方向更受抑制。作者明确指出，加高斯噪声本身不保证低通；自然图像谱假设不能直接套到CLIP特征维度。[正式PDF](https://raw.githubusercontent.com/mlresearch/v267/main/assets/song25b/song25b.pdf)

该文§6及D.2把架构/训练目标与推理指导分开比较，并检查一致性和运动的取舍。因此我们不能只看回访像素接近，就把复制旧帧当作成功；也不能把改变历史条件后画面变化当收益。

第二篇§2以`φ(x)`表示假设的真实状态：同状态应有一致外推，不同状态应可区分；一般化式(3)比较跨小数据集的输出可预测性，并用已知状态的oracle校准。§4再与更粗的合法下一步集合比较，排查任务捷径。这里的量依赖多次适配、小任务分布和状态定义，**不能把本项目一次视频的MSE直接称为该文的inductive-bias指标**。正式PDF与arXiv旧版的图号及部分表值有差别；本报告不混抄数值。[正式PDF](https://raw.githubusercontent.com/mlresearch/v267/main/assets/vafa25a/vafa25a.pdf)

## 只保留一个判别改进：在同一个去噪起点比较四条件

S53已经保留的四条件为：原条件`00`、只改语义路径`10`、只改latent路径`01`、同源同时改`11`。其最终视频差分

`D_Y = Y_11 − Y_10 − Y_01 + Y_00`

非零只能排除该输出上的可加关系。**它还不能把非线性定位到两条路径共同消费的那一步。** 一个完全普通的反例：先相加`z=a+b`，再经过`Y=z²`，内部加法交互为0，最终差分却为2。这次已用整数精确复算，见`ALGEBRA_RECEIPT.json`；这是标准反例，不是新定理。

因此建议在未来S53原定四条件中，加一项首个去噪调用的记录：固定相同的目标起始噪声、相机、时间步和其他条件，对实际共同消费函数的输出`u_ab`计算

`D_u = u_11 − u_10 − u_01 + u_00`。

不用另开一套实验，也不增加完整视频运行数。这里的`u`先按实际VMem接口命名为**去噪输出**，不擅自当成HG的score；若有CFG，记录比较发生在CFG前还是后，四臂必须相同。源码当前在`pipeline.py`调用`do_sample`，`sampling.py`先调用denoiser再调用guider；这只是读取源码确认候选观察位置，尚未实现hook或证明能无扰记录。

判别含义：若最终`D_Y`非零而起点`D_u`未超过原条件重放波动，就不能把该结果当成“起点共同消费器存在非加性交互”的证据；非线性可能在后续环节产生。若起点已非零，只说明该固定状态的局部非加性，仍不证明冲突、几何依赖或画质损害。即使两个差分都是0，线性抵消仍可能存在。单一起点为0也不能证明所有后续时间步无交互。

**成本与停止条件：** 首选附加到S53已有六次完整运行（三次原条件重放及三个干预臂），新增0次模型前向，仅保存/归约既有调用的输出；记录开销尚未实测，必须先证明观察器不改变模型结果。若起始目标噪声不一致、不同臂接口并非同一位置、无法无扰保存，就不解释这项比较。S53六次两批CPU运行的已有外推约4.47小时仍只是估算，本次没有启动该队列。不能为了这个观察点再重跑已成功C1/C2。
