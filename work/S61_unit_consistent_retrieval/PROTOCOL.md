# S61 检索渲染入口的单位一致性适配

这是普通基线工程修复的独立源码包，不是新方法。当前只运行人工数值测试，不读取 S60/C2 实际数值载荷或 RGB，不加载模型，不接入 pipeline，不改旧文件。root 后续另行以保存数据验收与安排不同作者审查。

固定接口：`render_in_canonical_units(renderer, surfels, pose, focal_lengths, **renderer_kwargs) -> (maps, receipt)`。renderer 是调用者显式传入的已绑定原函数；其余参数对应原 renderer。姿态已是该 renderer 要求的坐标约定，本适配器不再翻轴。surfel 使用原对象的 position、normal、radius 属性及任意原有 ID 字段；输出索引顺序不变。

从全部输入点计算 `q_i = inv(R) (X_i-t)`。仅用所有严格正的 `q_i.z` 的中位数定义正长度单位 u；不以视野、法线、来源或预计匹配成功过滤这批点。将全部点位置、全部半径、相机平移分别除以同一 u，保持 R、焦距/主点、法线、ID 及顺序的数值不变。所有传给 renderer 的对象都复制，避免改变输入缓存；renderer 仅被调用一次，异常直接传出，没有重试或选帧兜底。

相机/几何/焦距/主点必须有限；R 必须在浮点容差内为正常旋转，半径非负，图像尺寸为正整数。空几何或没有正相机深度明确抛出 `EmptyPositiveGeometryError`，其他无效数值抛出输入错误，均不调用 renderer。零法线/零半径允许保留给原 renderer 原样处理；没有额外替换或删除。有限浮点表达能力之外的换算明确失败，不主张任意极端浮点数都稳定。

返回的是原 renderer 的三张数值图对象，不把 depth 乘回 u。receipt 显式标记 `dimensionless_camera_depth_in_positive_median_units`、u、倍率、点数及正/非正深度数。深度加权消费者中的 `1+depth` 现在有明确的无量纲含义；这**有意改变检索深度单位**，并非与历史运行逐值等价。原 renderer 的近/远裁面与栅格化算法不改。本函数不证明原图或相机具有物理公制标定。

唯一一轮有限测试固定如下：非单位 R、非零 t、4 个正深度和 1 个负深度点，全部位置/平移/半径共同乘 `1e-9, 1, 1e9` 三个事先给定正倍率；以注入的简单数值函数及调用记录检查正深度中位单位、相机投影、半径端点投影、索引/法线/ID 保持、返回图不被再换算且调用数为 1。投影绝对容差 `1e-9 px`、相对 `1e-12`，归一化几何绝对容差 `1e-12`、相对 `1e-12`。另用会改写自身输入的 spy 验证原对象无修改，并检查少量有代表性的无效输入及渲染器异常只调用一次。

测试限定为共享正长度倍率，R 和非零 t 已存在；不要求原圆盘离散多边形在任意额外世界旋转下逐像素完全不变。没有实际原 renderer、保存几何验收、完整第二批或质量评分。未来生成如采用本适配器，必须明确声明为新的基线变体，旧失败记录不能改写。
