# S31：保存深度的共同尺度与非均匀变化诊断（准备，未执行）

## 固定问题和操作

对 C2t、C2a 各自的保存初点 `D0`（S29）与第 400 步终点 `D400`（S30），固定全部 4×384×512=786432 像素。原文件为 FP32，诊断在 FP64 运算：

`v = log(D400) − log(D0)`，`mu = mean_all_pixels(v)`，`k = exp(−mu)`，`D* = k × D400`。

每臂仅一个共同正标量，四帧共享。没有逐帧尺度、加性 shift、GT 拟合、置信度/远点筛选或优化步选择。所有初末像素必须正且有限；任一个不满足便失败保留，不丢像素后继续。D* 保存 FP64，以明确记录此项输出变换，没有转回 FP32 的额外舍入。它在对数深度中去除相对 D0 的全局平均变化；不是保证米制真值、物理形状不变或优化器尺度自由度控制。

设每帧 n 个像素、帧均值 `mu_f`、总 N=4n。完整平方和恒等式为：

`sum(v²) = N·mu² + sum_f[n·(mu_f−mu)²] + sum_f,p[(v_fp−mu_f)²]`。

三项分别描述共同均值、帧均值之间差异、帧内残差；另核 `sum((v−mu)²)` 等于后二项之和。恒等式数学上精确，FP64 计算有舍入误差，保存各项实际残差；固定平方和比较 abs=1e−9、rel=1e−12。全像素另核 `log(D*/D0)` 按独立差分形式计算等于 `v−mu`（逐元素 atol=rtol=1e−12），共同均值绝对值 ≤1e−12。分解保留总数、每帧数、每项平方和/均方/对数 RMS/占比和帧均值、残差 RMS、极值。总平方和为 0 时占比为 null，不能除 0 或声称已解释某百分比。

完整 v、D*、四帧均值、mu、k 保存到每臂 `diagnostic_arrays.npz`。这些量只说明非均匀的对数深度变化；帧间和帧内变化可能包含误差修正或其他变化，不能直接命名“物理形状破坏”。像素也不是独立样本，不做显著性检验。

## 封存与评分顺序

1. root 全文审后单独冻结本合同和代码/协议 SHA。执行须显式传正式合同及 SHA，拒绝候选状态、已有结果目录和重复运行。先核既有 S30 producer/scorer/独立复核 PASS、各自 S29 初点身份、直接源及选定历史产物完整字节。D0/D400 身份必须同时匹配生产记录、S30 主评分和独立复核。
2. 先写 input_seal，再解码四份保存 depth，算完并保存**两个臂**的全量分解与 D*；写 normalization_seal，重核原输入和新文件 SHA。此时没有读取新的 GT 字节。研究者早已见过 S30 结果，此工程顺序不恢复盲测状态。
3. 两臂 D* 全部封存后才读取并封存四张原 GT 字节，再调用未改动的冻结原 `score_s26b_consumer.py` 中 `load_sensor_depths`、`depth_metrics` 和 `aggregate`。原函数的 `nearest_grid` 是 640×480 到 512×384 的中心最近邻，sensor 除 5000 成米；全部正有限 GT 作分母、不截远点、不按 conf 筛、不做 GTscale。
4. 重新从已封存的 D* 文件取评分 depth，共 8 行、两个完整四帧等权均值；保留 AbsRel/RMSE/严格 δ1/无效预测与完整计数、null 规则。只对 D* 新评分；原初/终点评分完整导入已 PASS 的 S30 metrics JSON，保存其路径/SHA，绝不重新评分这些端点。可报告 D* 均值减原初/终点均值，但不把导入数值算成本轮新算。
5. 最后核全部读取输入与 D* 的 SHA 保持，保存 PASS/FAILED receipt、完整 JSON/CSV、四 GT 读取回执。失败保留中间产物，不自动延长预算、改容差、调尺度或重跑。

## 资源与解释边界

外部 caller 单次执行，CPU1、180 秒、2 GiB RSS；脚本设置常见数值库线程环境为 1，时间/RSS 由 root 的监督器实施，不自行启动调度器。0 新模型、MST、GA、Adam、backward。解码原 GT 四张一次（为保持原 loader 不改，预封存读取字节和 loader 自身读取字节分开，不能称只发生四次文件读取）。

即使 D* 指标更好，也只支持这组已见 common4 的**事后无 GT 输出归一化**有描述性影响；它借助初点作为参考，不是优化器内部约束的因果实验，不是可部署新方法或生成视频收益。若几乎没有非均匀变化，照实报告，不能据残差接近 0 声称物理尺度机制已完全解释；若残差明显，也不能不经真实几何消费者验证就称记忆或形状被破坏。
