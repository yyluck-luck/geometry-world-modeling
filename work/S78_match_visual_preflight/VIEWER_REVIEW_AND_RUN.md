## 供独立作者审查的行为

脚本只有 Python 标准库依赖。运行时要求明确的输入索引 SHA；核对固定 source ID 84、210、317、536、935、1017 × real/A0/B 共 18 条，不允许漏项、重复或已填评级。坐标必须属于原 576×576 域；来源坐标在三臂相同。没有残差计算或匹配调用。

未来实际运行时将读取四个原 PNG 的字节，比较旧合同 SHA 并核 PNG IHDR 中的 576×576 尺寸；不会解码像素或重编码图片。验证通过才新建输出目录，通过四个匿名符号链接引用原文件。任何身份不符、缺图或输出目录已存在都会退出。运行失败后的已有目录保留；不覆盖/删除旧目录，不重建缺失图，不写 S77。

显示顺序固定为 source ID 递增的 G01–G06，每组 C01、C02、C03，合计 P001–P018。匿名条件采用固定置换 C01=B、C02=real、C03=A0；这不是随机化。该对应关系只写在准备者说明和单独映射文件中，HTML 可见界面不显示 arm、原 source ID、target22、残差、正负号或方法结论。源码/符号链接仍可追溯原路径，不能声称安全隔离或完全盲化。

每项并排显示共同来源 S00 与匿名目标：全图保持原评分 576×576 CSS 像素，窄屏横向滚动，不缩小。局部窗口**总边长 64 原图像素，半宽 32**；中心按非负坐标 `floor(v+0.5)` 四舍五入，恰好 .5 向上，不采用 Python 银行家舍入。窗口为 `[cx−32,cx+32) × [cy−32,cy+32)`，统一最近邻放大 2 倍到 128×128 CSS 像素。靠边时保留这个中心、以常量灰 `#d9e0e5` 显示图外 padding，不移窗、不拉伸。圆环仍定位于原保存小数坐标，局部位置为 `64+2×(v−c)`，不把舍入后窗口中心冒充匹配点。圆环中心透明，仍可能遮挡环边纹理。CSS `image-rendering: pixelated` 在固定 2 倍整数放大下用于最近邻显示；实际浏览器显示仍需下一轮视觉检查。显示选择不写回图片，也不构成科学阈值。没有 canvas、图片另存、网络请求、外部库或 JavaScript。

18 项静态排列，不提供筛选、删项、评级、保存或自动判定功能。实际评级必须在下一轮按已审规则另存，不能把查看器构建回执称为视觉 QA 完成。`BUILD_RECEIPT.json` 会区分“4 次图像字节身份检查”与“0 次像素解码/评级/生成”；该计数描述脚本行为，不代表浏览器之后未加载图片。
