# R158 Corrected Owner/Reviewer Packet for a Future Synthetic-Only Benchmark

**Access date:** 2026-09-24  
**Evidence boundary:** R154 merged with all four R156 fixes. No broader search, code/data/fixture/runner execution, GPU, Slurm, evaluation replay, receipt, or flag mutation was used.

## Purpose and authorization boundary

This packet is a readiness checklist for a separately authorized synthetic-only benchmark-construction project. It does not claim benchmark results, method novelty, or field-wide novelty. It cannot reopen method END-LINE and preserves `new_method_validated=false` and `novelty_authorization=NONE`.

## 1. Packet identity, ownership, and scope

- [ ] Packet ID, revision, creation date, and packet content hash are recorded.
- [ ] A named owner signs responsibility for oracle custody, manifest immutability, scorer freeze, denominator release, and stop enforcement.
- [ ] A separate reviewer is named for independent rerun and has no oracle access before prediction sealing.
- [ ] Scope is synthetic-only; protected project data, real evaluation data, current R140 runner paths, GPU/Slurm jobs, receipt edits, and flag changes are excluded.
- [ ] The requested decision is readiness review only, not a result or method claim.

**Stop:** missing owner, reviewer, scope, packet hash, or requested decision => `NOT_READY_OWNER_PACKET`.

## 2. Split public and oracle manifests

- [ ] A **public manifest** contains anonymized case IDs, visible geometry/camera inputs, producer revision, scorer inputs, dimensions, and a map content hash needed for integrity.
- [ ] The public manifest contains no frame tag, hidden stratum, label-bearing filename/path, oracle-derived exception, or deterministic metadata that reveals the label.
- [ ] An **oracle manifest** contains hidden true frame `h`, declared hypothesis set `H`, depth-unit/schema truth, and one of four disjoint strata; it is held separately and hash-committed before scorer release.
- [ ] The owner documents a metadata-sanitization audit covering map headers, filenames, paths, source details, logs, exception text, and hash conventions.
- [ ] A reviewer verifies that public-map integrity hashes remain identical without exposing oracle fields.

**Stop:** any public artifact reveals `h` or stratum => `LEAKAGE_STOP`.

## 3. Auditable two-custodian hidden-label custody

- [ ] The oracle custodian commits an opaque/encrypted oracle manifest and records its hash and commit time before scorer freeze.
- [ ] The scorer custodian receives only the public manifest and submits a prediction hash before oracle release.
- [ ] Access logs, commit order, scorer configuration hash, and prediction hash are preserved for review.
- [ ] Oracle release occurs only after prediction sealing; no predictions are regenerated after reveal.
- [ ] The independent reviewer checks commit order and label-release timing without receiving labels early.

**Stop:** missing commit order, access log, prediction seal, or independent custody => `HIDDEN_LABEL_CUSTODY_STOP`.

## 4. Oracle independence from producer self-description

- [ ] Hidden `h` and out-of-hypothesis status are generated by a trusted synthetic wrapper or controlled transform committed before the producer call.
- [ ] Producer-declared tags are treated as visible comparator inputs, never as oracle truth.
- [ ] The scorer cannot infer `h` from producer self-description, source paths, map metadata, or deterministic source details.
- [ ] The reviewer receives public artifacts only until all predictions are sealed.

**Stop:** hidden truth derives from scorer-visible producer declaration, or reviewer can infer `h` before sealing => `ORACLE_INDEPENDENCE_STOP`.

## 5. Source and producer manifests

- [ ] Each producer family has an immutable source URL/revision or source hash, license/access note, and reproducible invocation description.
- [ ] The source record binds producer input pose convention, output frame semantics, depth units, ID/depth schema, intrinsics, image size, pixel center, rounding, z-buffer, crop/resize, and source hashes.
- [ ] `H = {RAW_CV, TRANSFORMED_G}` is frozen for the two-query scorer; canonical/common frames are explicit out-of-hypothesis cases.
- [ ] Every field is marked as measured producer contract, synthetic-generator truth, or unknown; unknown fields are hard stops.

**Stop:** unknown API, frame tag, units/schema, or source revision => `NOT_READY_SOURCE_PINNING`.

## 6. Immutable map evidence

- [ ] Exactly one producer call is recorded per case, with independently auditable call count.
- [ ] One content-addressed map contains immutable ID map, depth map, dimensions, intrinsics, units, and public metadata.
- [ ] Every query cell references the same map hash; branch-specific map regeneration is forbidden.
- [ ] A deliberate regeneration sentinel is retained as a negative control and excluded from valid FUP/AReject denominators.
- [ ] Map write/read boundaries and raw evidence needed for independent hash verification are preserved.

**Stop:** unequal map hashes, call count other than one, missing map metadata, or regeneration contamination => `MAP_IMMUTABILITY_STOP`.

## 7. Geometry and held-out split

- [ ] The suite contains multiple asymmetric geometries and nontrivial camera poses; the R140 24-point fixture is only a seed.
- [ ] Intrinsics, image sizes, pixel centers, depth units, and rounding vary only under a pre-registered matrix.
- [ ] Held-out geometries and poses are fixed before outcomes and are not selected after pass/fail.
- [ ] Each case has a fixed ID denominator and retains positive-z, in-bounds, exact-ID, depth-residual, missing-output, zero-depth, non-finite, and symmetry controls.

**Stop:** one fixture only, no held-out split, outcome-based case selection, or variable denominator => `GEOMETRY_SPLIT_STOP`.

## 8. Scorer and control freeze

- [ ] Query equations, `RAW_CV`/`TRANSFORMED_G` hypotheses, depth conversion, tolerance, rounding, pass rule, and `H2_UNIDENTIFIABLE` rule are frozen before oracle release.
- [ ] Compare ordinary declared-convention round trips, residual minimization, and fail-closed same-map 2x2 scoring.
- [ ] Threshold-sensitivity values are fixed independently of outcomes; no best-residual threshold search is allowed.
- [ ] Include unit/schema perturbation, branch-regeneration, canonical-frame, both-pass, both-fail, and metadata-leakage controls.
- [ ] Predictions are sealed before aggregation and cannot modify maps, manifests, scorer, or oracle files.

**Stop:** post-hoc threshold, query, hypothesis, unit conversion, scorer, or map change => `SCORER_FREEZE_STOP`.

## 9. Four disjoint oracle strata and estimands

Pre-register disjoint strata:

- `in_H_correct`: true frame is in `H` and declaration is correct;
- `in_H_misdeclared`: true frame is in `H` but declaration is wrong;
- `out_H_canonical`: true frame is a known canonical/common frame outside `H`;
- `out_H_unknown`: true frame is intentionally undocumented but generator truth is retained.

Define and report separately:

- `FUP_s`: probability of exactly one convention certified within stratum `s`;
- `AReject_s`: probability of `H2_UNIDENTIFIABLE` within out-of-hypothesis stratum `s`.

- [ ] Case-level numerators, denominators, exclusions, failures, and missing outputs are published for each producer family, stratum, and held-out split.
- [ ] Denominators are fixed before scoring and never reduced for query failure or missing cases.
- [ ] Confidence intervals and interval method are pre-registered for every primary stratum.
- [ ] In-hypothesis unique-identification accuracy and both-pass/both-fail rates are reported alongside FUP/AReject.

**Stop:** undefined conditioning population, mixed or outcome-dependent strata, hidden denominator change, dropped failure, or missing uncertainty interval => `ESTIMAND_STOP` or `STRATUM_STOP`.

## 10. Independent rerun and review

- [ ] Reviewer receives public manifests, source hashes, scorer version/hash, and map hashes only.
- [ ] Reviewer cannot access oracle labels until all predictions are sealed.
- [ ] Rerun checks map call count/hash, per-case tables, stratum membership after release, denominators, and aggregate intervals.
- [ ] Discrepancies remain failures with case IDs and cannot be repaired by relabelling or deletion.
- [ ] Packet defines release agreement and a written explanation for every discrepancy.

**Stop:** no independent reviewer, hidden-label custody failure, or irreconcilable rerun discrepancy => `RERUN_STOP`.

## 11. Unresolved limits and impossible requirements

- The bounded cited-source set cannot establish that no external benchmark already reports FUP/AReject-like quantities; field-wide novelty remains unproven.
- A producer with genuinely undocumented semantics cannot supply trustworthy hidden `h` from its own output. The synthetic wrapper must generate the label, or the case is `UNKNOWN` and excluded from a claim requiring truth.
- The two-label hypothesis `H` cannot represent every canonical or learned frame; such cases must remain out-of-hypothesis and be scored for rejection.
- A confidence interval cannot repair an undefined denominator, map regeneration, label leakage, or oracle dependence; these are hard stops.

## 12. Owner decision

- [ ] All fields pass and the owner signs `READY_FOR_SEPARATE_BENCHMARK_CONSTRUCTION`; or
- [ ] Any field fails and the owner records the exact stop branch, leaving protocol-only status.

Until the first option is separately authorized and signed, do not implement or execute the benchmark. Preserve method END-LINE, `new_method_validated=false`, and `novelty_authorization=NONE`.

## 13. Machine-readable evidence-object schemas

Schema rules:

- Hash fields are lowercase SHA-256 strings.
- Timestamp fields are UTC RFC 3339 strings ending in `Z`.
- PASS/FAIL fields are reviewer assertions over retained evidence; they do not replace raw evidence.
- Missing required fields, failed checks, or chronology violations trigger the fixed stop branch.
