# Proposal 对齐与创新优先级审查（2026-09-15）

**审查身份：** 独立审稿式子代理。实际审查记录时间：2026-09-15T00:44:54+08:00。依据项目主记忆、`docs/PROPOSAL_PROGRESS_CURRENT.md`、`docs/RESEARCH_HANDOFF_CURRENT.md`、S99/S100 冻结材料及已有近邻原文审查；不把本报告当作方法验收。

## 1. 先给结论

目前最重要的创新缺口不是再增加一个“几何风险分数”，而是证明一个**部署时可计算、不会读取未来答案、在真实记忆预算下能够预测未来几何收益的决策机制**。这正好对应原 proposal 的核心难点：长时程世界建模中，历史观测如何被保留、替换或拒绝，才能改善后续视角的几何一致性。

截至本审查，`new_method_validated=false`、`novelty_authorization=NONE`。GRC-Memory 仍是候选问题，不是已成立方法。S99 已否定“低历史不一致度在固定改写预算下平均优于 confidence”这一局部主张；S100 只发现少量条件依赖线索，不能直接升级为新颖性。

## 3. 近邻导致的创新边界

已有审查已经核验三类直接威胁（见 `work/agents/S100_innovation_review.md` 与 `S100_claim_boundary.md`）：

1. **集合条件选择已有先例。** GIM-World 的贪心 MI 选择让下一项分数依赖当前保留集合；因此“考虑上下文/冗余”本身不能作为独立贡献。
2. **有符号证据干预已有先例。** CUE-R 已通过 remove/replace 重新运行下游系统并报告结果差；因此“替换一条记忆并测量收益”这一通用范式不是首次提出。
3. **下游效用排序已有先例。** Utility-Oriented Visual Evidence Selection 已把候选效用作为选择代理；仅把几何风险重命名为 utility，或用 top-k 排序，不能形成新颖性。

真正可能留下的差异必须同时满足：

- 选择对象是保存的**几何状态/来源块**，而不是文本 chunk 或单张图像；
- 选择只使用历史可见量（几何残差、可见性、来源和计算成本）；
- 评价是独立未来 RGB-D/pose 状态，而不是历史重投影误差；
- 预算是实际记忆槽位、token 或端到端推理成本，而不是仅 source-block 改写数量；
- 规则在未见场景上先冻结，再与 random、recent、confidence、coverage、pose、GIM-style 条件选择比较。

即使满足这些差异，也只能获得“有待验证的独立设置/机制”资格，仍需结果证明。

## 5. 可证伪假设卡（下一阶段应冻结）

### H1：风险值是否预测未来收益

对每个历史候选 `i`，只能使用时刻 `t` 以前的信息得到风险 `q_i`。在固定候选池、固定真实记忆预算和未见未来窗口上，检验 `q_i` 是否预测后续替换/保留的有符号几何损失差。

**支持预测：** 预注册的 Spearman/partial correlation、top-k regret 和 calibration 在多个场景同方向，并优于 recent/random/confidence/pose/coverage 基线。  
**推翻预测：** 相关方向跨场景反转、置信区间覆盖失败、或简单 confidence/coverage 在同预算下不劣。  
**关键防泄漏：** 未来深度、未来 RGB、未来 pose 只能在预测封存后评分；不能用于风险分位、候选匹配或调参。

### H2：风险选择是否有决策价值

在相同候选池和相同总计算成本下，比较 `risk-aware`、confidence、recent、random、coverage/pose、GIM-style 条件选择。主指标是未来完整 GT 域的 AbsRel、delta1、pose/几何一致性和尾部误差；同时报告记忆槽位、显存、延迟和失败率。

**支持预测：** risk-aware 在至少两个未见场景、预先规定的主指标上胜过所有简单基线，且收益不依赖更大预算。  
**推翻预测：** 只在已见场景、单一 cap、单一目标或增加预算时有效；或收益由覆盖率差异完全解释。

### H3：是否真的解决 proposal 的长时程失败

在长序列、重访和遮挡后重现的条件下，risk-aware 选择是否减少历史错误几何对未来状态的传播，并保持物体位置/遮挡顺序？

**支持预测：** 对预先定义的重访/遮挡子集，未来几何误差和错误来源持续时间均下降，且 RGB 质量没有以明显重影换取。  
**推翻预测：** 只改善静态重投影或 RGB MSE，重访/遮挡位置仍错误；或任何增益来自数据选择、相机校准或额外推理次数。

## 6. 必做实验清单（为未来 SSH/GPU 预留）

这些是需要在学校服务器取得算力后执行的**具体试验名称**，目前均未完成：

1. **未见 RGB-D 长序列资格实验**（确认 RGB、深度、内外参、时间戳、坐标单位和动态/遮挡片段；冻结 train/calibration/dev/test 身份）。
2. **同候选池同槽位历史选择基线实验**（recent、random 多种子、confidence、coverage、pose、GIM-style 条件选择、候选风险选择；相同 `k` 和总推理预算）。
3. **未来几何风险预报实验**（只用历史特征训练/校准风险到未来有符号损失差；严格 out-of-scene 评估）。
4. **长时程重访遮挡传播实验**（遮挡前选记忆，遮挡后重现，测位置、深度、遮挡顺序和错误持续时间）。
5. **2×2 几何×外观交互诊断实验**（可信/扰动几何 × 普通/几何条件 RGB；只作机制诊断，不冒充方法）。
6. **反事实成对替换实验**（固定随机流、相机、候选池和背景，替换单个记忆，测未来 GT 损失差；报告上下文交互和评价域敏感性）。
7. **完整生成消费者实验**（相同历史预算下运行 VMem 或等价完整 world-model，比较 RGB、深度、pose、长期一致性和总成本；不能用缓存重渲染代替）。
8. **跨场景和失败边界实验**（不同运动速度、遮挡比例、视角跨度、深度缺测；预注册停止规则，不追逐阳性）。

在 SSH 前先准备数据清单、容器/环境锁定、GPU 显存需求、断点保存、随机种子、日志上传和结果哈希；算力只能加速既定合同，不能在看到测试结果后调规则。

## 7. 给主 agent 的行动建议

1. 把 S100 写成“上下文依赖的已见消费者诊断”，不要把它命名成已发现方法。  
2. 先完成真实未见 RGB-D 数据门和记忆槽位定义；没有这两项，不训练 GRC 选择器。  
3. 在学校 GPU 上优先跑 H1/H2 的最小跨场景版本；若风险预报不超过 confidence/coverage，停止 GRC 主线并保留阴性结果。  
4. 若 H1/H2 成立，再做 H3 长时程重访/遮挡和完整生成消费者；此时才有资格讨论论文贡献。  
5. 保持所有状态字段：`new_method_validated=false`、`novelty_authorization=NONE`，直到独立数据、冻结协议和跨场景结果真正通过。

**审查结论：** 当前最有价值的创新问题是“历史可见的几何风险能否在真实固定记忆预算下预测并改善未见未来世界状态”，而不是“提出 GRC-Memory 这个名字”。S99/S100 已有效缩小了问题，但尚未提供方法成立证据。
