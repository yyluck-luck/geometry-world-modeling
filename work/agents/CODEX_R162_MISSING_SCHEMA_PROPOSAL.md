# R162 Missing Evidence-Object Schema Proposal

**Access date:** 2026-09-24  
**Evidence boundary:** R160 and R158 only. These are minimal machine-readable protocol schemas; no broader search, code/data/fixture/runner execution, GPU, Slurm, evaluation replay, receipt, or flag mutation.

## Schema rules

- All hashes are lowercase SHA-256 strings (`^[0-9a-f]{64}$`).
- All timestamps are UTC RFC 3339 strings with `Z` suffix.
- `PASS`/`FAIL` fields are reviewer assertions over retained evidence, not substitutes for that evidence.
- Any missing required field, failed check, or chronology violation triggers the schema's fixed stop branch.

## P2 — Metadata-sanitization audit with independent sign-off

```json
{
  "schema_id": "P2_METADATA_SANITIZATION_AUDIT",
  "schema_version": "1",
  "packet_id": "string",
  "public_manifest_sha256": "sha256",
  "oracle_manifest_sha256": "sha256",
  "audit_created_at_utc": "rfc3339",
  "surfaces": [
    {
      "surface_id": "paths|filenames|map_headers|source_metadata|logs|exceptions|outputs|hash_conventions",
      "evidence_sha256": "sha256",
      "oracle_fields_absent": true,
      "result": "PASS|FAIL"
    }
  ],
  "public_artifact_hashes": ["sha256"],
  "independent_signoff": {
    "auditor_id": "string",
    "reviewer_id": "string",
    "reviewed_at_utc": "rfc3339",
    "review_digest_sha256": "sha256",
    "result": "PASS|FAIL"
  },
  "stop_branch": "LEAKAGE_STOP"
}
```

Required checks: every listed surface has retained evidence; no public artifact reveals `h`, stratum, units/schema truth, or label-bearing path; public and oracle hashes are distinct objects; the independent reviewer verifies the surface inventory and signs after the audit. The reviewer must not use the oracle manifest to excuse a public leak.

```json
  "schema_version": "1",

  "oracle_custodian_id": "string",
  "scorer_custodian_id": "string",
  "rerun_reviewer_id": "string",
  "oracle_commit_sha256": "sha256",
  "scorer_config_sha256": "sha256",
  "prediction_seal_sha256": "sha256",
  "events": [
    {
      "sequence": 1,
      "event_id": "string",
      "actor_id": "string",
      "actor_role": "oracle|scorer|reviewer",
      "event_type": "oracle_commit|scorer_freeze|prediction_seal|oracle_release|prediction_regeneration",
      "object_sha256": "sha256",
      "timestamp_utc": "rfc3339",
      "oracle_access": "none|read",
      "evidence_sha256": "sha256"
    }
  ],
  "reviewer_checks": {
    "oracle_inaccessible_before_prediction_seal": "PASS|FAIL",
    "release_after_prediction_seal": "PASS|FAIL",
    "no_prediction_regeneration_after_release": "PASS|FAIL",
    "chronology_monotonic": "PASS|FAIL",
    "reviewer_id": "string",
    "reviewed_at_utc": "rfc3339",
    "review_digest_sha256": "sha256"

```

Required chronology: `oracle_commit < scorer_freeze < prediction_seal < oracle_release`; no scorer-role event has `oracle_access=read` before release; no `prediction_regeneration` occurs after release. The independent reviewer verifies raw access events and hashes, not only the summarized PASS fields.

## P4 — Trusted wrapper/oracle manifest and pre-call commit

```json
{
  "schema_id": "P4_TRUSTED_WRAPPER_ORACLE_MANIFEST",
  "schema_version": "1",
  "packet_id": "string",
  "wrapper_source_sha256": "sha256",
  "wrapper_revision": "string",
  "transform_spec_sha256": "sha256",
  "oracle_manifest_sha256": "sha256",
  "pre_call_commit_sha256": "sha256",
  "pre_call_committed_at_utc": "rfc3339",
  "producer_call_id": "string",
  "oracle_truth": {
    "h_values": ["RAW_CV|TRANSFORMED_G|CANONICAL|UNKNOWN"],
    "hypothesis_set_H": ["RAW_CV", "TRANSFORMED_G"],
    "strata": ["in_H_correct|in_H_misdeclared|out_H_canonical|out_H_unknown"]
  },
  "producer_declared_tag_role": "comparator_only",
  "reviewer_checks": {
    "wrapper_hash_matches_source": "PASS|FAIL",
    "oracle_committed_before_producer_call": "PASS|FAIL",
    "producer_tag_not_used_as_oracle": "PASS|FAIL",
    "scorer_cannot_access_oracle_preseal": "PASS|FAIL",
    "reviewer_id": "string",
    "reviewed_at_utc": "rfc3339",
    "review_digest_sha256": "sha256"
  },
  "stop_branch": "ORACLE_INDEPENDENCE_STOP"

```

Required ordering: wrapper and transform specification are source-hashed; oracle truth is committed before the producer call; producer self-description is comparator-only; `h_values`, `H`, and strata are generated by the trusted wrapper, not inferred from residuals or scorer output. `CANONICAL` and `UNKNOWN` remain out-of-hypothesis cases.

## Acceptance and hard stops

- P2 is complete only when all surfaces have retained evidence and independent sign-off; otherwise `LEAKAGE_STOP`.
- P3 is complete only when raw event chronology and reviewer checks prove release ordering; otherwise `HIDDEN_LABEL_CUSTODY_STOP`.
- P4 is complete only when wrapper/source hashes and pre-call oracle commit prove truth independence; otherwise `ORACLE_INDEPENDENCE_STOP`.
- These schemas do not prove that no external benchmark already measures FUP/AReject; field-wide novelty remains unproven and any such claim remains blocked by `NOT_READY_OWNER_PACKET`.

Do not implement or execute the benchmark. Preserve method END-LINE, `new_method_validated=false`, and `novelty_authorization=NONE`.
