Workspace: local Mac checkout. Review cutoff: 2026-10-10. This is a literature and source review, not a reproduction of the papers or a new model evaluation. S141 training progress and remote outputs were not inspected. The project states remain **new_method_validated=false; novelty_authorization=NONE**.

## (a) Closest method, and whether S141 B is essentially it

**ANALYTICAL: AnyRecon is the single closest overall publicly available method among those verified.** This ranks the complete conditioning/adaptation recipe. Peer-reviewed publication status is unverified.

**B essentially applies an established geometry-conditioned diffusion recipe; it is not an exact AnyRecon implementation.** AnyRecon's geometry-update loop, DiT context/KV design, sparse attention and distillation are not reproduced by B. Neither inventing warp-plus-mask memory conditioning nor reproducing AnyRecon is a supported claim. [2604.19747, *AnyRecon: Arbitrary-View 3D Reconstruction with Video Diffusion Model*, §§3.2–3.4, 4.2](https://arxiv.org/html/2604.19747v1).

The source confirms what B actually adds:

- Attention LoRA wraps Q/K/V/output projections while freezing base parameters: **work/S141_finetune/s141_common.py:82–94, 109–121**.
- WarpInConv adds the output of a zero-initialized extra-input convolution to the old input convolution: **s141_common.py:97–106, 117–118**. The mirrored model specifies the old input and output widths and kernel: **data/S134_tacc/vmem_src/modeling/network.py:21–22, 56–60**.
- The extra channels are warp latents and pooled coverage; context positions receive zeros: **work/S141_finetune/train_s141.py:35–38; s141_common.py:157–164; gen_s141.py:178–182**.
- The same warp conditioning enters conditional and unconditional dictionaries: **gen_s141.py:139–147; train_s141.py:71–72, 117**. It is therefore not a separate inference-time warp guidance gradient.
- Training warp construction consumes context RGB and estimated depth, with target poses; it nearest-fills missing pixels and pools the original coverage map: **work/S141_finetune/warps_s141.py:62–66, 79–96**. “Warp-only” here does not mean a rendering with untouched empty holes.

**ANALYTICAL algebraic check:** the input operation is
$h=W_0*x+b_0+W_w*[z_{\mathrm{warp}},m]+b_w$.
Because both paths are linear convolutions with matching spatial kernel/padding, this is equivalent to a widened input convolution with kernel $[W_0,W_w]$ and bias $b_0+b_w$, with the old kernel frozen. Zero initialization preserves the old function initially; it does not create a new kind of geometric reasoning. This is a source-derived identity, not a numerical GPU fidelity test (**s141_common.py:97–106; network.py:56–60**).

ViewCrafter is the clearest earlier **U-Net input** precedent: rendered RGB → VAE → channel concatenation. MultiDiff already supplies warp latent + mask through zero-initialized residual connections. See3D explicitly initializes added visual-conditioning kernels to zero. These different implementations independently defeat novelty claims for B's individual ingredients. [2409.02048, *ViewCrafter: Taming Video Diffusion Models for High-fidelity Novel View Synthesis*, §III-C](https://arxiv.org/html/2409.02048v1); [2406.18524, *MultiDiff: Consistent Novel View Synthesis from a Single Image*, §3](https://arxiv.org/html/2406.18524v1); [2412.06699, *You See it, You Got it: Learning 3D Creation on Pose-Free Videos at Scale*, App. C.1](https://arxiv.org/html/2412.06699v3).

There is also specific cautionary evidence: GEN3C reports poorer generalization for an appended mask channel than for masking latents by multiplication. That is a reason to evaluate B's choice, not proof that B must fail on its different domain. [2503.03751, *GEN3C: 3D-Informed World-Consistent Video Generation with Precise Camera Control*, §4.3 and App. C.1](https://arxiv.org/html/2503.03751v1).

**Verdict for B:** useful adaptation experiment; currently no defensible new-method claim.

## (b) Has the complete “useful retrieved memory, no generation gain, warp wins” result already appeared?

**No exact replication precedent was verified in this search. This does not establish that none exists.** The complete claim requires all three observations within a matched experiment:

1. Retrieved contexts are independently shown to contain more useful geometric evidence than the comparison contexts.
2. The same frozen generator fails to translate that difference into improved outputs.
3. A direct geometric prediction from those same contexts beats the generator on explicitly named metrics.

The closest papers cover important subsets:

- **MemLearner already explicitly reports ignored memory conditioning.** Its failed separate query module behaves like text-to-video; the authors also inspect query/context attention similarity. It does not demonstrate that the failed module retrieves geometrically useful evidence, and it does not score raw reprojection. Thus “the first discovery that a generator can ignore memory” is untenable, but the full S139 conjunction is not replicated there. [2606.31734, *MemLearner: Learning to Query Context memory for Video World Models*, §3.2, §5.4/Table 2, App. C.2](https://arxiv.org/html/2606.31734v1).
- **Spatia supplies a close partial empirical precedent.** MEASURED by its authors, Table 4 reports closed-loop PSNR_C of 15.55 with neither spatial condition, 15.64 with references alone, 17.18 with projections alone, and 19.38 with both. Reference-only SSIM is unchanged and LPIPS worsens. These architectural ablations already show that adding references alone need not help. Projection-conditioned generation is not the raw projection, however; the paper does not establish the three-part result above. [2512.15716, *Spatia: Video Generation with Updatable Spatial Memory*, §4.2/Table 4](https://arxiv.org/html/2512.15716v1).
- **VMem itself is the essential contrary result.** Its cycle-trajectory retrieval ablation reports better generated outputs from surfel retrieval than temporal/camera-distance/FOV selection. For its smaller-context configuration, paper-reported MEASURED PSNR is 14.82 for surfel retrieval versus 13.27 for camera distance. This prevents generalizing the project's failure into a claim about all VMem use. [2506.18903, *VMem: Consistent Interactive Video Scene Generation with Surfel-Indexed View Memory*, §4.4/Table 4](https://arxiv.org/html/2506.18903v3). WorldMem and Context as Memory also report positive retrieval ablations in the table above.

The local records support a narrower, concrete result. The following are **MEASURED in existing project artifacts**, not regenerated in this review:

The result/protocol scope is one chess scene with cross-sequence revisit windows and one frozen consumer; pretraining exposure is unverified (**work/S139_crossseq_revisit/RESULT.md:3–7, 53–57**). The geometric predictor is not a capacity-matched generator control (**RESULT.md:31–42**).

**Do not equate “no benefit” with “no use.”** Different conditioning can alter outputs without helping PSNR, can help only particular regions, or can expose an out-of-domain conditioning failure. Those are distinct from output invariance under a controlled memory intervention. The inspected local base path actually inserts context latents through replacement and uses averaged CLIP context, camera maps and frame masks (**data/S134_tacc/vmem_src/modeling/pipeline.py:1124–1126, 1143–1185; modeling/network.py:226–234**). An available input path does not prove effective consumption, but the aggregate score comparison alone does not prove the path is ignored.

For evaluation precedent, **LiveNVS** directly compares non-neural DIBR and neural rendering on real ScanNet; its learned method improves all three principal metrics over DIBR. **LVS** has a warp-only comparison and a separate 7-Scenes experiment, but its warp-only ablation is on rendered GS-render data. Neither is the claimed memory-world-model failure. [2311.16668, *LiveNVS: Neural View Synthesis on Live RGB-D Streams*, App. B.3/Table 7](https://arxiv.org/html/2311.16668v2); [2610.12127, *LVS: Local View Synthesis from Relative Camera Pose by Reusing Previous Views*, §3.3/Table 2](https://arxiv.org/html/2610.12127v1).

**Metric disagreement is established neighboring territory, not a novel principle.** GenWarp describes good PSNR but degraded image quality for warp-and-inpaint baselines; that is not an exact raw-warp/SSIM precedent. [2405.17251, *GenWarp: Single Image to Novel Views with Semantic-Preserving Generative Warping*, §4.3/Table 1](https://arxiv.org/html/2405.17251v1). The perception–distortion theorem concerns reference distortion versus distributional realism, not a theorem predicting the relative ordering of PSNR and SSIM. [1711.06077, *The Perception-Distortion Tradeoff*, §§II–III](https://arxiv.org/html/1711.06077v3). LPIPS can complement the measurements but does not certify accurate geometry or memory. [1801.03924, *The Unreasonable Effectiveness of Deep Features as a Perceptual Metric*, §§3–4](https://arxiv.org/html/1801.03924v2).

**Answer to the replication question:** the broad story is partly a re-observation of known conditioning failures and geometric-conditioning remedies. The precise S139/S140 conjunction has not been verified as an existing result; it also has not been established as globally first.

## (c) What remains potentially worth reporting?

**ANALYTICAL: the strongest present contribution is a bounded empirical diagnosis and evaluation practice, not a new warp-conditioned architecture.**

A defensible statement is:

> In this frozen VMem configuration on cross-sequence 7-Scenes chess revisits, surfel-selected contexts improve a separate forward-warp predictor relative to recent contexts, but do not improve generated-frame PSNR; direct reprojection from the selected contexts has lower pixel error than generation, while SSIM reverses that ordering.

Every numerical component of this statement is linked above. It describes a particular operating regime and a mismatch between measured evidence utility and final output benefit. It does not assert that VMem never uses memory, that memory is generally unnecessary, or that warp is universally better.

What could give the study value beyond a narrow negative result:

1. **Separate retrieval utility from consumer benefit.** Evaluate the same selected evidence through both deterministic geometry and the learned consumer. Keep distinct the questions “which history is useful?”, “does changing it change the output?”, and “does that change improve the result?”. A matched multi-model, multi-scene extension could test whether the mismatch recurs. That is a proposed extension, not a completed result or confirmed novel benchmark.
2. **Report adaptation as diagnosis.** The protocol compares attention-only adaptation A against a geometry-conditioned adaptation B, with the warp as B's primary comparator (**work/S141_finetune/PROTOCOL.md:33–42, 51–64**). Success could demonstrate that this failure is repairable under this training budget. Failure would bound this adapter/training recipe, not establish that diffusion cannot exploit geometry. No S141 outcome is certified here.
3. **Preserve the attribution limit.** The registered arms are A-static, A-mem and B-mem; there is no B-static (**PROTOCOL.md:54–58**). Therefore B beating warp or base-mem cannot by itself show that B specifically unlocks a retrieval advantage over recent context. A future separately frozen comparison would need B-static with its corresponding warp, and conditioning controls if making claims about learned warp use. The B-versus-A difference also bundles added information and trainable parameters.
4. **Keep observed-region fidelity and missing-region completion separate.** This is sound evaluation, but not a new scientific principle: GenRec explicitly builds the reconstruction/generation split into architecture, loss and gradient flow, and uses region-aware evaluation. [2608.17832, *GenRec: Knowing Where to Reconstruct and Where to Generate*, §§3–4 and App. B](https://arxiv.org/html/2608.17832v1). A new contribution would need a new finding established by that separation, not the separation alone.
5. **Distinguish scene holdout from research holdout.** Chess is excluded from S141 training, but S139/S140 chess failures motivated S141 and the evaluation reuses those windows (**PROTOCOL.md:7–15, 17–19, 51–58**). It is held out from fine-tuning data, not an untouched confirmation set for the research trajectory. A fresh scene/model check would materially strengthen generality.

One further qualification affects interpretation of region scores: S140's masks are the warp's own coverage masks, not independently certified ground-truth disocclusion labels (**work/S140_warp_guided/score_s140.py:31–38, 46–50**). Its result document itself calls the claim that chess holes are genuine disocclusions an untested hypothesis (**work/S140_warp_guided/RESULT.md:34–37**). Report “uncovered by this warp” unless scene visibility has been independently checked.

The current evidence justifies a reproducible technical/diagnostic report. A strong research-paper claim would need generalization, a clear explanation for the difference from VMem's published positive retrieval results, and matched consumer/geometry baselines. B's success alone would not provide method novelty. The prior-art review does not assess KPS's independent novelty; that requires its own closest-work analysis.
