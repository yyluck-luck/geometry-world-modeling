## 1. 能增加什么信息，不能识别什么

S80 把接受的目标点与一条极线比较。引入源深度后，可以在固定相机与静态点假设下把候选位置收紧为一个二维预测点，从而检验沿极线方向的位移。这比点到线更有约束，但不是为匹配身份提供独立真值，也不是恢复生成器的实际相机。

令源特征为原生 576 像素坐标 x=(u,v,1)，源光轴深度为 Z，相机内参为 Ks。若 q=Ks^{-1}x，且 q_z=1，则 Xs=Zq；若深度其实是到相机中心的量程 r，则应为 Xs=rq/||q||。两者不能混用。以光学 c2w 的旋转 Ri、中心 ci、目标 Rj、cj 计算：

`Xt = Rj.T @ (Ri @ Xs + ci - cj)`

`p_expected = project(Kj @ Xt)`，`e_px = ||p_expected - target_xy||_2`。

单位是原生 576 图像像素；三维长度与相机平移必须同为米。这里的 expected 是“传感器深度和指定相机给出的几何期望”，不是新神经模型预测。

大误差只能反对以下联合假设：匹配对应同一物理表面、表面静止、源深度赋值有效、RGB/深度时间与空间注册可用、相机时点/轴/尺度正确，以及当前近似成像模型足够准确。匹配错误、几何/身份变化、深度边缘、时间误差、未建模畸变仍可解释结果。小误差也不证明全图三维正确。

**一个必要的数值辨析：** S80 的主量是两个方向点到极线距离的平均，S81 是目标点到二维期望点的距离，两者不能按同一个 10 px 阈值直接视作等价。若使用完全一致的 K/位姿/坐标模型，期望点应在目标极线上，因此 `e_px >= d_to_target`（浮点容差内）；它不必大于 S80 的双向均值。S80 “生成记录双向均值均大于 10 px”不能在未算 S81 前改写成“S81 必然全大于 10 px”。

## 2. 四组最小必要合同缺项

若采用最近时间关联，合同明确搜索范围、最大允许差、并列时选择方式，且不按投影分数改选帧。已注册到 RGB 网格不自动等于与 RGB 同时曝光；相机运动及深度边缘仍会产生误差。若只采用近邻时间近似，应原样报告时间差及未做运动补偿，不声称严格同步真值。是否采用时间补偿属于另一个测量版本，不得见分数后补做。

当前已读来源确认实际序列是 fr2_desk、原 K 是近似 ROS K，并有 OpenNI 注册/未额外去畸变边界；**本轮没有独立核该新增深度的编码因子、修正是否已应用或具体时间差**。执行前由数据核查给来源，不凭记忆填写 5000、毫米制或额外 fr2 scale factor；尤其避免重复施加数据发布时已做的校正。缺少 Z/range、单位或注册证据是本批执行 blocker；不能产生可解释米制投影。

### B. 相机轴、裁剪和一次取样

继承 S72 的 `optical_cameras.npz` 光学 c2w 和 `K_pixels_576` 身份。S69 已把 consumer 轴变换单独记录；S81 不再乘 `diag(1,-1,-1,1)`，不混入 consumer 归一化平移或 `camera_scale=2`。不得从目标图拟合 F/H/pose，或把新校准 K 偷换进旧生成请求。

原 helper 对图像使用 Torch area resize，再裁剪；对 K 按实际宽高比例缩放，减裁剪偏移。合同要写出实际变换尺寸及像素约定。已知路径的尺度为 640×480 → 768×576 → 576×576，水平裁 96；在继承旧 K 的几何坐标约定下，名义逆变换为 `u_native=(u576+96)/1.2, v_native=v576/1.2`。不能临时加半像素校正而声称仍是原协议。area 插值后的 RGB 特征也不是某个原始像素的逐点复制，因此名义坐标映射不是光学表面身份保证。

最便宜且可复核的首批规则：每个源 feature ID 只从已注册原网格取一个深度样本，nearest 取整明确为 `floor(v+0.5)`；先判断连续坐标和取整索引是否在域内，禁止 clip 边界，禁止遇无效点再搜最近有效邻居。记录原浮点坐标、逆变换坐标、实际整数样本地址及深度原码。若在原浮点射线上使用最近邻样本的 Z，明确这是局部深度常量近似；不能把取样位置当作未量化的真值位置。

也可以预先选双线性，但必须同时冻结四邻域、权重、任一无效时行为和跨深度边缘限制。首批无需加入双线性、最近邻、多窗口挑最优的扫参。取样规则不完整是 blocker；选定一种并承认其边缘近似则不是 blocker。

### C. 保留无效、出视野与未知遮挡，不偷换分母

### D. 答案与消费隔离、shared-source 配对

S80 匹配已经封存。新增源传感器深度只能进入 S81 评分，不进入新的特征提取、接受/拒绝规则、描述子、生成消费者或参数选择；不需重新读 RGB 做匹配。相机在旧实验本来就是共同请求条件，不能事后改称“过去从未使用任何 GT”；新增深度是本次额外评分信息，这使 S81 不能公平声称打败不具备这份信息的观察器。

对相同 `(source_feature_id,target_id)`，深度赋值与 expected_xy 应只计算/缓存一份，real/A0/B 及 BF/LG 都消费这一份。禁止按 matcher 或目标臂分别寻找有利深度。

配对以 S80 完整源特征身份作键，不能用数组行号、坐标近邻或旧 S73 IDs 连接。每个 target 内同时列出：

1. 全部方法/臂各自接受记录的主摘要。
2. 指定两组共同 source IDs 的固定交集及数量；只对两边都定义的误差作辅助差值，保留双方失配/无效计数。可用 `generated−real`，其正值仅表示该共有源点上生成匹配距同一期望点更远，不能证明相同物理目标表面。
3. BF/LG 共同 source ID 但不同 target feature ID 是“同源点不同预测”的对比，不是相同对应。若在同一目标图内完整 `(source_feature_id,target_feature_id)` 特征边都相同，深度、期望点与误差应相等；这应作为保存量一致性检查，而不是两份独立支持证据。

不要以共同交集覆盖全体主表，也不要在交集为空时换新交集保存结论。明确配对方向、交集定义、分位方法后即可，不必增加成对显著性检验。

## 3. 只需一次有界前审，不把它扩大成框架

实现作者给出上述唯一版本合同和源码后，不同作者检查以下四项即可：

1. **输入身份/时基表齐全：** 源深度的尺度/语义/注册/时间差有可核来源，旧相机/K/全24行身份相符。检查读取白名单中不含生成器、模型权重和重新匹配入口。
2. **少量纯合成算例：** 零运动恒等、已知平移方向、Z与range区别、非整数像素/裁剪逆变换、无效值/边界/Z≤0/出视野；它们检验公式和状态，不算真实实验。本轮尚未执行这些测试。
3. **独立几何一致性：** 同一相机模型下期望点应满足原目标极线；检验 `e_px >= d_to_target`，不能误用双向均值。固定小容差并记录 FP32 输入升至 FP64 的口径，不因真实残差不理想放宽容差。
4. **计数闭合：** 全24行、全部原接受记录、固定 N、原索引、每个无效理由和共同源交集可从保存表重新算；同一源/目标期望点跨方法一致。一次实际执行后复算保存量，明确不是独立重跑或物理对应真值。

没有目标深度、暂不精确建模畸变、只有一个已见序列、人工判断非盲，不阻止这个保留限制的描述性诊断。它们阻止的是遮挡精度、物理相机准确性、跨场景泛化和方法贡献的强表述。源深度的量纲/注册未明、偷偷修旧 K、改变匹配或隐藏无效分母，才是本批必须先解决的 blocker。
