# S23：强基线的深度与内部几何诊断

性质：在S21/S22轨迹结果已知后设计的探索；不是盲测、新方法或完整视频评测。研究问题是：轨迹误差的排序是否也适用于深度，较好的轨迹是否仍伴随值得解释的几何误差。先固定规则，再读取这300帧的新传感器深度和稠密头诊断结果。

## 固定条件

- 复用S21 CUT3R/TTT3R及S22共同精度FILT3R全部300帧已封存预测，同一300张TUM fr2_desk实拍，0新模型运行。保留S22原生CPU兼容失败。
- RGB/depth用全序列时间戳建立一对一匹配：候选绝对差严格小于0.02秒，按差值、RGB时间、depth时间排序贪心匹配，然后查取既有300 RGB，不为了凑数改匹配。时间戳允许预先读取，depth PNG在运行封存记录之后读取。
- 官方TUM深度PNG除5000得到米，0为缺测；不再次乘相机深度修正因子。RGB与depth原本已注册。原640×480图在S21缩为512×384且无额外裁边。GT用固定像素中心最近邻映射到预测网格，保留原整数深度与缺失；这是本地诊断协议，不宣称逐字复现FILT的Bonn原评测。
- 使用self pointmap的Z而不是欧氏射线长度。全部GT>0像素，无置信度筛选、深度上界、自动裁掉难例或边界。所有匹配/缺失及预测非正/非有限数均单独报告。

## 指标与信息条件

主指标：原输出尺度的逐帧AbsRel与delta1（比值严格小于1.25），报告300帧等权平均与有效像素合并结果。RMSE与log-RMSE为辅助。若任何应计入帧没有配对或GT，完整300帧均值保留NA，另报可用帧描述。预测非正/非有限在delta分母中计失败；AbsRel/RMSE/log-RMSE不能静默丢弃该像素，完整量保留NA并另报有效预测子集。

两项固定辅助：

1. 将self深度乘S21/S22已经得到的每方法全轨迹Sim(3)尺度，显示轨迹尺度误差能解释多少深度变化；此尺度用了真值，不能叫部署方法。
2. 每帧用有效正预测像素的GT/pred中位数作事后尺度oracle，显示单帧统一尺度可解释的部分。它不是最优误差下界，不是预测器；逐帧校正会掩盖时间漂移，只作诊断并展示所有尺度。

独立前审补充：若oracle没有可用正预测配对，明确记录不可用；原GT仍保留在该诊断的delta分母中计失败，连续误差为NA，不将该帧删出像素汇总。闭合有效点为空时记录0有效点、全部排除数和NA，不计算空分位数。固定核验网格为空同样保留NA。连续指标的标量复核包括闭合p90的独立排序线性分位数实现。

另测DPT三头同帧闭合差：`W - (R @ P_self + t)`的欧氏距离中位数、p90及相对self点范数的中位数。不用传感器答案、不筛置信度，有限且范数>0的点均纳入，排除数量显示。使用已保存原pose矩阵。DPT self/world由不同头预测，该量不是恒等零；但它只反映同帧输出自洽性，不能直接叫跨帧一致性、准确率或遗忘因果。

## 验证、结果解释与停止条件

- 先做人工完美/尺度偏差/非正缺失/严格delta边界、GT最近邻映射及刚体闭合/故意扰动检查。
- 运行时核每帧存档原SHA，流式读取与评分，原预测不修改；留下每帧指标、所有五个60帧区间和全分母。结果最大帧只能作明确事后图示，不当独立样本。
- 同作者另一套标量公式对每帧固定32像素步长网格复算所有尺度的深度指标与刚体闭合；整数计数精确，连续指标atol=1e-10、rtol=1e-8。独立作者前审是否完成以单独记录为准，不能用另一公式冒称另一作者。
- 三方法都改善且不存在明显剩余矛盾，就不强造研究问题。若有排序翻转或大残差，先排除尺度、网格、配对与头含义，再在独立条件确认。单已见静态约10.44秒序列不能证明普遍长期失败或PhD级新颖性。
