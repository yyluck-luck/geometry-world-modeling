# 保存几何的单位依赖诊断

范围：已看过 C2 V9 失败元数据后的探索性离线诊断，不是盲实验、视频生成、新方法或质量评分。不修改旧源、档案或任何预定分母。

只读取 archive 事件 58 的 515 个 surfel 位置/法线/半径/来源及相机、焦距、渲染尺寸；事件 60 的数值 depth/index/cos 输出；事件 62 的来源权重。解码器遇到图片或非数值载荷立即拒绝。允许导出数值图数组，不读取/导出 RGB。

从既定 pipeline SHA 的 AST 提取原样 renderer、分配函数和检索聚合三函数，不导入 pipeline，不加载模型。固定 512×288、原法线/来源/焦距、原裁面和所有数学常数。

只运行两个条件：①原单位，必须与保存的三张数值数组逐项相同、检索仍空；②位置、相机平移和半径同乘 1/median(positive camera z)，把正深度中位数定义为一个长度单位。旋转、K、法线和来源均不变。投影在绝对 1e-9 像素、相对 1e-12 容差内必须相同。归一化规则在栅格化前确定，不搜索其他倍率/裁面/阈值。

报告全部两条件、耗时、尺度、深度范围、投影差、占据索引像素数、来源权重和计数。若失败保留 execution_01，不覆盖或静默重跑。一次外部运行上限 120 秒。

几何投影等价不表示物理尺度已知；原程序固定近/远裁面及 depth 权重常数仍保留，因此测试的是这些绝对数值假设对同一几何的影响。若出现非空检索，也只证明该边界的可恢复性，不证明真正第二批生成成功或画质改善；中位尺度归一化是普通工程对照，不能称创新。生产修复需另行明确坐标/深度/半径/位姿及缓存更新的完整一致性。
