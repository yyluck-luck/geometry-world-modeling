# Root 独立原文核读与实验逻辑修正

原读书报告保留。root核对正式PDF的文本：Self Forcing §3.2/算法1/§3.3、表2及后文消融、rolling KV和训练效率；FramePack §4.1/4.2及表1后解释。精确范围不等于两篇全文或复現。原报告正式来源身份、训练/推理差异及未来端点额外信息的提醒成立。FramePack §4.2的K极限解释与§5.3一句关于更大K的文字存在方向张力，本项目不据此推出K的单调规律或选择超参。

三条件对照只保留为局部、有限的前瞻诊断。报告首段“能区分”应读作“有助于排除特定竞争解释”；不能将等残差强度当成等难度或充分分布匹配，更不能把noise分支直接叫“减弱历史”。需要独立历史参考H_ref和独立评分目标R_target，二者分工不能混同；前者可进入oracle分支，后者不得进入任何分支或处理策略。

已经实际做了一个精确整数反例。令F(h)=4h₁，没有时间轴、训练失配或自回归；H_ref=(0,0)，H_self=(1,0)，目标0。四个等概率噪声为(±1,0),(0,±1)，与自误差的平方范数都为1。ref损失0，self损失16，noise期望损失8。因此Δ_correct=16且EΔ_shape=8，仍完全可以由一个普通线性系统的方向敏感性解释。它否定的是“这个结果模式足以定位曝光偏差/特有历史污染机制”的逻辑，不反证VMem存在或不存在这种机制。

一般地，对线性消费者A和误差e，E‖Ae‖²=tr(AᵀA Cov(e))+E(e)ᵀAᵀAE(e)。匹配E‖e‖²只固定总能量，无法固定其与消费者敏感方向的关系。这是标准代数，不是新定理或论文贡献。完整分布匹配也不能靠有限noise样本假装成立。

保留的最小研究问题：在预定、真实对齐、参考隔离的同一消费边界，纠正一个来源是否有超出重放/对齐不确定性的目标收益。若没有收益，停止该来源假说；若有，先排除普通方向敏感性和oracle信息量解释，再考虑结构化误差机制。无R时可测条件影响，但不能用回访像素误差或生成图自估相机补出收益答案。当前尚无可执行的新方法或新训练。
