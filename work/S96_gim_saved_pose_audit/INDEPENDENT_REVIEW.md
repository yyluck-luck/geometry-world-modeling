# S96 独立复核：GIM-World 保存位姿核谱审计

- 复核时间：2026-09-12（实际本机运行，UTC 时间见 `independent_results.json`）
- 复核性质：作者运行后的独立数值重算；不是 GIM-World 原生 MIND 复现，也不是 RGB-D、视频生成或 GRC-Memory 方法实验。
- 输入：已保存的 TUM `freiburg1_xyz` 3000 行 ground-truth 位姿文本；四个预先冻结的 16 行池；官方源码快照和 S96 运行结果。
- 网络、媒体解码、模型推理：均未使用。

## 复核方法

我没有导入或调用 `run_audit.py`。单独使用 NumPy/FP64 重建了官方 `pose_time_kernel` 的计算：

1. 读取 TUM 的 `qx,qy,qz,qw`，显式归一化并用独立公式构造旋转矩阵；
2. 采用与 S96 协议一致的 camera-to-world 解释，取旋转矩阵第三列作为相机 +Z 方向；
3. 使用 TUM 米坐标直接计算位置距离。这与“先转厘米、再由 GIM 的 `POSITION_SCALE=100` 除回米”等价；
4. 对位置距离和方向角使用正距离的中位数带宽；主条件使用 `sigma_t=(max(index)-min(index))/4`，敏感性条件关闭时间因子；
5. 加入 `jitter=1e-4`，重算特征值，并与保存的 `.npy` 和 `RESULTS.json` 数值比较。

显式四元数公式与 SciPy `Rotation` 的浮点路径略有差异，因此采用 `rtol=1e-10, atol=1e-9` 的矩阵数值一致性阈值，而不是要求不同实现产生相同字节哈希。保存文件自身的 SHA-256 仍逐项核验。

## 独立结论

1. 在这四个固定池、这组保存的 TUM 位姿、官方自适应带宽、固定时间因子和给定 jitter 下，独立重算没有发现负特征值；这支持“本次有限输入审计没有观察到谱异常”。
2. 这不能推出 GIM 核对所有轨迹、所有带宽或所有数据都 PSD，也不能否定此前针对平方角度核的理论风险；它只约束本次有限样本条件。
3. 该结果不包含 RGB、深度、未来位姿、完整消费者 forward、生成质量、GRC 风险或记忆选择后的未来误差，因此不支持 GRC-Memory 方法成立、创新成立或 GIM-World 原论文结果正确/错误的结论。
4. 四个池来自同一条轨迹，并非四个独立场景；不能用于显著性、跨场景泛化或论文最终统计。
5. `official_selected` 只是源码返回的候选行号；本复核只检查其数量、池成员关系和首尾锚点，不宣称其具备信息论最优性。
