# S33前的解析检查：短基线下是否存在压缩残差的可行路径

**这是基于原目标的条件性代数推导，不是新算法、真实实验结果或已证实的S32优化根因。** 不用于更换预选窗口、预算、评分或S33唯一控制。推导采用S32的C2a条件：所有深度可训练，相机给定，焦距在这条构造路径中保持固定；实际优化仍允许焦距训练。旧深度被锁定的其他臂未必允许此路径。

## 从原实现写出目标

原optimizer.py:251–288把深度反投影为世界点，并与每条pair变换后的冻结头点图比较。令相机中心为c_i，世界射线为r_iu（固定焦距和旋转），深度为d_iu，则X_iu=c_i+d_iu r_iu。给定star边e=(0,j)，原pair输出可写为Y_e,iu=s_e(Q_e p_e,iu+t_e)，其中固定adaptor并入p。注意原实现缩放完整3×4，t_e也乘s_e。

原dist='l1'实际上是三维欧氏范数乘固定非负权重，分别除以固定total_area_i/j后相加。设残差R_e,iu=X_iu-Y_e,iu。以下J是这个欧氏范数目标，而不是逐坐标L1或平方误差。

## 显式构造一个候选路径

取0<a<=1，对所有帧设d_iu(a)=a d_iu；所有边设s_e(a)=a s_e；Q_e与焦距不变，令

    t_e(a) = t_e + ((1-a)/(a*s_e))*c_0.

每个有限a>0时这仍是自由pair平移允许的有限值，原signed_expm1的编码可表达该平移。它给出

    Y_e,iu(a) = a Y_e,iu + (1-a)c_0,
    X_iu(a)   = a X_iu   + (1-a)c_i,
    R_e,iu(a) = a R_e,iu + (1-a)(c_i-c_0).

anchor侧i=0的残差精确乘a；目标侧j多出实际相机基线项。于是三角不等式和非负权重给出

    J(a) <= a J(1) + (1-a) C,
    C = sum_e [ (sum_u w_e,ju)/total_area_j * ||c_j-c_0|| ].

C只含原固定权重、面积分母和给定相机中心，不是观测深度真值拟合。若在某实例上C<J(1)，则任意0<a<1的这个显式可行路径的目标上界都低于初始目标，因此原目标存在偏向整体缩小的可行改进方向。若所有相机共心，C=0，则J(a)=aJ(1)并可趋近0；深度和有效pair尺度同时趋近0。正深度的参数化不会单独排除这个极限。

## 推导没有证明什么

- 本轮没有计算三个S32窗的C，也没有验证C<J(1)，没有读取pose数组/GT/NPZ。四帧时间短不等于已量化的空间基线小。
- 上界存在不保证Adam沿此方向，也不说明实际终点是全局极小；权重、非共心相机和其他变量可能导致不同轨迹。实际S32的共同缩小仍是相关证据。
- 当c_j不同，此路径改变物理结构且产生基线残差项，不是无损坐标规范变换；不能将其称完全gauge不变性。
- a趋近0时构造的未缩放平移可能增大，推导仅保证每个有限正a可表达，不保证FP32数值稳定、优化成本或实际收敛。
- S33固定有效pair尺度几何均值，只排除了“全部s_e乘a”这条路径；深度仍可能通过自由平移、相对尺度、焦距等别的方向变化。不能提前保证抑制所有退化或改善GT指标。

这个推导解释了为何值得做普通共同尺度强对照。尺度坍缩和尺度约束已有DUSt3R机制；没有首次性声明。S33原合同、预定四窗及一次固定版本的停止规则保持不变。
