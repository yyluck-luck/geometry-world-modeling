# S14B草案：固定来源关联下的历史观测分散度

状态：DRAFT_NOT_APPROVED_FOR_EXECUTION。这是S14正式审读后的**普通测量诊断**，不是C2已获批准的新机制，也不主张新颖性。先定义一个真实可算的量，再决定是否值得与查询选图联系。本文件不启动数据解码、标签联结或模型训练。

## 唯一问题与域

在已有S7/S8的6个主密度块、固定A0事件与A0P0记忆下，同一记忆点关联到的不同历史帧，是否在预测坐标中存在可测的观测分散？这里的“分散”只表示内部预测差异，不等于真实错误或不合法匹配。

使用每块20个历史帧的保存观测；不读取query姿态/照片、票权、选择、GT、支持分数、S14A特征表或任何S13 oracle。6块来自2个已见物理场景，不称6个独立场景。主stride8，不扩其它地图臂或stride12。

每块输入限4份：observations.npz、A0_events.json、A0P0.npz、A0P0_sources.json。24份候选路径与当前字节SHA见 `work/S14_mechanism_input_audit/receipt.json`；这份可用性记录不是执行冻结。启动前需将确切24文件、最终脚本、本设计及独立审读绑定为新的执行manifest。

## 固定连接与普通测量

按observations.offsets将每帧观测切片，与该帧events.targets逐项连接；校验ids中的frame/u/v及顺序、targets出生/既存约束、帧数20、所有observations恰好参与一次、每点frame集合与sources/地图counts一致。不重新做最近邻匹配，也不按观测效果改关联。

对记忆点j、来源帧f的观测集合I(j,f)，定义帧质心 `c(j,f)=mean_i∈I(j,f) x_i`，来源帧数为m(j)，跨帧均值 `μ(j)=mean_f c(j,f)`。所有以下均按帧等权，不能把同一帧多个像素当作更多来源证据：

| 输出量 | 定义 | 可作何种解释 |
|---|---|---|
| W(j)，帧内分散 | `mean_f mean_i ||x_i−c(j,f)||²` | 一帧内多个关联观测的分布，不自动是误差 |
| B(j)，帧间分散 | `mean_f ||c(j,f)−μ(j)||²` | 不同来源帧对位置的差异，不自动是错误关联 |
| A(j)，锚点偏移 | `||μ(j)−x_mem(j)||²` | 首写位置距帧质心均值的差异 |
| D(j)，相对记忆的均方距离 | `mean_f ||c(j,f)−x_mem(j)||²` | 混合了B与A，不能只看总值归因 |

同时报告来源帧数m、总观测数、首写frame/观测身份，以及每个量除以该点原地图半径 `A0P0.radii[j]²` 的无量纲版本。它是点j首写观测的半径，不是块均值或后续更新半径，须与出生观测精确一致且为有限正值；任何非法数值停止并保留失败，不加epsilon掩盖。原值单位为保存的预测坐标平方，不写m²或mm²。

保留全部点。m=1时B按定义为0，另标single_source，不能把它作为多视图一致成功；在本输入事件规则中，同帧匹配仅能指向帧前已存在的点，每个新出生独占target，所以合法m=1恰好只有一条出生观测，W/B/A/D全部为0。空组属于输入错误。正常曲面/遮挡、位置和法向匹配阈值、每帧像素数、首写顺序都会影响这些量。该测量沿固定已筛选事件，因此并不能直接估计未经筛选的真实噪声。

## 预定核对、输出与禁止的结论

输出须为全点表、逐frame质心/计数来源表、全部观测flat index关联和每块摘要；摘要报告点数、总观测数、point/frame组数、单/多来源点数，以及m分层的点数和8个量的中位数/90%分位数/均值。小数插值固定为NumPy默认linear；跨场景不汇总成独立统计检验。不得只留高残差案例或在看到结果后换分母。

在运行前独立审读中检查：连接不丢/不重观测、frame等权、半径语义、单来源规则、D=B+A恒等式以及与原首写地图的身份。D必须从逐帧质心到x_mem的距离直接计算，再分别核对原值和除以每点半径平方后的D=B+A，不能直接赋D=B+A制造同义自检。不导入生产实现的第二程序应从同一输入独立重建连接与全部W/B/A/D，整数与连接精确；浮点预定atol=1e-12、rtol=1e-10用于求和顺序差，不能事后扩大。实际数据超出预定门则保留失败、解释来源。

准备时可设计人工例检查零分散、帧内/帧间差异、非均衡每帧像素数和非法半径，但只属于软件测试。成功运行还需实际读取/输出计数、UTC与环境、源码/manifest/输入前后身份、完整失败保存及不同实现复核；已有目录拒绝覆盖。调用者可设600秒外部超时、观测峰值内存，预期1GiB以内但这不是尚未实测的性能保证。

**均值最小化同组残差是数学事实，不是算法胜出。** D=B+A来自平方距离分解；用μ替代x_mem只会按定义移除A，不能证明B降低或真实选图/视频变好。不得把这项诊断写成重新验证了“平均更新优越”。本轮不比较方法效果、不拟合、没有显著性检验，也不提供风险保证。

## 继续和停止

执行准备的目标仅是获得有清楚含义的预测一致性测量。若数据连接/精度失败，先修测量实现；若只有单来源或分散量退化，直接报告，不增加扰动制造信号。若数值可算，后续再单独决定是否与普通MVS一致性、相机分散度、来源票权和真实支持联系；这需要另一份预先分析协议，不能自动联结已见标签。

即使有大分散，也无法凭本阶段认定C2的四图联合冲突成立；即使很小，也不能认定真实几何可靠。下一位执行者先读 `docs/S14_FORMAL_METHOD_REVIEW.md` 与 `docs/S14_MECHANISM_INPUT_AUDIT.md`，编写最小提取器和独立核验入口，再完成不同作者执行前审读/冻结。尚未批准或运行。
