# S31 root 独立保存量复核：运行前固定

此代码在 S31 实际运行前准备，未读取真实 NPZ 或 GT。单次执行须传入正式合同、源码和本协议 SHA；主生产 PASS 后才执行，已有回执拒绝重跑。外控 CPU1、180 秒、2 GiB，由继承的原监督器执行资源限制。

先封存源、四份真实初终点及全部 S31 产物和四 GT 字节，写 input_seal 后才解码。复核阶段读取已有答案是公开的，不再称盲测。只重算 S31 保存量，不执行模型、GA、MST 或反向传播。

与作者的 NumPy `log(b)-log(a)` 和中心化平方和不同：每像素 Python 标量 `math.log(float(b)/float(a))`，`math.fsum` 求均值/平方和；共同项 N mu²，帧间项 M sum(mu_f²)-N mu²，帧内项 sum(v²)-M sum(mu_f²)。验证全部 1,572,864 个 v 和 D* 像素、每帧均值、两标量、三项平方和与所有分量的均方/RMS/占比及每帧描述。FP64 全像素绝对/相对容差 1e-12；标量沿平方和协议 abs1e-9/rel1e-12，零分母 null 一致。原始矩方法有抵消舍入，开方仅对因舍入产生的微小负值截到0，平方和值仍按原容差比较，不改变生产结果。

对封存的两个 D* 采用既有不同作者 S28 helper 的 OpenCV/整数网格/逐行 math.fsum 评分，不导入主评分器。新8条全网格、2组完整等帧均值、全部分母/缺失、16个相对历史端点差和8行CSV；AbsRel/RMSE/delta1/无效比例固定 abs1e-12/rel1e-10，整数/状态/null精确一致。原16条端点只检查导入相同，不再评分。4张 GT 实际解码一次。

复核不再重算作者 `identities` 内的每个浮点舍入残差：完整 v、D* 与各平方和本身已另式比较，原恒等式门属于生产验证。不宣称全原始依赖库存、历史800梯度或真实相机坐标再次复核。PASS 仅表示上述数值与身份范围。失败保留所有产物，不自动改容差、延长预算或重试。
