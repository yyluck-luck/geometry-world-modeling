Empty/small intersections remain explicit insufficient comparisons.

5. **Keep the inference narrow.** The intersection is selected after seeing each image's feature matches and may prefer easy or repeated patterns. A common anchor ID can match different physical objects in different images; matching is not ground-truth visibility or scene-point identity. N is a feature-detection denominator, not a count of all visible physical points. More matches or lower fixed-F error may reflect texture, appearance similarity, hallucinated repeats, visibility or detector behavior. Epipolar agreement constrains only distance to a line and is necessary, not sufficient, for geometric correctness. S72 real-control tails and approximate calibration remain relevant. Neither all-match nor intersection results isolate memory causality, establish achieved generated poses, or create a new method claim.
