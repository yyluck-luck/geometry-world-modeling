# Source-attention mass is not correspondence-unknown probability

**Conclusion:** VIVID's joint self/source softmax can reduce direct source contribution in a layer, so “fallback capacity” is defensible. Calling self mass a calibrated substitute for unknown correspondence is not. The distinction narrows the preceding novelty assessment without withdrawing its verified overlap: multiple candidate source values and adjustable source influence already enter the denoiser. No method is selected and no trained model is being evaluated here.

The source identity is `apple/ml-vivid` commit `a6b7f65c67815e698f2ee85bcf00f935200fd5ae` (13 February 2025), the official repository for **Novel View Synthesis with Pixel-Space Diffusion Models**, CVPR 2025. The prior batch read author version arXiv:2411.07765v1, Appendix B.2 Eq. 2; this batch reuses that paper scope and reads the pinned source directly. [Versioned paper](https://arxiv.org/html/2411.07765v1), [attention source](https://github.com/apple/ml-vivid/blob/a6b7f65c67815e698f2ee85bcf00f935200fd5ae/training/models.py#L267).

**Exact normalization boundary.** `models.py:271–272` normalizes query, key and value channel vectors using `normalize(..., dim=2)`, whose epsilon is defined at lines 35–40. It does not normalize each source branch's total attention mass separately. Lines 273–280 concatenate self/source keys and values, form scaled dot-product logits, add geometric bias only on the source segment, take **one softmax over the combined token axis**, then sum values with those weights. The projection and magnitude-preserving residual blend follow at lines 281–282; they are not a calibrated uncertainty decoder.

For one head and one target query, write self logits `a_i` and source logits `b_j + g_j`, including the geometric bias. Then

`Z_self = sum_i exp(a_i)`; `Z_src = sum_j exp(b_j + g_j)`;

`M_src = Z_src / (Z_self + Z_src)`, and `M_self = 1 - M_src`.

This is attention allocation. No event label such as “a physical match exists” is present in this normalization. A negative common source bias reduces `M_src`, but neither its complement nor a head's mixing parameters become probabilities of such events merely by summing to one.

**Exact hand counterexample, no numeric execution.** Take one self token and one source token, all logits zero (possible at the attention operator with a zero query and the optional geometric bias disabled). Assign post-normalization values `0` and any fixed nonzero vector `v`. The source mass is `1/2` and the attention value is `v/2`. Duplicate the *same* source key/value/bias once, adding no distinct source information. Now source mass is `2/3` and the attention value is `2v/3`. More generally, r identical copies yield `r/(1+r)`. A calibrated physical-match probability cannot be inferred solely from a quantity that changes this way under redundant token counting without an explicit model of that counting. This does not prove attention is defective; softmax has precisely its intended token-level semantics.

This is a symbolic intervention on the attention operator, not an assertion that arbitrary token duplication is a supported full-model input when the spatial epipolar tensor has fixed dimensions. The example uses the explicitly supported bias-disabled operator, avoiding a claim that a duplicated spatial mask was passed through the actual network. Both before/after cases are exact arithmetic on the stated logits, with no tensor, model, or scientific-data run.

**What happens when geometry supplies no reliable match?** In the inspected chain `get_epipolar_dist → get_epipolar_attn → XAttnBlock.forward`, there is no discrete candidate list, validity mask, “all candidates rejected” test, dustbin token, or explicit abstain branch. Every grid pair receives a distance and a finite soft bias when the inputs/operations are finite. Large distance drives the sigmoid toward its baseline; it does not remove the token. Thus an entirely out-of-view correspondence is not represented as an empty set in this path. Zero initial mixing parameters also mean zero geometric bias, not an unknown state. This statement is confined to this source chain, not every file or every trained variant.

One concrete degeneracy policy is different from abstention: `utils.py:154–156` perturbs zero x/y translation components with small random draws and replaces sufficiently small z translation using their norm and a random sign, with the stated motivation of creating epipolar lines for single-image augmentation. These operations act on the reconstructed local camera tensor returned by `decompose_geometry`; we do not infer alteration of a user archive. The random operands are evaluated inside the function even when `where` selects the original components. Lines 171–177 then perform perspective and line normalization without an explicit invalid-line fallback in this helper. Nonfinite behavior is untested; it must not be called neutral or a successful empty-case policy. [Pinned geometry helper](https://github.com/apple/ml-vivid/blob/a6b7f65c67815e698f2ee85bcf00f935200fd5ae/training/utils.py#L143).

Consequently this helper is not an exact replacement for S73's fixed requested-F observer: its degeneracy treatment changes the geometry used internally and consumes RNG. This is a code-contract difference, not evidence that this policy caused any published error or the unrelated S70 framing failure.

**Innovation implication.** Keep the verified closest baseline—joint soft weighting with adjustable geometric bias—and remove the stronger interpretation that self allocation already estimates unknown correspondence. A future explicit unknown mechanism would still need a meaningful supervision/calibration target, redundancy-aware semantics and evidence beyond ordinary self/source competition. Those are unresolved requirements, not a new contribution proved by this counterexample. Low source mass in one layer also cannot establish complete source independence: the residual stream and other layers may carry condition information. No S73 contract, result or current implementation changes follow from this note.
