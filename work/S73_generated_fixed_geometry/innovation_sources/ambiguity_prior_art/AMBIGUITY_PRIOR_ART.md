# Prior-art pressure on ambiguous-correspondence guidance

**Verdict:** the broad description “retain multiple matches and avoid forcing unreliable source information into denoising” is already too close to an existing generative attention mechanism to support novelty. An explicit, calibrated no-match probability was **not** verified in this bounded search. Its absence here is not evidence of absence in the literature. `NO_METHOD_SELECTED` remains.

The one qualified mechanism is **Novel View Synthesis with Pixel-Space Diffusion Models (VIVID)**, Noam Elata, Bahjat Kawar, Yaron Ostrovsky-Berman, Miriam Farber and Ron Sokolovsky: CVPR 2025, pp. 26756–26766; original author version arXiv:2411.07765v1, 12 November 2024. Appendix B.2 defines the per-head geometric attention bias

`A_epi = m * sigmoid(tau * (c - D_epi)) + b`.

The bias is added only to the source/target cross-view part of joint attention. Section 3.2 explicitly motivates soft, learnable influence because an epipolar line includes irrelevant candidates. Geometry-incompatible semantic transfer remains possible; each head learns separate mixing parameters. The architecture already mixes target self tokens with multiple source tokens. The reported final method selects simple pose embedding after the geometry ablation, so do not confuse this tested epipolar variant with the final default model. [Versioned primary text, §3.2 and Appendix B.2](https://arxiv.org/html/2411.07765v1), [official CVPR record](https://openaccess.thecvf.com/content/CVPR2025/html/Elata_Novel_View_Synthesis_with_Pixel-Space_Diffusion_Models_CVPR_2025_paper.html).

**Actual official implementation inspected:** `apple/ml-vivid`, commit `a6b7f65c67815e698f2ee85bcf00f935200fd5ae`, `training/models.py`. Lines 22–29 implement the sigmoid bias with positive temperature via exponentiation and a patch-size-dependent cutoff. Lines 267–282 concatenate self and cross keys/values, add a zero self-bias plus learned cross-bias, softmax jointly, then consume the weighted values in the denoiser. Line 240 initializes four learned mixing scalars per head to zero. This is actual source reading, not a model run. [Pinned source](https://github.com/apple/ml-vivid/blob/a6b7f65c67815e698f2ee85bcf00f935200fd5ae/training/models.py#L267).

**Overlap and remaining distinction.** Multiple candidate source tokens already survive until their weighted values are consumed. Because self tokens share the normalizer, cross-view mass is not forced to one. Inference from that code: for finite logits, making the cross-view bias increasingly negative drives total source weight toward zero while self weight remains; this is an ordinary implicit fallback path. It is not a dedicated dustbin token or a calibrated probability that physical correspondence does not exist. The learned per-head parameters are also not per-pixel uncertainty estimates. Therefore a genuinely different claim would require a concrete uncertainty target/objective, a reason it beats this ordinary competition, and controlled benefit beyond simply reducing source weight. None was established here. Adding a null token or renaming soft attention cannot by itself supply that difference.

**Strong counterpressure:** an ambiguous repeated-texture case can make all candidate source features geometrically admissible. This existing weighted attention and a proposed null-state mechanism both lack the missing identity evidence. Either can attend incorrectly or suppress useful information. Improvement must be demonstrated at retained support and against simple soft weighting/self fallback; dropping uncertain points alone is not evidence of a new mechanism.
