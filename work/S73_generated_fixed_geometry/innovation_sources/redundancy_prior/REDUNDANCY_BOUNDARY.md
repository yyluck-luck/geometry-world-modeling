# Repeated evidence: an old aggregation distinction

**Decision:** exact-copy invariance is already a classical set-aggregation property, not a novel guidance mechanism. One relevant primary source is **PointNet: Deep Learning on Point Sets for 3D Classification and Segmentation**, Charles R. Qi, Hao Su, Kaichun Mo and Leonidas J. Guibas, author version **arXiv:1612.00593v2, 10 April 2017**. Its §4.2–4.3 aggregates independently transformed points by coordinatewise maximum; Theorem 2 characterizes a bounded critical subset determining that aggregate. [Primary paper](https://arxiv.org/pdf/1612.00593v2)

For fixed deterministic per-observation features h, write `u(S) = MAX_{x in S} h(x)`. Appending another exact copy of an existing feature leaves every maximum unchanged: `MAX(a, a) = a`. This is **idempotence**, which is stronger than invariance to reordering. The statement is about the aggregation operator with unchanged features, not an audit of every normalization, stochastic training operation or complete PointNet inference implementation.

The connection to the preceding VIVID softmax example is exact: the latter normalizes over token multiplicity. One self token and one source token with equal logits give source mass 1/2; copying the source token gives 2/3. Max aggregation has no corresponding count-dependent denominator. Therefore token-level source mass need not measure the amount of distinct observational evidence. This does not make max aggregation a calibrated probability, or prove it is a better generator component. Changing the consumer to max pooling would be an ordinary baseline intervention, not a demonstrated innovation.

**Cost of idempotence.** A maximum discards multiplicity and contributions below its extrema. It cannot accumulate several individually weak but independent measurements merely because their number increases. It can also select an anomalously high feature and lose useful average information. These are direct properties of the operator, not claimed empirical PointNet failures.

**An exact copy and another observation are different.** Copying one stored photograph reuses the same acquisition noise; it does not produce another sensor measurement. But two separately acquired observations can be conditionally independent given the scene, even if their quantized values or learned features coincide. Under the illustrative scalar model `y_i = theta + epsilon_i`, independent Gaussian noise with variance `sigma²` and Gaussian prior precision `tau0` produces posterior precision `tau0 + n/sigma²`. Treating one stored sample copied n times as independent would falsely obtain that precision. Conversely, discarding n independent acquisitions because their values coincide can discard real evidence. This is a stated-model derivation, not a scientific numerical experiment or a result attributed to PointNet.

Consequently there is no general instruction to deduplicate images, tokens or near-matching features. The meaning of redundancy depends on observation identity, timestamp, acquisition dependence and the intended latent quantity. A source-ID copy control can test bookkeeping invariance; it cannot establish that nearby frames add no geometric or statistical information. Keep exact-copy tests separate from repeated independent observations and from correlated adjacent video frames.

The appropriate conclusion for innovation triage is limited: permutation invariance, idempotent set pooling and evidence accumulation answer different questions. None automatically supplies an unknown-correspondence event, calibrated confidence, or correct requested-camera generation. `NO_METHOD_SELECTED`; existing S73 protocols and results remain untouched.
