# S84：内部拟合误差下降，是否伴随该单锚点参考深度误差下降？

本目录只准备了源码与冻结合同；尚未读取真实PNG/NPZ、调用评分函数或运行模型。`PREPARATION_RECEIPT.json`记录实际准备时间、输入访问范围，以及只做AST解析/内存编译的检查。根任务与不同作者审清这两个固定文件后，才进入一次真实只读评分；当前没有结果。

两份输入是S83 **MST初始化后** 与 **100步后、清理前** 的封存状态，不是S82原始head。S83 `snapshot` 保存 `get_depthmaps()`，局部适配器返回注册log-depth的exp；原反投影构造 `(Z(u−cx)/fx, Z(v−cy)/fy, Z)`，随后才变到世界坐标。因此字段 `depth` 是相机光轴Z，不能用world_points第三列或raw self/cross第三列替换。源码/合同/回执身份已绑定在新合同；旧二进制SHA来自保存回执，本轮未读取二进制复核。

评分固定完整512×384网格，映射为原坐标乘1.25，按floor(+0.5)取640×480注册深度并除5000得到米。两阶段使用同一个仅由传感器决定的有效集合V；不按预测置信度、误差、距离或边缘筛点，不拟合尺度或偏移。若V为空或任一阶段在V出现非有限/非正预测，主比较是UNSCORABLE。只有两阶段完整有效才计算ΔMAE；小于−1e−9米、绝对值不超过1e−9米、大于1e−9米分别记录下降、无可分辨变化、上升。此容差只处理数值区分，远非物理精度保证。

正常评分保存全部196608行NPZ/CSV，包括每点原/取整坐标、传感器缺失、两份Z、无效原因和误差；还保存完整分母和输出SHA。CSV `nan` 是未定义值，不是0误差。结构或身份失败可能在构造行前发生，此时保留失败回执/已有部分输出，不伪造完整行或自动重试。程序只在本目录唯一 `execution_01` 写结果，不把GT写回优化。为核字节身份会读取整个两份NPZ，其中包含其他历史/颜色等字节；实际只解码depth/history_ids/K/c2w。四张深度打包为一个字段，因此会解码四张，只评分history19；不能称其余三张字节未读。未解码颜色、world_points、confidence、raw heads或其他新输入。

最近邻与构念边界：既有[DUSt3R原文](https://openaccess.thecvf.com/content/CVPR2024/html/Wang_DUSt3R_Geometric_3D_Vision_Made_Easy_CVPR_2024_paper.html)与本地优化源码说明，其目标将预测点图互相对齐；较低内部目标并非独立物理正确性。把封存Z与固定外部参考算MAE是普通深度诊断，作用是检验这两个“更好”是否一致，不是新方法、校准不确定性或生成收益。S81参考已见、晚17.126ms，近似K/注册误差/无去畸变限制保留；像素相关且只有一个锚点，不能当196608个独立场景。即使MAE下降，也仍须独立复算，并另用G0/Gpaste/Gguide的公平生成结果检验消费者收益。
