## A1. 几何指标存在对比度可利用性 —— ✅ 实测确认，已修正

复核者给出反例：固定有效掩码下线性 warp 满足 `E(a·Î+b) = |a|·E(Î)`，
故降低对比度即可降低一致性误差而几何毫无改善。

**本方实测（真实帧，scene_13 w0000）：**

| 对比度 a | 原始 MAE | sd 比 | 原守卫 |
|---|---|---|---|
| 1.00 | 8.716 | 1.000 | PASS |
| 0.80 | 6.984 | 0.801 | **PASS（漏过）** |
| 0.60 | **5.218** | 0.600 | **PASS（漏过，虚假改善 40%）** |
| 0.50 | 4.349 | 0.500 | BLOCKED |

线性关系精确成立（0.6×8.716=5.230 vs 实测 5.218，差 0.2%）。
**原 0.5 空间标准差底线不足以挡住该利用。**

**修正：** 主报告量改为对比度不变形式 `reproj_MAE / spatial_sd`。
实测该比值在 4 倍对比度范围内稳定到 0.3%（0.1638 / 0.1638 / 0.1634 / 0.1635）。
原始 MAE 与 spatial_sd **一并保留报告**，不隐藏。

**对既有结论的影响（已重算）：**

| 对照 | 原始 MAE | 对比度不变 | 重判 |
|---|---|---|---|
| S109 memory − static | +2.34 | +0.0424（1.7 SE，6/16） | 减弱 |
| S111 nms_off − static | +2.52 | +0.0267（1.4 SE，12/28） | **降为噪声** |
| S111 nms_on − static | +6.47 | +0.1111（4.1 SE，5/28） | 维持 |

**撤回**："nms_off 几何更差"这一表述不再成立。

## A2. TUM 深度尺度 —— ✅ 实测确认，是会直接毁掉 S113 的 bug

本项目既有 `src/tum_rgbd.py` 明确记载 TUM 为 **`/5000`**（且 0 表示缺失），
而 `geom_eval_s110.py` 硬编码 `/1000`（RGB-D Scenes v2 的尺度）。

**若不修，S113 会以 5 倍错误的深度做全部重投影。**

**修正（执行前必须完成并复核）：** 深度尺度、无效值规则、内参缩放、
位姿方向与遮挡处理**按数据集显式配置**，不得由实现自由决定；
并以真实帧对照重跑评价器控制，确认分离度仍成立。

## A4. F2 "判为无差别" 统计上错误 —— 接受，改写

`Δ < 2·SE(Δ)` 不能推出无差别：可能是效应小，也可能是不确定性大；
且 Δ 显著为负时同样触发，而那显然不是"无差别"。

**改为：**
> **F2 触发：未达到预注册的正向重访增益判据，故本次结果不支持该解释；
> 不宣称两类窗口等效。**

数值边界不变，不临时加等效性检验。

## A5. 实验单位与标准误 —— 原协议缺失，现补齐冻结

- **汇总顺序**：同一窗口的 2 个 seed 先取均值，得到每窗口一个值；窗口为分析单位
- **Δ 定义**：`Δ = mean_revisit(memory − recency) − mean_control(memory − recency)`
- **SE(Δ)**：由**窗口级**值计算，两组独立，`SE(Δ) = sqrt(SE_rev² + SE_ctrl²)`
- **重叠**：窗口起点间隔 < 20 帧者已在构造时排除
- **聚类（关键）**：若全部重访窗口源自**同一次闭环事件**，它们不是独立重访事件。
  构造时须记录每个重访窗口所属的闭环事件 id；**独立闭环事件数 < 3 时，
  结果记为 `UNTESTABLE_INSUFFICIENT_INDEPENDENT_REVISITS`，不触发 F1/F2 科学结论。**
- **禁止**：不得把 4 臂、2 seed、4 目标帧或重叠窗口计为独立样本

## A6. N-1 复放资格不适用于新配置 —— 接受，列为硬门槛

既有逐字节复放证据属于**旧 predictor/scorer**。v15 引入了新记录器，
构成新配置。**两个不同 seed 不替代同 seed 复放资格。**

**执行前必须：** 在 v15 配置下、同节点、同 seed 做 3 次复放并确认逐字节一致；
失败即 `N1_FAILED`，**不得以容差、平均或噪声模型替代**。

## A7. 跨窗口泄漏 —— 接受，这是原协议未覆盖的真实风险

**某帧可能是窗口 A 的 future，同时是窗口 B 的 history。**

**修正：** 隔离按**窗口**实施，不按序列。predictor 每次只挂载该窗口获准的输入；
禁止把整条序列或共享未隔离状态开放给所有窗口。scorer 在预测封存后另行获得参考数据。

审计钩子覆盖不完整时报 **`UNMEASURED`**，不得因"未记录到读取"签发无泄漏证明
（PEP 578 官方说明其不适合充当沙箱）。

## A8. 几何评价器的名称与资格 —— 接受降格

**正式名称改为：** 基于传感器深度与参考位姿的**跨视角 RGB 一致性辅助指标**。

- 它对某些对应关系破坏与内容破坏有反应（实测 8.716 / 42.877 / 85.359）
- 它**不是**物理几何正确性的认证
- **主几何指标为 Rdist/Tdist**（VMem 4.1 节 / CameraCtrl 协议，已实现并通过 4/4 规范控制）
- 本辅助指标只能与主指标并列报告

**守卫失败时的处理（明确）：** 保留原始分数、失败标记与完整分母；
**只扣留"几何改善"的归因**，不从主 RGB 对照或窗口账目中删除该窗口。
