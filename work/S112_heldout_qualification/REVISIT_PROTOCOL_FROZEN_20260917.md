## 1. 要回答的问题

2026-09-17 的 S109 与 S111 在 RGB-D Scenes v2 上得到一致负结果：相同真实输入下，
VMem 的 surfel 记忆检索不优于固定近期启发式（NMS 关闭时 +0.242 dB、17/28；
NMS 开启时 **−0.729 dB、9/28**）。

已记录的首要竞争解释是：**那些序列以单向前进运动为主，缺少显著的离开—返回**，
而重访正是记忆系统的核心价值主张。本协议检验该解释。

## 2. 可证伪的预先预测

> **P1**：在满足重访判据的窗口上，memory 臂相对 recency 臂的配对 PSNR 差值
> 将显著大于其在无重访窗口上的对应差值，且方向为正。

**否证条件（预先声明）：**

- **F1**：若 memory 减 recency 在重访窗口上的配对均值仍 ≤ 0，或正向配对数 ≤ 50%，
  则"缺少重访"**不能**解释既有负结果，该解释被推翻。
- **F2**：若重访窗口与非重访窗口的差值之差小于两者合并标准误的 2 倍，则判为无差别，
  同样不支持该解释。
- **F3**：若 memory 臂未通过几何评价器的抗退化内容底线，其几何结论作废。
- **F4**：若两臂 RGB 保真度差异超过 0.5 dB，则其几何对照按既有守卫规则扣留。

**F1 或 F2 成立即为该解释的死亡判据。** 届时应转而寻找其他解释，不得调整窗口判据重试。

## 4. 窗口构造规则（机械执行，不得看图选窗）

使用官方 `groundtruth.txt` 位姿与 `rgb.txt` / `depth.txt` 时间戳。

1. RGB 与 depth 以 **20 ms** 容差做一对一最近邻配对；位姿以同样容差关联。丢弃计数全部记录。
2. 记配对后的帧序列为 `f_0 … f_{N-1}`。
3. **重访判据**：存在 `i < j` 满足
   - 平移距离 `‖t_i − t_j‖ < 0.30 m`
   - 旋转测地角 `< 20°`
   - 时间间隔 `j − i > 150` 帧
4. **重访窗口**：目标为 `f_j, f_{j+5}, f_{j+10}, f_{j+15}`；
   记忆库为 `f_{i−30} … f_{i+30}` 每 5 帧一取，并入 `f_{j−60} … f_{j−5}` 每 5 帧一取。
   即记忆库同时含**早期访问区**与**近期路径**。
5. **非重访窗口（对照）**：从不满足判据 3 的位置按相同结构取窗，数量与重访窗口相同。
6. 两类窗口各取**前 8 个**（按 j 升序），不足则全取。选择完全由上述规则决定。
7. 记忆库中任何帧的索引必须 `< j`（严格早于首个目标帧），不得含未来。

## 5. 臂矩阵（k = 4 恒定，首槽参考相机在内容臂之间固定）

| 臂 | context |
|---|---|
| `recency` | 目标前最近的 4 帧（`f_{j-20}, f_{j-15}, f_{j-10}, f_{j-5}`） |
| `early_visit` | 早期访问区 4 帧（`f_{i-15}, f_{i-5}, f_{i+5}, f_{i+15}`） |
| `memory_nms_on` | 由 `get_context_info` 选出，NMS 开启（VMem 默认） |
| `memory_nms_off` | 由 `get_context_info` 选出，NMS 关闭 |

`memory` 臂的阈值按已验证方式引导：在恰好 5 帧状态以**记忆库自身相机位姿**作引导查询，
不使用任何目标位姿。
